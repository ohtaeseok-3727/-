# C18 개발 준비 — 죽음의 왕

[착수 안내](C03_C18_DEVELOPMENT_START.md) · [공통 구현](C03_C18_IMPLEMENTATION_GUIDE.md) · [공유 자산](../02_resource_ledger/C03_C18_SHARED_RESOURCES.md) · [최종 스토리](../../_story_scene_production/05_final_chapters/CHAPTER_18_FINAL.md)

## 상태·필수 입력

`SPEC_ONLY`. C15/16/17 세 흔적의 위치/방향과 소유/전달 탈취/충돌 규칙, C14 외핵 보존·상호 복구 파형·플레이어/용사 좌표 조각·아크 드래곤 외부 수호를 모두 사용한다. 직전 C17 결과 하나만 수신하고 C14 결과를 잃는 연결은 불가. 기존 ChapterFlags는 정수뿐이므로 벡터/파형은 문서 데이터 ID 또는 정수 키 집합으로 보존하는 방식을 구현 시 선택한다.

## 맵 통합 제안

`GP-M18-DEATH` 회수로→세 시험체→개인 사자/고정못 구역→무덤 왕좌→뒤편 내핵 HYBRID/BOSS_ARENA. 귀환 시 `GP-M14-CENTRALGATE` 세계측을 재사용한다. 왕좌 붕괴/내핵 노출/쐐기 설치/귀환/양핵 종료는 상태층. 외핵을 귀환용으로 중복 생성하지 않는다.

## 구현 순서·방법

- P0: Chapter18·장기 상태 입력과 귀환 경로 확인→세 시험체 검증→실제 사자 타깃 정책. 일반 Enemy 죽음/보상으로 해방을 흉내 내지 않는다. 공격 금지를 입력·자동 조준·투사체·범위/궁극기·환경 피해 경로 모두에 적용.
- P1: 귀속망 역류·해방 개별 완료→용사 실 고정/지속 감소(죽지 않는 하한과 재시도 분리)→세 권능 간섭 순서→왕좌 고정점 파괴와 죽음의 왕 실제 사망. 전투 불능인 용사가 즉시 평상 모션으로 회복하지 않게 후유증 상태 유지.
- P1: 사망 이벤트 1회→내핵 노출→시험 성공→쐐기 설치→좌표 결합→귀환 완료→설치 완료 신호의 순차 계약. 즉시 내핵 파괴/좌표 소실로 귀환을 건너뛰지 않음.
- P2: 외핵 타격→손상 감지→내핵 복구파 발생→설치 쐐기 발동→내핵 절단+복구 끊긴 외핵 붕괴. 프레임 독립적인 폐쇄 주기/사건 번호로 두 핵을 같은 주기에 종료. 단순 독립 타이머 두 개가 우연히 일치하는 방식은 피함.
- P2: 현재 사령망·중심문 망의 종료와 남은 세계를 결과 화면/월드 상태로 반영. 게임 전체의 마지막 완료 판정을 C03 고정에서 C18 결과로 확장.

## 출력·완료 조건

제안 `C18_COMPLETE / C18_RESIDUAL_POWERS_IDENTIFIED / C18_DEAD_RELEASED / C18_HERO_ALIVE / C18_DEATH_KING_DEAD / C18_NECROMANCY_ENDED / C18_THREE_POWERS_COLLAPSED / C18_INNER_WEDGE_ARMED / C18_RETURNED / C18_BOTH_CORES_CLOSED`.

세 시험 규칙 재현, 사자 공격 불가/못 파괴 금지·역류 해방, 용사 생존/쇠약, 죽음의 왕 실제 사망, 쐐기 시험/설치, 귀환 전 내핵 미파괴, 외핵 보존/수호의 연속성, 같은 폐쇄 주기·중복 이벤트·지역 이동/재시도 상태를 정적 검토한다. 종료는 현재 사령망과 중심문 네트워크이며 종족 화해·모든 전쟁 종료·모든 지옥문 소멸이 아니다. 제7영웅 운명/최초 삭제자·다른 세 왕 육체 생사는 OPEN. 게임 실행 검증 미수행.

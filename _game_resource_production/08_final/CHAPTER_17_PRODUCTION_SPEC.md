# C17 개발 준비 — 전쟁의 왕(전쟁핵 전선)

[착수 안내](C03_C18_DEVELOPMENT_START.md) · [공통 구현](C03_C18_IMPLEMENTATION_GUIDE.md) · [공유 자산](../02_resource_ledger/C03_C18_SHARED_RESOURCES.md) · [최종 스토리](../../_story_scene_production/05_final_chapters/CHAPTER_17_FINAL.md)

## 상태·입출력

`SPEC_ONLY`. 입력 C15/16 흔적 1/2와 규칙·C14 귀환 상태·C12 재합류 신호 경험. 전쟁의 왕은 C09 동일 존재의 현 전선 버전. 제안 출력 `C17_COMPLETE / C17_CONFLICT_RULE / C17_FORCED_COMBAT_ENDED / C17_THRONE_WARCORE_DESTROYED / C17_RESIDUE_VECTOR / C17_INNER_CORE_DIRECTION`.

## 맵 통합 제안

`GP-M17-WAR` 충돌 학습 입구→반복 잔영·깃발/사슬 구역→양측 분리 우회→재합류 문→왕좌/전쟁핵 BOSS_ARENA/HYBRID. 지옥 공통 키트, 충전량에 따라 보호막/문양 상태 변형. 분리는 같은 장면 안에서 진행하며 새 맵 진입으로 충전을 초기화하지 않는다.

## 구현 순서·완료 조건

P0: Chapter17·ConflictMeter에 공격/처치/패링/회피/환경 충격 사건 구분, 중복 집계 방지. 정확한 증분/저충전 문턱은 구현 조정값. P1: 문양/깃발/사슬 해제→분리 목표/합류→현재 충전 기반 보호막→왕 자체 과충전 창. C12 생존전과 달리 저충전 유지가 단계 목표. P2: 왕좌/핵 모두 종료·세 벡터를 겹쳐 C18 목표 생성.

일반 사냥으로 가장 쉽게 클리어되는 역설을 피한다. 잔영 처치 반복은 충전 비용이며 문양 해제가 해결. 전선 종료/왕 육체 사망을 구분, 최종 생사는 OPEN. 충전 수명/단계 재시도·동시 행동/환경 우회·세 좌표 전달 정적 확인. 게임 실행 검증 미수행.

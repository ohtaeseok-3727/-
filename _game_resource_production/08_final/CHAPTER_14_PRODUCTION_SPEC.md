# C14 개발 준비 — 지옥으로 가는 문

[착수 안내](C03_C18_DEVELOPMENT_START.md) · [공통 구현](C03_C18_IMPLEMENTATION_GUIDE.md) · [공유 자산](../02_resource_ledger/C03_C18_SHARED_RESOURCES.md) · [최종 스토리](../../_story_scene_production/05_final_chapters/CHAPTER_14_FINAL.md)

## 상태·입출력

`SPEC_ONLY`. 입력 C13 복구 반향·단면문 폐쇄 지식, 생존 아크 드래곤. 제안 출력 `C14_COMPLETE / C14_DUAL_CORE_CONFIRMED / C14_OUTER_CORE_PRESERVED / C14_COORDINATE_SHARDS / C14_ARC_GUARDS_OUTER / C14_ENTERED_HELL`. 외핵 보존과 좌표 조각은 C18 귀환·종결의 필수 장기 상태다.

## 맵 통합 제안

`GP-M14-CENTRALGATE` 중심문 세계측 계측·외핵·보조 고정 3개·진입 대기 구역 PUZZLE/TRANSITION. C13과 문 베이스 자산은 공유하되 단면/양면 논리는 구분. C18 귀환·아크 드래곤 수호/타격을 동일 베이스의 최종 폐쇄 상태로 재사용한다. 다른 장에서 같은 물리 맵을 활성화하는 세션 소유권은 구현 시 명시한다.

## 구현 순서·완료 조건

P0: Chapter14·계측/위상·외핵/내핵의 상호 복구 상태 모델. P1: 10초 축소 실험과 좌표 흐림→외핵 보존 선택→보조 고정 3개/진입 창. 타격 상호작용과 파괴 가능 대상을 분리하여 필수 외핵을 일반 공격으로 소실시키지 않음. P2: 두 조각 소유·외부 수호 상태를 후속 장 전체에 전달하고 C15 진입.

아크 드래곤의 수호는 공동 위험에 대한 제한 협력이며 화해가 아니다. 지금 외핵을 부수면 해결된다는 잘못된 성공 경로를 두지 않는다. 좌표 한 조각 누락/실험 중단/복구 재진입/일회성 진입·보존 상태 수명 정적 확인. 게임 실행 검증 미수행.

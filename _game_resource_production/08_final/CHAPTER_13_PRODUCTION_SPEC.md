## 상태·입출력

`SPEC_ONLY`. 입력 C12 현재 명령 중단/정복 교두보, 부상자 보호선 확인. 제안 출력 `C13_COMPLETE / C13_LIMITED_NONAGGRESSION / C13_SINGLE_ANCHOR_CLOSED / C13_RETURN_WAVE_RECORDED`. 원문 Final의 양면 가능성은 후속 C14에서 직접 확정할 가설이며 확정 사실과 별도로 저장한다.

## 맵 통합 제안

`GP-M13-FIRSTGATE` 인간 전선↔중앙 첫 문↔몬스터 전선 BATTLEFIELD/PUZZLE. 양측 경계·세 번 신호 지점·인간 사슬/몬스터 이동핵·중앙 단면 고정핵. GP-M10-FRONT 전선 자산과 GP-KIT-DEMON 설비 공유. 폐쇄 후에도 상대 진영 공격 태세는 남는 상태층. 중심문으로 이동할 출구 확보.

## 구현 순서·완료 조건

P0: Chapter13 등록·부상자 보호선 확인·양측 허용행동/경계와 신호 카운터. P1: 사슬 인스턴스 완료·실제 이동핵/포획/역슬롯·증원 차단→핵 노출·협력 파괴. 적 파동 전멸이 문 폐쇄 조건을 대신하지 못함. P2: 반향 계측/중심문 조사 목표.

제한 규칙은 전투 현장의 검증 가능한 행동이며 영구 동맹이 아니다. 상대 편이 도와주는 연출을 새로 확정하지 않는다. 단면문 성공을 양면 중심문에 그대로 적용하지 않음. 핵 조건·세 번 신호·경계 접근·증원 중복/차단·재시도·반향 전달 정적 검토. 게임 실행 검증 미수행.

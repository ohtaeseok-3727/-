## 맵 통합 제안

## 구현 순서

- P0: Chapter4 + Map/Gameplay/View 등록, C03 완료 잠금, 전초촌→분기 숲→성역 목표 연결. 야수/지성/조련의 대상·신호·후퇴 정책 분리, 일반 FSM/A* 재사용.
- P1: 조사 항목과 사건 순서/증거 강도 → 공명 튜토리얼 → 보스 게이지/반향 차단·보장 저지 → 수문/충돌 분리·철수 신호 세 번·생존 회수. 전면 섬멸로 우회하지 못하게 함.
- P2: 신호 방해·표본 대조 UI·현장 흔적·북동 탁본 안내·C05 결과 전달. 과거 조사 후 현재 전령 등장 10~20초는 원문 범위 내 구현 조정.

## 출력·불변식·완료 조건

제안 `C04_COMPLETE / C04_REMOVAL_ORDER_CONFIRMED / C04_DRAGON_ATTACK_DIRECTION / C04_GARKAN_ALIVE / C04_BOUNDARY_RUBBINGS / C04_NORTHEAST_ROUTE`.확정: 친필 제거 명령·아크 드래곤의 인간군 격퇴·지성 종족·오늘 충돌 중단. 보호 의도/정식 회담은 미확정. C05는 서로 다른 두 탁본을 실제 재료로 요구한다.

구조/반환 없이는 대치가 해소되지 않고, 두 중계기 파괴·수문/핀 조작 없이는 생존 보스전 완료 불가. 가르칸 모든 피해 생존·야수족 회수·양군 퇴로·재방문 상태를 정적 확인. 휴전/불가침/자동 동맹을 생성하지 않는다. 게임 실행 검증 미수행.

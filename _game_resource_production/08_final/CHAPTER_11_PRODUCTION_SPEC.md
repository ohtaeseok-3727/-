## 상태·입출력

`SPEC_ONLY`. 입력 C10 왕명 원문·후송 우선/후송대 상태·현장 지휘권. 제안 출력 `C11_COMPLETE / C11_EVAC_OUTSIDE_BORDER / C11_ORDER_INTENT_CONFIRMED / C11_COMMAND_HANDED_OVER / C11_RETURN_AS_PAIR`. C12 진입에는 마지막 수레 통과와 실제 지휘 인계가 모두 필요하다.

## 맵 통합 제안

`GP-M11-EVAC` 수문 계곡→부상자 다리→옆 협곡/역돌파→국경 안전권 LINEAR/ESCORT. GP-M10-FRONT와 국경 연결, 왕문으로 둘만 돌아가는 역방향 출구. C10 후송 수레/들것과 친위룡 기본군 공유. 파괴 교량은 변형 상태이며 무관한 새 맵을 로드해 추격을 없애지 않는다.

## 구현 순서·완료 조건

P0: Chapter11와 실제 호송 경로/차단 상태, 추격 거리·구역 상태 분리. P1: 수문 착지/교량 분리/옆 협곡 유도 순서 및 피해 하한·전투 퇴장, 부상자 통과 수→국경 안전→지휘 인계. 처치 수나 시간 경과만으로 후송 완료 처리하지 않음. P2: 봉인/행동 증거 비교와 둘만 귀환 안내.

친위룡 공격은 왕명 의도이며 단순 오해로 수정하지 않는다. 강제 착지·고립·유도된 친위룡은 살해 성공으로 집계하지 않는다. 마지막 수레·지역 비활성화·실패 재시도·인계 후 병력 동행/공격 명령 차단을 정적 검토한다. 게임 실행 검증 미수행.

## 상태·선행 계약

`SPEC_ONLY`.입력: C04 완료·인간/용 경계 탁본 두 장·북동 후보·현장 지휘권. 아르카스 회담을 검증하며 ‘불타버린 협정’이라는 제목만으로 협정 서명을 확정하지 않는다.

## 맵 통합 제안

`GP-M05-OUTER` 피난로·관문·외곽 진지 ESCORT/HUB ↔ `GP-M05-ARKAS` 지하 대기/무기실·회담실·기록고·쌍 관측탑/종탑·치료소 HYBRID. 실내 구역/탑을 같은 복합 시설의 구역으로 우선 설계하고 이동 거리가 과할 때만 분리한다. 화재·침수·탈출은 동일 베이스 변형. 입구는 C04 북동 경로, 출구는 산맥 후송로.

## 구현 순서

- P0: Chapter5 등록/맵·이동·입력 탁본 확인 → 호송/구조/화재 상태 → 접근 퍼즐. S02 무장 판정은 접견용 임시 보관 상태 제안이며 플레이어 아이템을 삭제하지 않음.
- P1: 3명 구조 선행과 서명 페이지 소실을 고정 → 세 기준 시간 환산/오차 UI → 명부 매칭 → 실제 운반대 위치와 화염·냉각 구역을 연결한 보스 FSM.
- P2: 증거 분류판/후송선 인계·인물 표현·환경 변화. 구조 속도로 완전 서명본을 회수하는 숨은 성공을 만들지 않음.

## 출력·불변식·완료 조건

제안 `C05_COMPLETE / C05_FORMAL_TALKS / C05_WEAPON_STORAGE / C05_NEAR_SIMULTANEOUS_REPORTS / C05_EVAC_ROUTE / C05_ERGANON_ID_CANDIDATE`.생존 확인은 출력하지 않는다. C06은 후송표·공통 시간표·고정틀/치료 인장 식별 정보를 사용한다.

정식 회담·무기 보관·거의 동시 보고만 확정. 협정 서명/선제 공격자/배후는 OPEN, 에르가논 동일 개체는 강한 정황. 보스는 현재 약탈자이며 고대 음모 조직으로 연결하지 않는다. 구조 우선·운반대 실제 완료·근거 부족 카드 거부·재시도 손실/중복 지급을 정적 확인. 게임 실행 검증 미수행.

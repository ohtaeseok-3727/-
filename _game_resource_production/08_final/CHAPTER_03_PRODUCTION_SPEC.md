# C03 개발 준비 — 이름 없는 일곱째

## 현재 상태와 입력

`CODE_EXISTS / ART_PARTIAL` — [기존 구현](../../docs/implementation/CHAPTER_03_IMPLEMENTATION.md)과 [최신 도시·포탈](../../docs/implementation/CHAPTER_03_CITY.md)이 기준. C02 완료·손실·벽화 탁본을 수신한다. C03 전체 재작성 대신 누락된 표현/개발 요구만 보완한다. 현재 정상 시작·스킵 정책과 기존 플래그 이름을 보존한다.

## 맵·연결·재사용

`GP-M03-CITY` 아르겐 야외 HUB/INVESTIGATION ↔ `GP-M03-MEMORIAL` 기념홀, `GP-M03-READING` 공개 열람실, `GP-M03-ARCHIVE` 봉인 서고(잠입/보스). 모두 기존 4지역. 도시 남문에서 C02 구호지와 연결한다. 최신 확정에 따라 기록관만 포탈 출입하고 주택·공방·수도원은 닫힌 개별 건물이다. 수도원 내부 조사를 외벽 배치/이관 기록으로 바꾼 차이를 유지한다. C04 출구 연결은 새 작업이다.

## 구현 순서

- P0: 기존 Chapter3 상태/최신 4지역/포탈 검증 유지 → C04용 결과 수신·출구 연결 설계. `Chapter3Architecture`와 건물 점유 영역을 읽고 가림·동선 보강.
- P1: 도형 인물/장치를 기존 용사/공유 NPC와 신규 고유 시트로 교체. 문서 확대·드래그 UI는 현재 없으므로 요청 범위에 맞춰 선택할 구현 제안이다. 스토리 조작과 최신 외벽 조사를 보존.
- P2: 추격/순찰/쇠뇌 예고·비살상·분산 사본 출발·지원 제재 시각화와 선택 피드백 정리.

## 출력과 주의

기존 `C03_COMPLETE`, `C03_LIMITED_FIELD_PERMIT`, `C03_EXPEDITION_COORDINATES`, `C03_HERO_COMMAND_RETAINED`와 증거/정치 플래그를 사용. `C03_WANTED=0`, `C03_WAR_ORIGIN_CONFIRMED=0`. C04는 제한 조사권·필체/인장·원정 좌표를 사용한다. 세라드 생존, 최소 세 필수 보관선, 지원 제한과 용사 지휘권을 유지한다.

## 완료 조건·후속 확인

S01~S10 선행 잠금·자유 조사 순서·원본 조건·반출 실패 재시도·사본/보급 중복 방지, 포탈 왕복/충돌/목표 안내와 C02 실제 손실 전달을 정적 확인한다. 모든 피해 경로에서 세라드 생존·처치 보상 없음. 게임 실행/화면/조작감 검증은 별도 명시 요청 후 수행한다.

## 상태·입출력

`SPEC_ONLY`. 입력 C07 위장 식별 코드·관측소 좌표. 제안 출력 `C08_COMPLETE / C08_RECOVERY_OBSERVATION / C08_PLAYER_PREDICTION / C08_UPPER_REPORT_CODE / C08_BLOOD_CASTLE_COORDS`. 행동 예측은 아직 없는 신규 기믹이며 기록되지 않은 과거 플레이를 보유한 것으로 꾸미지 않는다.

## 맵 통합 제안

`GP-M08-OBSERVATORY` 검은 관측소 BRANCHING/PUZZLE: 외곽 인증→인간/몬스터/용 기록실 세 갈래→동기화실→모르카 전투실·상부 송신대. 한 관측소 키트를 공유하고 기록실의 도구/관측 표식만 다르게 한다. 종족 구분은 적대 색이 아닌 대상 코드.

## 구현 순서·완료 조건

P0: Chapter8·세 기록실/동기화 선행 조건 → 관측 도중 실제 행동 수집. 데이터는 회피 방향/우선 타깃/장치 순서의 제한 길이 버퍼·빈도표로 제안. 이전 장 데이터가 없으면 C08 준비 구간에서 수집하고 표본 부족 시 명시적 기본 패턴 사용. P1: 예측 표본 고정→예고→공격→관측 갱신 FSM, 우회/미끼/역순 선택으로 오차 증가. 학습 데이터 없이 정답을 읽는 보스로 만들지 않음. P2: 세 회복률·상부 보고·라우팅과 C09 연결.

예측 정보를 화면에 주고 즉시 피할 수 있는 틈을 설계한다. 사망 후 버퍼 유지/초기화 정책은 구현 시 조정값으로 명시한다. 악마의 장기 소모 관측은 확정, 모든 전쟁의 직접 통제는 미확정. 세 자료 완료·예측 오차 변화·보고 수집·중복 좌표 방지를 정적 검토. 게임 실행 검증 미수행.

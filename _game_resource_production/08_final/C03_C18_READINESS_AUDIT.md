## 검토한 내용

- 최종본 각 장면의 조작/물증/상태와 다음 장 연결을 읽고 추출했다. 개발 방법·맵 통합·신규 플래그/모듈은 제안임을 표시했다.
- C03 기존 4지역과 최신 포탈/건물 변경을 반영했다. C04~18은 현재 미등록으로 분류했다.
- 재사용 맵: C10 왕정→C12, C14 외핵/중심문→C18. 동일 인물: C09/C17 전쟁의 왕, C10/12/14/18 아크 드래곤, 전 장 용사.
- 장기 입력: C14 귀환 조각/외핵 보존·C15~17 세 흔적/규칙을 C18에 전달하도록 명시했다.
- 비살상/전선 종료/실제 사망, C17 기록 잔영/C18 실제 개인 사자, 협력/화해를 구분했다.
- 존재하는 자산 경로와 새 제작 요구를 분리했다. 스냅샷 자산 목록에는 과거/거부 시트도 포함되므로 존재 자체로 재사용을 승인하지 않는다.
- 새 문서의 상대 링크, 장면 대응, 스냅샷 해시, 생성 문서 인덱스와 검색 DB 반영은 완료 보고 전에 확인한다.

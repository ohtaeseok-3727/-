# C03~C18 공유 리소스 장부

2026-10-20 · [개발 착수 안내](../08_final/C03_C18_DEVELOPMENT_START.md)

이 장부의 `GP-*`는 후속 개발 준비 문서 전용 ID다. 기존 C01/C02의 NPC/MAP/OBJ 번호를 재할당하지 않는다. 장별 Cxx 리소스 ID는 해당 장 문서에서 정의한다. `EXISTING`은 경로/소스 존재만 확인, `CANDIDATE`는 용도·품질 재확인 필요, `SPEC_ONLY`는 신규 제작/구현 필요다. 문서용 지도 ID는 런타임 정수 MapId가 아니다.

## 제작·배치 경로 원칙

- 실제 이미지: 기존 `SimpleGame/Assets/Characters/NPC/`, `Monsters/`, `Environment/Props/`, `Effects/` 아래 해당 역할 폴더를 검토한다. 미존재 예시 경로를 배포 완료로 쓰지 않는다. 캐릭터 종족과 NPC/적 역할에 맞춰 위치를 정한다.
- 지도: `SimpleGame/src/chapters/ChapterNMap.cpp`의 MapDefinition을 우선 사용. 문서용 맵 한 개는 여러 zone/area를 가질 수 있다. 한 장면마다 새 지역을 만들지 않는다.
- 새 스프라이트: Blender 형태/동작 → 투명 연속 프레임 → 도트 스타일 시트. `.blend`, 렌더/팔레트/변환 설정, 시트 메타데이터를 함께 보관한다. 기존 SmallKnight/SmallMage 기준과 알파를 직접 대조한다. 이 문서 작성에서는 제작하지 않는다.
- 신규 인물의 숫자 프레임/해상도/색을 임의 확정하지 않는다. 최소 모션 요구는 대기·이동·상호작용, 전투원은 예고/공격/피격, 생존 퇴장은 사망과 다른 상태, 보스는 단계별 고유 행동이다.
- 오브젝트는 기본형+라벨/문장+손상 상태로 제작한다. 논리적으로 다른 탁본/개인 유품/명령문을 하나의 증거 ID로 합치지 않는다.
- UI는 현재 도형·텍스트로 로직 우선 개발 가능. 오디오 API와 자산은 이 준비 작업에서 확인하지 않았으므로 사운드 연결 시 별도 조사한다.

## 제작 순서

P0: 장면/결과 계약, 베이스 지형·충돌, 가독성 있는 임시 객체, 핵심 기믹과 재시도. P1: 공용 인물/적과 각 장 필수 증거·보스·협력 모션. P2: 상태별 맵 연출·VFX·UI·오디오. P3: 장식. 현재 파일 존재/실제 연결/실행 검증 상태는 별도로 갱신한다.

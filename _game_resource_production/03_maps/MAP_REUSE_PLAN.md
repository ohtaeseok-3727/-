# MAP_REUSE_PLAN — CHAPTER 01

- S01 + S02 → MAP-001.
- S03 + S04 → MAP-002.
- S05 through S09 → MAP-003.
- S06/S07/S08 damage progression → MAP-003-B state layer, not duplicated map geometry.

## Environment Kits
- KIT-TOWN-01: village/farm ground, fences, simple structures, ration/depot props.
- KIT-FOREST-01: forest trail, creek, rocks, dead trees, wooden bridge.
- KIT-MINE-01: mine wall/floor, rail, cart, timber support, storage, workbench, gate.

## Variant Layers
MAP-001 ALERT:
- alarm state, damaged/emptied farm props, displaced civilians.

MAP-002 RAIN:
- rain VFX, wet-ground treatment, clue visibility state.

MAP-003 COMMAND_DAMAGED:
- broken bells, closed reinforcement gate, inactive healing point, debris, boss damage continuity.

## Revisit

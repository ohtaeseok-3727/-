## Consolidation Decision
- S01 and S02 are one village/farm map.
- S03 and S04 are one forest route map with a bridge encounter zone.
- S05-S09 are one abandoned-mine base with subzones and state variants, not five separate maps.

## MAP-001 Critical Path
Village entry → ration station → farm alarm → damaged farms/investigation → north trail exit.

## MAP-002 Critical Path
Track fork → creek clue → ridge sightline → convoy bridge interception → mine route exit.

## MAP-003 Critical Path
Mine exterior → gate or drain → relay/production/training observation → lift/depth route → command arena → command room/exit.

## Landmarks
- MAP-001: ration depot, closed mill, field edge.
- MAP-002: shallow creek, narrow wooden bridge.
- MAP-003: mine gate, rail/lift infrastructure, command reinforcement gate.

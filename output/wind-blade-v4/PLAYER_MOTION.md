# 플레이어 모션 연결

- 사용자 요청에 따라 기존 `mana-blade-motion-v1.png`를 변경 없이 `../../SimpleGame/Assets/Characters/SmallMage/mana-blade-motion-v1.png`로 복사했다.
- `../shared/mage-player-motion.js`의 `MagePlayerMotion`이 4열, 480px 행 간격으로 8프레임을 그린다. 기존 프레임 시간 [140,110,90,50,60,65,90,150]ms를 유지한다.
- `preview.js`가 플레이어와 바람 칼날에 같은 재생 시간을 전달한다. 최초 발사는 기존 마력칼날 효과 시작 시점인 340ms에 맞춘 미리보기 가정이다.
- 캐릭터는 비율을 유지해 표시하며 바람 칼날의 기존 크기 변형·1.5배 이동 속도·순차 발사 간격을 유지한다.
- 게임 코드·전투 판정은 변경하지 않았다. JavaScript 구문 검사만 수행했으며 게임 빌드·실행은 하지 않았다.
- 크기 후속 요청: 각 칼날이 플레이어 몸집 정도로 보이도록 기본 표시 캔버스를 `660 × playerScale`로 확대했다. PNG의 투명 여백을 고려한 값이며 베기 면별 변형은 유지한다. 이동거리 계산에는 종전 여유값을 사용하여 표시 크기 변경으로 이동 속도가 바뀌지 않게 했다.
- 속도 후속 요청: 직전 1.5배 속도에서 다시 2배 빠르게 조정했다. 이동거리는 유지하고 도착 시간만 절반으로 줄였다. 실제 게임 속도는 아직 미정이다.
- 생성 위치 후속 요청: 플레이어 기준 오른쪽으로 20px 앞당겼다. 이동거리와 속도는 유지한다.

2026-10-26: 중복 이미지 복사본을 삭제하고 런타임 자산을 직접 참조한다. 공통 모션 코드는 `output/shared/mage-player-motion.js`에 통합했다.

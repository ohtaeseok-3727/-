# 기사 스프라이트 기반 검 이펙트 v2

기존 기사 가로 베기·내려베기를 참고하여 검날 오라, 연속 곡선 잔상, 잔광 입자, 내려베기 착지 섬광을 코드로 만든 브라우저 시안이다. 게임 런타임 연결 전 단계다.

## 보기

프로젝트 루트에서 `py -m http.server 8765 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:8765/output/procedural-sword-v2/preview.html`을 연다. 이미 서버가 켜져 있으면 추가 실행할 필요 없다.

- 가로 베기 / 내려베기: 기존 공격 모션을 전환한다.
- 표현: 새 코드 효과, 기존 효과 스프라이트, 캐릭터만 표시 중 선택한다.
- 궤적 자세히: 공격 궤적을 보기 좋은 시점에서 정지한다.
- 시간 슬라이더: 원하는 시점으로 이동하며 정지한다.
- 0.25× / 0.5× / 1×, 검기 색상, 오라·입자 표시를 조절한다.

## 참조와 구현

- [원본 기사 공격](../../SimpleGame/Assets/Characters/SmallKnight/attacks-transparent-v2.png): 가로 베기와 내려베기 각 6개 자세를 그대로 표시한다.
- [원본 기사 효과](../../SimpleGame/Assets/Characters/SmallKnight/effects-transparent-v2.png): 금빛과 은백색 중심, 가로 초승달과 세로 궤적을 참조한다. 비교 모드에서만 원본 효과 이미지를 표시한다.
- [기존 미리보기](../../SimpleGame/Assets/Characters/SmallKnight/preview.html): 자세 순서 `[0,1,2,3,3,4,4,4,5,0]`와 단계별 시간 `[150,130,35,35,45,45,40,40,130,160]`ms를 유지한다. 반복 사이에는 대기 시간을 추가했다.
- 새 효과의 형태·오라 강도·검날 연결점·소멸 시간은 시안용 근사값이다. 검날 끝점을 자세마다 수동 지정하고, 잔상 곡선은 기존 효과의 형태를 바탕으로 작성했다. 픽셀 단위 자동 검 추적이나 게임 피해 판정이 아니다.
- 캐릭터 원본 PNG는 수정하지 않는다. 새로운 스프라이트를 생성하지 않으며, 새 검 이펙트는 Canvas 도형으로 그린다.

## 파일과 실행 흐름

| 파일 | 역할 |
| --- | --- |
| [preview.html](preview.html), [preview.css](preview.css) | 비교 화면과 좁은 패널 대응 |
| [preview.js](preview.js) | `SwordStudio`가 이미지 로딩, 입력, 시계와 렌더링을 연결 |
| [motion.js](motion.js) | `KnightMotion`이 원본 프레임·발 기준점·검날 연결점과 비교용 원본 효과 표시를 담당 |
| [sword-effects.js](sword-effects.js) | `SwordEffects`가 테이퍼 곡선, 겹친 발광, 검날 오라, 시간 기반 입자와 착지 효과를 그림 |
| [arena.js](arena.js) | `Arena`가 한 번 그린 배경을 재사용하고 바닥 그림자·주변 입자를 표시 |

이미지 로딩 → 원본 타이밍으로 자세 선택 → 바닥 빛 → 캐릭터 → 검날 오라·잔상·입자 순서로 그린다. 효과를 절대 재생 시간으로 계산해 슬라이더 이동이나 느린 재생에서도 이전 프레임의 입자가 남지 않는다.

## 확인

사용자의 보여 달라는 요청에 따라 브라우저 미리보기를 실행했다. 가로 베기와 내려베기의 주요 궤적, 원본 효과 전환, 색상 선택과 오라 제어를 확인했다. 브라우저 콘솔 오류·경고는 발견되지 않았고 JavaScript 4개 파일의 구문 검사를 통과했다. 좁은 패널에서 캐릭터가 작아지는 문제는 화면 크롭 방식으로 조정했다.

게임 빌드·실행 및 실제 게임 연결 검증은 하지 않았다.

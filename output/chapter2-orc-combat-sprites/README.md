각 PNG 옆의 동명 JSON에 프레임 사각형·피벗·내용 경계·여백을 저장했다. 모두 640×640 셀, 피벗 (320,512)이다. 일반병/엘리트는 2560×2560의 4×4, 바르칸 두 시트는 2560×1920의 4×3이다. 모든 지상 포즈는 내용 하단을 y=512에 정렬했다. 바르칸 점프 두 번째 포즈는 원본의 약 34픽셀 부양 차이를 유지했다. 가로 위치는 원본 열 중심을 공통 피벗으로 옮겨 무기 동작의 좌우 이동을 보존했다. 이는 시트 정렬용 피벗이며 실제 게임의 발 접지점·공중 이동 곡선은 재생 검토가 필요하다.

`tools/prepare_chapter2_sprites.py`의 단일 `SpriteSheetPreparer` 클래스가 알파 임계값 240으로 연결된 몸체를 추출하고, 고립된 작은 잔여물을 제외한 뒤 확대·축소 없이 재배치한다. Pillow는 PNG 입출력, NumPy는 픽셀 마스크와 원본 RGB 보존 검증에 사용한다. 이동 시트에서 픽셀을 복사하거나 포즈를 새로 생성하지 않았다.

검증: 56개 몸체 추출, 저장 후 픽셀 재비교, 전체 알파 값 0/255만 존재, 모든 프레임 여백 검사, 남긴 픽셀 RGB 동일 검사를 통과했다. 사방 최소 여백은 일반병/엘리트/바르칸 공격 128px, 바르칸 보조 113px다. 체크 배경 검토본 `*-v2-inspection.png` 네 장을 육안 확인했다. 체크 배경은 검토본에만 있고 자산 PNG는 실제 투명 배경이다. 상세 결과는 `inspection-v2.json`에 있다.

게임 코드에 연결하거나 빌드·게임 실행하지 않았다. 기존 생성 포즈의 체형·무기 길이 차이와 애니메이션 품질에 대한 이전 검토 한계는 별개로 남는다.

브랜치: `codex/chapter2-orc-combat-sprites`. 내장 imagegen으로 이동 시트를 참조하여 신규 동작을 생성했다. 기존 이동 시트와 런타임 자산은 교체하지 않았다. **전부 REVIEW_ONLY이며 게임 적용 가능한 완성본으로 승인하지 않았다.**

## 고정 기준과 생성 기록

- 각 적의 `SimpleGame/Assets/Monsters/Orc/{Common,Elite,Barkan}/walk-v1.png`가 체형·외형 기준이다.
- `SmallKnight/walk-transparent-v1.png`를 도트 크기·비율·팔레트 스타일 기준으로 함께 제공했다. 오크가 플레이어보다 큰 것은 사용자 확정이나 배율은 미정이다.
- 모든 신규 동작은 원본 픽셀을 복사하지 않고 새로 그리도록 요청했다. 바르칸 후속 수정은 생성된 신규 동작의 배경 제거를 요청했다.
- 정확한 전체 프롬프트는 `prompts.json`, 원본 파일명·SHA256·실측 크기·알파 개수는 `inspection.json`에 기록했다. 원본은 Codex generated_images에도 보존되어 있다.

## 검토 결과와 남은 문제

- 일반병의 가죽 장비, 엘리트의 철갑, 바르칸의 붉은 천과 금속 문장은 육안으로 구분된다. 바르칸의 무기 공격·공중 자세·함성 자세도 구분된다.
- PNG CRC와 RGBA8 헤더를 검사했고 네 시트 모두 alpha=0 픽셀이 존재한다. 그러나 반투명 픽셀이 많고 바르칸 보조 동작에는 배경처럼 보이는 잔여 색 번짐이 남는다. **알파 채널 존재는 배경 제거 성공을 뜻하지 않는다.**
- 생성기가 요청한 크기를 그대로 출력하지 않았다. 일반병/엘리트 1254×1254는 4×4 정수 셀로 나눌 수 없다. 바르칸 공격만 362×362 정수 셀로 나눌 수 있으나 셀 경계 안전 여백과 모든 프레임 앵커는 검증되지 않았다. 보조 동작 1024 높이도 3행으로 정수 분할되지 않는다.
- 프레임 사이 체형·무기 길이 변화, 손과 무기의 연결, 기존 이동 시트와의 정확한 픽셀 크기·팔레트 일치, 발 기준점, 사망 자세의 연결성을 추가 수정해야 한다. 정적 육안 검토만으로 일치 판정을 하지 않았다.
- 바르칸 배경 제거를 각 시트에 한 차례 제한적으로 시도했다. 같은 문제를 만드는 전체 재생성을 반복하지 않았다. 다음 제작 단계는 경계·체형을 고정한 개별 프레임 교정과 알파 정리이며, 이 검토용 시트를 런타임에 연결해서는 안 된다.
- 빌드·게임 실행·애니메이션 재생 검증은 수행하지 않았다. 전투 AI, 공격 판정, 함성의 밀침/공속 효과도 이번 자산 제작에서 구현하지 않았다.

# 천단참 사선 베기·화면 균열 미리보기

[미리보기 열기](preview.html). HTML 파일을 직접 열어도 동작한다. 게임 빌드 없이 브라우저에서 확인한다.

0.5배속 자동 반복으로 시작한다. 재생/일시정지, 다시 보기, 0.25/0.5/1배속, 좌우 방향, 반복, 시간 슬라이더와 4개 단계 정지 버튼을 제공한다.

검기 응축(0–650ms) → 화면을 향해 사선 베기(650–820ms) → 잔상(820–1050ms) → 잔상을 따라 화면 균열(1050–1890ms). 균열은 연결된 선에서 갈라지고 배경 양쪽이 어긋나며, 파편이 날아가지 않는다.

`preview.js`의 CheondanGeometry는 [게임 연출](../../SimpleGame/src/ui/CheondanView.cpp)의 직접 그리기 수식과 시간을 옮긴다. CheondanPreview는 재생 UI·확인용 배경·기존 기사 동작·배경 분리를 담당한다. 새 효과 이미지나 외부 라이브러리가 없다. 기존 캐릭터 파일을 상대 경로로 참조하므로 이 폴더만 따로 옮기면 캐릭터가 보이지 않을 수 있다.

게임 캡처가 아니다. Canvas의 배경 분리는 작은 띠 단위 클리핑이며 게임은 후처리 셰이더에서 픽셀별로 샘플링한다. 미리보기는 화면 연출에 집중하고 게임의 이동 피해 판정·얇은 월드 균열 표식·조명·블룸은 재현하지 않는다. 게임 수치나 파일을 미리보기 조작으로 바꾸지 않는다.

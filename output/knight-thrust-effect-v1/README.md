2026-09-23. 내장 image_gen으로 제작. 파일: `../../SimpleGame/Assets/Characters/Skills/Knight/thrust-effect.png`.

- 캐릭터와 실물 검이 없는 은백색 찌르기 효과다. 이전 찌르기 모션에 중첩할 용도다.
- 1536×1024 RGBA PNG, 2열×2행. 셀당 768×512.
- 재생 순서: 좌상(발생) → 우상(확장) → 좌하(최대 길이) → 우하(소멸).
- 같은 효과를 여섯 번 재사용하며 높이·각도·생성 시점은 게임에서 별도로 조정한다.
- 기준 시트는 `SimpleGame/Assets/Characters/SmallKnight/walk-transparent-v1.png`. 이전 찌르기 모션은 방향 참조에 사용했다. 캐릭터 픽셀을 복사하거나 캐릭터를 다시 그리지 않았다.
- 4px 간격 알파 표본 검사: 알파 최솟값 0, 최댓값 254, 투명 표본 88,954개, 비투명 표본 9,350개, 좌상 모서리 알파 0. 실제 알파 투명 배경이 존재한다.
- 시각 대조: 은백색/회색의 큰 도트 궤적, 오른쪽 방향, 길이 확장과 분해 표현을 확인했다. 생성 이미지라 기준과 RGB/격자가 수치상 완전히 동일하다는 보증은 하지 않는다.
- 생성 결과의 시작점은 프레임별로 약간 다르다. 셀 안의 권장 피벗(육안 근사)은 순서대로 (175,310), (133,310), (171,225), (130,226)이다. 게임 연결 시 이 피벗을 검끝에 맞춰 정렬한다.
- 효과의 길이·색상·프레임 수는 제작 시안이며 피해 판정·밸런스 수치를 확정하지 않는다. 게임 코드 연결과 빌드/실행은 수행하지 않았다.

실제 제작 프롬프트는 `PROMPT.md`에 기록했다.

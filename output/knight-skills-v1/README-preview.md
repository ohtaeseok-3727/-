# 기사 스킬 미리보기

`preview.html`을 일반 브라우저에서 열면 연속 찌르기·검기 상인·검기 발산을 각각 확인할 수 있다. 기존 PNG를 그대로 읽으며 인터넷 연결이나 설치가 필요 없다.

## 재생

- 각 스킬은 독립 재생/정지, 처음부터, 이전/다음 단계, 시간 슬라이더와 반복 옵션을 가진다.
- 공통 옵션: 전체 재생/정지, 0.25×/0.5×/1× 속도, 배경색, 좌우 반전, 연결점 표시.
- 각 카드에서 이펙트를 끄거나 가로·세로 위치와 크기를 조정할 수 있다. 변경값은 현재 미리보기에서만 사용한다.
- 연속 찌르기: 캐릭터는 찌르기 동작을 한 번 수행하며 180/210/240/270/300/330ms에 이펙트가 30ms 간격으로 발동한다. 모두 같은 각도(오른쪽 수평)이며, 생성 위치는 앞뒤·위아래로 불규칙하게 배치한다. 마지막 효과가 끝나는 475ms부터 검을 거두고 610ms에 대기로 돌아간다. 시간·위치 값은 미리보기용이다. 배치는 고정된 불규칙 오프셋이며 매 재생마다 난수를 뽑는 방식은 아니다.
- 검기 상인: 기존 이동 시트 첫 프레임의 검에 독립 검기 루프를 붙인다.
- 검기 발산: 이전 시트의 위쪽 캐릭터 동작과 아래쪽 발사체를 분리해서 재생한다. 360ms부터 발사체가 이동하고 캐릭터 회복 뒤에도 남아 소멸한다.
- 검기 속도는 기존 대비 2배(0.51→1.02px/ms)다. 비행·소멸 시간을 420ms로 줄여 780ms에 종료하며, 이동 거리와 캐릭터 모션 시간은 유지한다.

## 파일 역할과 흐름

찌르기 위치의 발동 순서는 높이순 4→1→6→3→5→2로 섞었다. 기존 여섯 위치와 30ms 간격은 유지하며, 매 반복마다 재추첨하지 않는 미리보기 배치다.

- `preview.html` / `preview.css`: 페이지 구조와 화면 배치.
- `preview-data.js`: 원본 경로, 프레임 사각형, 발/효과 기준점, 여섯 찌르기 이벤트.
- `preview.js`의 `SpriteRenderer`: 원본 프레임을 위치·배율·각도에 맞춰 표시.
- `SkillPreview`: 스킬별 재생 시간, 입력, 동작과 효과의 결합을 관리.
- 이미지 로딩 → 스킬별 카드 생성 → 독립 시간 진행 → 캐릭터와 효과 표시 순서다. 별도 게임 코드나 런타임을 실행하지 않는다.

원본은 `../../SimpleGame/Assets/Characters/Skills/Knight/thrust.png`, `../../SimpleGame/Assets/Characters/Skills/Knight/aura.png`, `../../SimpleGame/Assets/Characters/Skills/Knight/wave.png`, `../../SimpleGame/Assets/Characters/Skills/Knight/thrust-effect.png`, 기사 미니 이동 시트다. 삭제한 직접 픽셀 제작 v2는 사용하지 않는다.

## 검증과 한계

- Node의 구문 검사로 두 JavaScript 파일을 확인한다. 원본 PNG 존재, 실제 이미지 크기 대비 모든 프레임 사각형 범위, 찌르기 이벤트 6개를 확인한다.
- 연결점은 생성 시트에서 측정한 근삿값이며 조정 슬라이더를 제공한다. 시간·배율·속도는 미리보기용 가정이다.
- 이전 검기 발산 모션은 횡베기 표현이 약하고 방출 프레임에 검기가 일부 함께 그려져 있다. 해당 원본을 변경하지 않고 사용한다.
- 회수 프레임은 원본 x=1232부터 추출해 왼쪽에 넘어온 이전 프레임의 검기 조각을 제외한다. 발 기준점도 186→106으로 함께 보정해 캐릭터 표시 위치를 유지한다.
- 브라우저 자동 확인은 인앱 브라우저의 로컬 `file:` URL 보안 정책에 의해 차단되었다. 자동 화면/재생 확인을 완료했다고 주장하지 않는다. 사용자가 일반 브라우저에서 파일을 직접 열어 확인할 수 있다.
- 게임 적용·게임 빌드·게임 실행 검증은 수행하지 않았다.

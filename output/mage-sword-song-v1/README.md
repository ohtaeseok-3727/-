# 마법과 검의 노래 — OpenGL 효과 v2 미리보기

[preview.html](preview.html)을 브라우저에서 직접 열면 된다. 외부 패키지와 서버는 필요 없다.

두 마법진 동시 생성 → 4초간 검 세례 40회 → 두 원의 합체 → 최종 폭발을 직접 그린다. 재생·일시정지·반복·배속·시간 탐색·단계 선택을 지원한다. 정식 수치와 게임 연결은 [구현 문서](../../docs/implementation/MAGE_SWORD_SONG.md)를 따른다.

`ArcaneGpuPreview`가 WebGL2 효과·HDR·블룸·굴절을, `SongGeometry`와 `SwordSongEffect`가 검 장식과 기본 도형 대체 경로를, `SwordSongPreview`가 조작·배경·기존 캐릭터 표시를 담당한다. 마법진·마력 응축·입체 폭발 셰이더는 게임 소스에서 가져온다. 효과 이미지가 없고 캐릭터는 기존 원본 PNG의 데이터 URL이다.

게임 셰이더 변경 후 프로젝트 루트에서 `python tools/effects/export_arcane_preview.py`를 실행하면 `arcane-shaders.js`와 `character-data.js`를 갱신한다. HTML·JavaScript 파일들을 함께 유지하면 로컬 파일로 열 수 있도록 구성했다. 별도 서버·패키지 설치는 필요 없다.

지원 상태는 화면 위에 표시한다. WebGL2가 없거나 준비가 실패하면 기본 Canvas 도형으로 돌아간다. 부동소수점 타깃 미지원은 일반 정밀도를 사용하므로 광채가 제한된다. 컨텍스트 손실은 새로 열기 안내를 표시한다. 픽셀 비용과 최대 3개 Canvas 업로드가 있어 브라우저 성능은 게임의 성능과 다르다.

타격 개수 표시는 연출 시간으로 계산한 안내다. 실제 게임 피해·AI·전리품을 실행하는 도구가 아니다. 효과 셰이더는 같지만 배경·후처리 설정·캐릭터 시안 동작에 차이가 있다. 정적 구문·등록·참조 확인만 수행했으며 게임 빌드·회귀·미리보기 재생·화면·성능 검증은 하지 않았다.

# 일반 고블린 스프라이트 제작 기준

## 제작 대상

- 일반 고블린 이동 시트: 옆모습 기준 4프레임 걷기.
- 일반 고블린 공격 시트: 곤봉을 위에서 아래로 내리치는 4프레임 공격.
- 두 시트 모두 실제 알파 채널을 가진 투명 PNG로 만든다.

## 확정 외형

- 일반 고블린은 갑옷을 입지 않고 곤봉을 든다.
- 노출 표현은 성적 특징이 없는 비성적·무특징 형태로 제한한다.
- 현재 제작 범위는 일반 고블린뿐이다. 고블린 워리어·고블린 헌터·고블린 군단장의 스프라이트는 포함하지 않는다.

## 시각 기준과 제작 가정

- 새 몬스터이므로 기존 고블린 이동 시트는 없다. 기사와 마법사의 미니 이동 시트는 큼직한 픽셀아트 미감의 참고로만 사용한다.
- 일반 고블린은 짧은 팔다리와 덩어리감 있는 체형, 플레이어 미니 스프라이트와 같은 굵고 큼직한 도트 표현을 사용한다.
- `walk-v2.png`에서 정한 체형, 픽셀 크기, 색상 팔레트는 이후 일반 고블린 공격 시트의 고정 기준이 된다.
- 공격 스프라이트는 이동 시트의 원본 픽셀을 복사하거나 재사용하지 않고 새로 그린다.
- 걷기와 공격 중 머리·몸통 비율, 팔다리 수와 연결, 곤봉을 드는 손이 일관되어야 한다.
- 결과는 이동 시트와 공격 시트를 직접 대조해 체형·픽셀 크기·팔레트의 일관성과 투명 알파 채널을 확인한다.

## 저장된 시트 메타데이터

- `walk-v2.png`: 2172×724 PNG, 가로 4등분으로 프레임당 543×724.
- `attack-v2.png`: 2172×724 PNG, 가로 4등분으로 프레임당 543×724.
- `walk-v1.png`과 `attack-v1.png`은 이전 장팔다리 시안을 보존하는 파일이며 교체·삭제하지 않는다.
- 이 항목은 파일 보관과 슬라이스 기준만 기록한다. 재생 속도, 애니메이션 등록, 게임 적용은 포함하지 않는다.

## 정적 품질 확인

- v2 두 시트는 32bpp ARGB PNG이며 실제 알파 0 픽셀과 반투명 가장자리 픽셀이 있다.
- 두 시트의 각 543px 셀에서 알파 값이 128을 넘는 본체 영역은 셀 좌우 경계에 닿지 않는다.
- 눈으로 비교한 결과 이동·공격 모두 짧은 팔다리와 굵은 도트 비율을 유지한다. 공격 3프레임은 자유 손 일부가 몸통과 겹치지만, 두 팔의 구조와 곤봉을 쥔 팔은 식별된다.

## 아직 미정인 사항

- 프레임별 캔버스 크기, 재생 속도, 좌우 반전 사용 여부, 파일명과 게임 적용 방식은 아직 정하지 않았다.

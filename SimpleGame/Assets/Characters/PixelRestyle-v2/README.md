캐릭터 시트 3장에 총 48개 자세를 보관한다. 원래의 게임용 PNG는 덮어쓰지 않았다. 미채택 v1은 Git 제외 경로 `.local_knowledge/artifacts/hero-player-restyle-rejected-v1/`에 보관하며 배포·게임 참조에서 제외한다.

## 제작·교정

- 제작은 **내장 image_gen**을 사용했다. CLI/API 대체 경로나 Blender를 사용하지 않았다. 최종 프롬프트·참조 역할·교정 지시는 [prompts.json](prompts.json)에 보관했다.
- 처음 승인한 NPC 도트를 기준으로 공통 기본형을 먼저 만들고 그 기본형을 이동·공격 시트에 참조했다. 기사·마법사의 갈색 머리, 기사 은색 갑옷·올리브 방패, 마법사 남색 옷·청록 장갑 보석, 용사의 금발 묶음머리·붉은 망토·검과 방패를 구별한다.
- 용사 시트의 불투명 배경 추출은 실패해 제외했다. 투명한 기사 시트를 형식 참조로 사용해 새 용사 시트를 생성했고, 피격 자세 한 칸의 검·방패 손 배치를 별도로 교정했다. 미채택 불투명 결과를 투명 자산으로 판정하지 않았다.
- 최종 PNG는 도구 출력을 그대로 복사했다. 픽셀을 Python으로 다시 그리거나 지우지 않았다. 메타데이터 추출은 원본 RGBA 값을 변경하지 않는다.

## 프레임·코드 연결

[pixel_restyle.py](../pixel_restyle.py)의 `SheetInspector.inspect/write`가 [frames.json](frames.json)과 `src/generated/PixelRestyleHeroData.h`를 만든다. 알파 128 초과의 실루엣으로 실제 분리 간격을 찾는다. 시트의 가로·세로를 단순 균등 분할하지 않는다. 실제 부분 알파는 원본에 보존한다.

각 행 마지막의 서 있는 회복 자세를 높이 기준으로 삼아 행별 생성 크기 차이를 보정한다. 같은 행에서는 배율을 고정하여 웅크림·팔 뻗기 자체는 유지한다. 발 피벗은 각 자세의 발끝 영역으로 구한다. 4자세 이동은 기존 8개 시간 슬롯에 두 번 대응한다.

`PixelRestyle.apply`는 기존 8개 클립의 몸체 사각형·발 오프셋을 교체한다. 준비/타격/회복 구간과 입력·피해 판정·기존 몸체 시간 배열·전체 시간·효과 시작 시간·독립 효과 프레임은 유지한다. 마법 효과는 새 장갑의 청록 보석 위치를 추출하여 손을 따라가게 연결하고 1번의 전방 20/위 5 보정을 유지한다.

[export-combat-visuals.py](../export-combat-visuals.py)는 공통 JSON·브라우저 JS·실제 `src/generated/CombatVisualData.h`·배포 대상을 함께 갱신한다. 기존 스킬 효과 배포 항목을 보존했다. `Chapter1Sprites`·`Chapter2Sprites`는 생성 헤더의 용사 경계·대기/검격 3영역을 공유하고, C03도 기존 `Chapter1Sprites` 호출로 새 용사를 표시한다. 텍스처 캐시 수명과 생존 상태 선택은 유지한다.

`KnightSkillView::SkillBodyTime`은 기존 찌르기·검기 스킬의 준비/타격/회복을 새 기사 공통 검격 자세에 대응한다. 별도 찌르기 전용 새 고유 동작을 만들었다는 뜻은 아니다. `SpriteHilt`는 새 시트의 [칼자루 좌표](sword-anchors.json)와 현재 몸체의 발 피벗·배율로 오라 위치를 계산한다. 옛 시트 셀 크기나 경계 비율을 새 칼자루 좌표로 재사용하지 않는다. 좌표·각도는 새 픽셀을 보고 설정한 시각 배치값이며 실제 게임 화면의 정밀 정렬은 미검증이다.

기존 [combat-preview.html](../combat-preview.html)은 갱신된 공통 데이터를 읽는다. 이번 작업에서는 미리보기나 게임을 실행하지 않았다.

## 검토 범위

최종 PNG를 직접 대조해 도트 표현·체형·손·장비·프레임 분리를 검토하고 48개 프레임의 경계·피벗·장갑 위치를 추출했다. 세 시트 모두 실제 알파 투명 픽셀을 가진 RGBA다. 완전 이진 알파 또는 모든 동작의 해부학적 완벽함을 자동 검증했다는 의미는 아니다.

기존 Git 데이터와 8개 클립의 ID·직업·몸체 시간·전체 시간·효과 시작 시간·독립 효과 프레임이 유지됨을 확인했다. 48개 프레임의 알파 128 초과 픽셀이 누락·중복 없이 분리 영역에 들어가며, 발 피벗과 회복 자세 높이 150 정규화도 확인했다. 자산 13개의 PNG 크기·경로, 새 헤더의 프로젝트/필터 단일 등록, XML 파싱, 문서 링크 958개와 변경 공백 검사가 통과했다.

게임 빌드·실행·C++ 회귀·실제 애니메이션 재생은 사용자 지침에 따라 수행하지 않았다. 실제 화면에서의 효과 정밀 정렬과 동작 연결은 실행 검증으로 확인한 상태가 아니다.

전체 C++ 경로 검사에는 기존 `MageUltimateSwordView.h`의 프로젝트/필터 등록 불일치 1건이 있다. 이전 Git 버전에도 같은 불일치가 있음을 확인했으며 이번 변경에서 수정하지 않았다. 새 생성 헤더는 프로젝트와 필터에 모두 등록했다. 스테이징·커밋·병합·push는 수행하지 않았다.

# 작은 기사 이동·공격 시안

- 최종 이동: walk-transparent-v1.png, 1536×1024, 4열×2행 8프레임.
- 최종 공격: attacks-transparent-v2.png, 1536×1024, 6열×3행. 방패 밀치기 / 가로 베기 / 내려베기 순서.
- 최종 효과: effects-transparent-v2.png, 1536×1024, 6열×3행. 방패 충격 / 가로 궤적 / 내려베기 궤적·지면 충격.
- 세 최종 PNG의 32비트 RGBA 형식과 빈 배경 지점의 알파0을 확인했다. 생성 편집이므로 원본 전경과 픽셀 단위로 동일하다고 보장하지 않는다. 원본은 source 파일로 보존했다.
- checkerboard-rejected 파일은 알파가 없는 실패 결과이며 사용하지 않는다.
- preview.html: 배경 변경, 효과 켜기/끄기, 재생·속도·단계 이동 지원. 좌우 반전은 장비도 뒤집는 검토용이다. 우측 시점을 기준으로 제작했으며 횡스크롤 방식 확정이나 게임 연결은 수행하지 않았다.
- 캐릭터는 기준 높이를 맞추고 공격 효과는 약150~230px 크기로 짧게 재생한다. 원본 공격 셋째 행의 검이 위로 돌출되어 y650부터 추출한다.
- 게임용 정규 저해상도 아틀라스는 아직 아니다. 빌드·게임 실행·HTML 실행은 하지 않았으며 이미지 육안 확인과 파일 형식 검토만 수행했다.

## 제작

효과 위치 수정: 가로베기 중심 X를340에서290으로50px 몸통 쪽으로 이동했다. 내려베기는 효과별 보이는 하단(알파32 이상)과 현재 캐릭터 자세의 부츠 하단을 이미지에서 읽어 같은 화면 Y에 정렬한다. 크기·재생시간·원본 PNG는 유지한다. 이미지 픽셀 읽기와 코드 정적 검토만 수행했다.

내장 image_gen으로 기존 knight-small-cute-v1.png를 참조하여 이동과 공격을 생성했다. 공격 효과는 별도 생성했다. 배경 제거도 image_gen으로 수행했고 실제 알파 유무를 확인하여 결과를 선택했다. 효과 배경 제거는 생성 한도 후 재개하여 완료했다.

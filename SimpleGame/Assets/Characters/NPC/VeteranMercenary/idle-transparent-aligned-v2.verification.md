# v2 정적 검증

- 소스와 출력 시트는 모두 2172×724이며, 4개 셀은 각각 543×724이다.
- 외곽에서 이어지는 밝은 무채색 체크무늬만 4방향 flood fill로 알파 0 처리했다.
- 어두운 외곽선·유색 전경을 5px closing으로 연결하고, 외곽선이 약한 각 프레임의 양 어깨 방어구에는 좁은 보호 다각형을 적용한 뒤 flood fill을 수행했다.
- 셀 안쪽에 완전히 막힌 무채색 영역은 보존한다. 배경인지 장식인지 판별할 수 없는 내부 픽셀을 삭제하지 않기 위해서다.
- 프레임은 중앙 x와 발바닥 행의 중앙값에 맞췄고, 각 이동은 셀 경계 안에서 이루어져 잘린 전경 픽셀이 없다.
- 이 정리는 체크무늬와 정렬만 다룬다. 미니 기사 이동 시트와의 체형·픽셀 크기·팔레트 정확 일치는 기존 시안의 미해결 제한으로 남는다.

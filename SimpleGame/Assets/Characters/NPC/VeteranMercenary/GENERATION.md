# 베테랑 용병 NPC idle 시안

- 사용자 요청: 플레이어가 아닌 베테랑 용병 NPC의 idle 스프라이트.
- 제작 방식: built-in image_gen.
- 외형 제안: 짧은 회색 머리와 수염, 작은 흉터, 낡은 철제·가죽 장비와 올리브색 망토. 외형은 사용자 확정 설정이 아니다.
- NPC 전용 이동 시트가 아직 없으므로 미니 기사 이동 시트를 임시 시각 기준으로 사용한다. 체형·픽셀 크기·팔레트를 유지한다.
- 게임에 자동 연결하지 않으며 빌드·실행하지 않는다.

## 검토 결과

- 저장 파일: `idle-draft-v1.png` (외형 검토용, 게임 적용 금지).
- 4프레임 외형 시안은 생성했으나 출력 크기는 요청한 1536×512가 아닌 2172×724이다.
- 배경 제거를 한 차례 추가 요청했으나 PNG color type 2(RGB), tRNS 없음으로 실제 투명 배경이 아니다. 체크무늬가 이미지에 포함되어 있다.
- 기사 기준과 직접 대조했으며 같은 소형 스타일이지만 체형·픽셀 크기·팔레트의 정확한 일치는 확인하지 못했다. 완성 에셋으로 승인하지 않는다.
- 빌드나 실행 검증은 하지 않았다.
- 추가 편집 프롬프트: 네 캐릭터의 픽셀·동작·정렬·체형·팔레트를 유지하고 체크무늬와 배경 질감만 제거하여 실제 RGBA 알파 투명 PNG로 출력. 미니 기사 이동 시트 기준을 유지.

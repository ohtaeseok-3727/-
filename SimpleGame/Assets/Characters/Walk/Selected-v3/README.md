# 사용자 선택 이동 시트 v3

2026-10-26 · 사용자가 선택한 3행×4열 시트의 마법사 무릎 갑옷과 기사·용사 무기 크기를 교정한 뒤, 실제 투명 배경과 재생 위치를 보정했다. 최종 요청에 따라 **이동만** 게임에 연결했다.

- [walk.png](walk.png): 기사·마법사·용사 순서의 12자세. 1536×1024 RGBA, 완전 투명 픽셀 729809개. imagegen 출력 픽셀을 그대로 보관한다.
- [frames.json](frames.json): 투명 간격으로 나눈 프레임 경계, 허리 버클 X·발바닥 Y 피벗, 캐릭터별 고정 기준 높이, 기사 칼자루 좌표. 원본 PNG의 셀 배치는 이동시키지 않고 이 좌표로 재생 위치를 고정한다.
- 색감·도트 후속 교정: 사용자가 전체 밝기 보정과 런타임 색 보정을 거부하고 PNG 자체의 피부·머리색을 공격 시트에 맞추도록 지시했다. 내장 imagegen으로 갈색/금발·피부 팔레트를 공격 시트 기준으로 교정하고, 부드러운 명암을 줄여 계단형 윤곽·선명한 픽셀 덩어리로 수정한 PNG를 직접 교체했다. 전체 RGB 0.85 보정과 런타임 팔레트 코드는 제거했다. 새 픽셀 경계에 맞춰 버클 중심과 발바닥 피벗을 재확인했으며 고정 행 배율과 12자세 구성은 유지했다.
- [prompts.json](prompts.json): 내장 imagegen의 무기 크기·배경 추출·공격 팔레트·도트 표현 교정 지시.

[selected_walk.py](../../selected_walk.py)의 `SelectedWalk.apply`가 기사·마법사의 `*-walk` 몸체만 이 시트로 바꾼다. 기존 8개 90ms 슬롯의 시간은 유지하고 각 자세를 두 슬롯씩 재생한다(0·0·1·1·2·2·3·3, 전체 720ms). 행 전체에 한 배율을 적용해 프레임별 크기를 바꾸지 않는다. 공격 6종의 몸체·효과·시간·앵커는 변경하지 않는다.

같은 모듈의 `write_header`가 [SelectedWalkData.h](../../../../src/generated/SelectedWalkData.h)를 생성한다. [HeroWalkView](../../../../src/rendering/HeroWalkView.h)는 용사 이동 텍스처를 소유하고 같은 피벗과 고정 배율로 표시한다. C01/C03의 기존 대기는 첫 이동 자세를 사용한다. C02는 실제 경로 이동 중에만 4자세를 반복하고 정지 시 첫 자세, 공격 시 기존 공격 시트를 사용한다. 기존 이동 경로·속도·공격 판정은 바꾸지 않았다.

검 오라가 기존 위치로 돌아가지 않도록 새 기사 이동 칼자루 좌표도 연결했다. 이전 v2 시트는 공격이 참조하므로 보존한다. 생성·교정 중 미채택 시안·중복 미리보기·캐시 60개 파일을 삭제했다(프로젝트 안 24개, 이 채팅의 생성 이미지 캐시 36개). 최종 PNG·좌표·제작 지시만 이 폴더에 보존했다.

검토: 기존 미리보기에서 체크·흰 배경과 반복 재생을 확인했고, 적용 단계에서는 공격 데이터 불변·피벗/배율·이미지 경계·신규 프로젝트 등록·배포 경로를 정적으로 검사했다. 문서 링크 972개에 누락이 없었다. 전체 C++ 경로 검사는 기존 `MageUltimateSwordView.h` 프로젝트/필터 등록 불일치 1건이 남으며, HEAD에도 동일함을 확인했다. 게임 빌드·실행은 수행하지 않았다. 이 선택이 보행 해부학 전체의 완벽함을 검증했다는 의미는 아니다.

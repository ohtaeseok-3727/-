# 미니 스프라이트 미리보기 프레임 분리

SmallKnight/preview.html 및 SmallMage/preview.html의 이동·공격·효과에 공통 padded-frames.js를 적용했다.
미리보기에서 각 프레임을 별도 캔버스로 분리하고 사방 64 원본 픽셀의 투명 여백을 둔다.
공격 시트의 불균일한 가로 경계는 알파 분포를 읽어 조정했다. 원본 좌표 기준으로 배치 오프셋을 보정하므로 캐릭터 크기, 발 기준점, 효과 위치와 속도는 유지한다.

원본 PNG 파일 자체의 크기나 픽셀은 변경하지 않았다. 이 변경은 미리보기 로딩 시 프레임을 분리하는 방식이며 게임용 PNG 재배치 파일을 생성한 것은 아니다.
현재 미리보기가 사용하는 시트에 적용한다. 과거 보관용 시트에는 적용하지 않는다.
파일 및 코드 정적 검토만 수행했다. 게임 빌드와 미리보기 실행은 수행하지 않았다.

# 챕터 1~18 오픈월드 타일 시안

2026-11-11 · 각 챕터의 대표 구역을 숫자 격자로 배치한 도트 타일 시안이다. [챕터별 제작 명세](../../../../../_game_resource_production/08_final/INDEX.md)에서 지형과 장소를 고르고 [공유 리소스 장부](../../../../../_game_resource_production/02_resource_ledger/C03_C18_SHARED_RESOURCES.md)에 따라 석재·야외·지옥 바닥을 재사용했다. 색상, 배치와 32px 원본 크기는 시안의 선택이다.

| 구성 | 수량 및 용도 |
| --- | --- |
| 바닥 | 28종 × 3변형. 변형 간 테두리 픽셀을 일치시킨다. |
| 도로 | 8종 × 15연결. 직선·모서리·갈림길·교차로·끝부분을 포함한다. 숲길과 목교는 같은 폭으로 만난다. |
| 물가 | 15방향 조합. 물 바닥 위에 강둑과 물결을 얹는다. |
| 장식·상태 | 18종. 식생·폐광 레일·그을음·관측 문양·용맥 균열·소유권·봉인 표식을 별도 레이어로 놓는다. |

아틀라스에 타일 237개와 빈 타일 ID `0`이 있다. 각 챕터의 CSV는 18×10칸이며 같은 칸에 바닥 → 물가 → 도로 → 장식·상태 순서로 그린다. `tiles.json`의 도로 `mask`는 북 `1`, 동 `2`, 남 `4`, 서 `8`을 더한 값이다. 예를 들어 동서 직선은 `2 + 8 = 10`이다. CSV에 들어가는 숫자는 방향 합계가 아니라 **아틀라스 타일 ID**다.

미리보기는 [기존 60도 지면 구도](../../../../../docs/architecture/GROUND_VIEW.md)에 맞춰 타일을 화면에서 32×28px로 투영했다. 서로 인접한 오픈월드 구역에 적용할 때는 각 격자에 월드 시작 좌표를 지정하고, 경계에서 같은 폭과 방향의 도로를 연결한다. 챕터 10과 12는 왕정 석판 타일을 공유한다. 챕터 18의 귀환 시안은 챕터 14 CSV 세 장을 그대로 참조하고 봉인 레이어만 교체한다.

[제작 스크립트](../../../../../tools/sprites/build_chapter_tile_drafts.py)는 [챕터별 배치 데이터](../../../../../tools/sprites/chapter_tile_draft_data.py)를 읽고 Pillow로 픽셀 도형을 그려 PNG·CSV·갤러리를 생성한다. 재생성에는 Python, Pillow, Windows 맑은 고딕 글꼴이 필요하다.

```text
python tools/sprites/build_chapter_tile_drafts.py
```

확인 범위는 타일 알파, 도로 접합, 바닥 변형 테두리, 숫자 격자에서의 화면 재현이다. 각 그림은 대표 구역을 비교하기 위한 시안이며 챕터 전체 지도, 설치 좌표, 충돌과 통행 설정은 실제 적용 단계에서 정한다.

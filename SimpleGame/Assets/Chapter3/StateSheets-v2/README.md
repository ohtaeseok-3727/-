[소품 시트](props.png)는 원고·석상 기초·기록판·봉인 상자·운반대·브레이크·보급 수레·승인서 8개다. 최초 소품 출력의 밝은 배경은 내장 이미지 편집으로 제거했다. 최종 7개 PNG는 RGBA이며 실제 alpha=0 픽셀과 모든 셀의 비어 있지 않은 알파 경계·잘림 없음을 검사했다. PNG를 코드로 재색칠·변형·리사이즈하지 않았다.

## 프레임과 재생

- [인물 메타데이터](frames.json), [소품 메타데이터](props.json)는 SHA-256·원본 크기·알파 경계와 피벗을 담는다. 생성 PNG 간격이 완전히 균등하지 않아 투명 간격으로 경계를 구한다.
- [인덱서](../../../../tools/sprites/index_chapter3_atlases.py)는 PNG를 읽기만 하며 [인물 C++ 데이터](../../../src/generated/Chapter3SpriteData.h)와 [소품 C++ 데이터](../../../src/generated/Chapter3PropData.h), 메타데이터·미리보기를 생성한다. 이미지 원본은 변경하지 않는다.
- [Chapter3Sprites](../../../src/chapters/Chapter3Sprites.cpp)는 NPC별 텍스처를 한 번 로드하고 IDLE 4fps·WALK 10fps·공격의 정규화된 예고 진행률에 맞춰 UV를 고른다. 각 NPC 첫 대기 프레임의 높이로 전 프레임의 배율을 고정하고 머리 중심 X·발바닥 Y를 맞춘다. 프레임마다 크기를 맞춰 변형을 감추지 않는다.
- [로컬 재생 미리보기](preview.html)는 같은 메타데이터·고정 배율·피벗을 사용한다. 기존 [인물 기준](../ImageGen-v1/characters-v1.png)과 [용사 기준](../../Characters/Walk/Selected-v3/walk.png)을 직접 대조했다.
- [프롬프트·제작 도구 기록](prompts.json)을 보관한다. 내장 image_gen 사용이며 CLI/API 대체는 사용하지 않았다.

## 실제 검사와 범위

Release x64 빌드와 OpenGL의 88프레임 로드/렌더, 확대 프레임표 6개를 확인했다. 기사·마법사 모두 실제 충돌·도보·포탈·상호작용·기본 공격·패링으로 C03 전체를 자동 완주했다. 주요 5단계의 파일 저장/복원과 별도 프로세스 이어하기, 마법사 세라드전 사망/재도전도 통과했다. 상세 결과와 한계는 [챕터 3 최신 구현 기록](../../../../docs/implementation/CHAPTER_03_IMPLEMENTATION.md)을 따른다.

자동 브라우저 검토는 도구가 현재 URL을 확인하지 못해 중단됐다. HTML의 브라우저 연속 재생을 육안 확인했다고 기록하지 않는다. 게임 렌더러에서 순차 프레임과 전체 진행을 실행하고 원본 시트·확대 프레임표·장면 캡처를 검토했다.

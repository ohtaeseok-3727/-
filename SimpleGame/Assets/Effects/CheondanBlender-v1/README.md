# 천단참 Blender 리메이크 v1 — 2026-10-26

후속 사용자 교정에 따라 현재 시안은 [공통 베기 궤적·거울 파쇄 v2](../CheondanMirror-v2/README.md)다. 이 문서는 이전 시안의 제작·출처 기록으로 보존한다.

사용자 요청: 인터넷에서 화면 파쇄·참격 잔상 스타일을 조사하고 Blender로 기사 궁극기를 새로 제작한다. 기존의 ‘코드로만 제작’ 조건은 이번 이펙트 제작 범위에서 대체한다. 게임 연결은 아직 하지 않았다.

## 제작물

- [Blender 원본](cheondan.blend): 응축, 원호 참격, 지연 잔상, 연결된 사선 균열의 메시·머티리얼·키프레임·카메라.
- [투명 시트](cheondan-atlas.png): RGBA, 2560×1080, 8열×6행, 셀 320×180, 46프레임. 마지막 두 셀은 미사용이다.
- [변환 설정](settings.json): 24fps, 팔레트, 단계별 프레임, 알파 임계값. 1번과 45–46번 프레임은 의도적으로 비어 있다.
- [재생 미리보기](preview.html): 일시정지·프레임 선택·느린 재생·좌우 전환. 배경 격자·건물의 어긋남은 Canvas 시연이며 Blender 원본이나 게임 배경 캡처가 아니다.
- [GIF](../../../../output/cheondan-blender-v1/preview.gif), [단계 비교](../../../../output/cheondan-blender-v1/review.png): 로컬 검토 자료.

인터넷 검색으로 아래 자료를 찾았다. 동영상 본문은 검색 도구에서 프레임 단위로 열리지 않았으므로 정확한 동작 타이밍·특정 프레임을 분석했다고 주장하지 않는다. 이미지 검색의 설명과 검색된 자료를 기반으로 선택한 조형 방향이며 원본 효과 이미지·모델은 복사하지 않았다.

원호가 실제로 회전하며 휘두르기 흔적을 남긴 뒤, 화면 대각선의 어두운 틈과 금빛 가장자리가 남는다. 짧은 가지 균열은 본선에 붙이고, 분리 파편은 만들지 않는다. 이는 기존 [천단참 사선 베기·잔상·균열](../../../../docs/design/11-knight-skills.md)에 맞춘 제작 선택이며 새 밸런스 규칙이 아니다.

## 도트 기준과 확인 범위

캐릭터는 제작하거나 수정하지 않았다. 고정 기준은 [기사 미니 이동 시트](../../Characters/SmallKnight/walk-transparent-v1.png)이며, 불투명 효과 픽셀의 RGB는 이 시트에 실제로 존재하는 여섯 색만 사용한다. 640×360 Blender 렌더를 320×180으로 축소하고 팔레트 양자화·이진 알파로 마감했다. 3D 조명·부드러운 윤곽을 최종 스타일로 사용하지 않았다.

렌더 46장 생성과 패킹을 수행하고, 전체 시트의 실제 RGBA·알파 0/255·참조 팔레트 포함 관계·2–44프레임 비어 있지 않음을 검사했다. 단계 비교 이미지에서 참격·잔상·균열과 기준 시트를 직접 대조했다. 화면 균열 소멸 시 가지가 떨어져 보인 첫 시안은 본선 두께 유지와 가지의 선행 소멸로 교정했다.

게임 빌드·실행, 런타임 연결·판정·프레임 동기화·창 비율별 검증은 수행하지 않았다. 기존 [게임 구현](../../../../docs/implementation/CHEONDAN_ULTIMATE.md)은 그대로이며 시트는 자동 적용되지 않는다. 제작 미리보기의 시간은 약 1.917초이며 게임 시계와 연결할 때 단계별 매핑이 필요하다. 화면 시트는 16:9 기준으로 별도 합성해야 하며 월드 좌표 효과와 같은 배율로 그리지 않는다.

## 재제작

프로젝트 루트에서 Blender 5.2의 `--background --python tools/effects/blender/build_cheondan.py`로 원본·연속 PNG를 만들고, Pillow가 있는 Python으로 `tools/effects/blender/pack_cheondan.py`를 실행한다. 원본 프레임은 `output/cheondan-blender-v1/raw/`에 저장한다. 게임 실행 명령이 아니다.

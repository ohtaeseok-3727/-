# 천단참 거울 파쇄 v2 — 2026-10-26

사용자 교정 요청: 검 휘두름과 화면 자상의 궤적을 자연스럽게 맞추고, 화면이 거울처럼 깨지며 폭발하게 한다. 기존 v1의 서로 다른 원호/사선과 가지 균열 위주 표현을 대체한다. 과거의 ‘분리 파편 없음’ 제약은 이번 요청 범위에서 해제한다.

최신 교정: 화면이 거울처럼 변하는 과정과 거울판 정지 구간을 제거했다. 이제 참격 다음 프레임부터 이미 분리·회전한 조각이 터져 나온다. 파편 자체의 두께·반사 무늬·회전은 유지한다.

## 바뀐 연출

1. 3–10프레임: 베기 시작 방향으로 검기를 응축한다.
2. 11–19프레임: 거대한 검날 끝이 위에서 아래로 휘어지는 하나의 원호를 따라 움직인다. 움직이는 칼끝, 그 뒤의 넓은 참격, 가늘게 남는 자상이 같은 표본 좌표를 사용한다. 자상을 별도의 사선으로 그리지 않는다.
3. 20–24프레임: 같은 곡선 위 잔상이 짧게 남는다.
4. 25–45프레임: 거울판을 미리 덮거나 정지하지 않고, 이미 간격이 벌어진 파편 상태로 곧바로 전환한다. 칼자국 주변의 작은 조각과 바깥쪽 큰 판들이 서로 다른 축으로 회전·확대하며 바깥과 관객 쪽으로 흩어진다. 첫 파쇄 프레임부터 조각 사이로 뒤 배경이 보인다.
5. 46–50프레임: 파편 표시를 종료한다.

분할은 고정 난수의 보로노이 셀을 사용한다. 표면의 넓은 반사 띠와 건물 실루엣은 하나의 거울 면에 이어지도록 각 셀로 잘랐으며, 조각에 붙어 함께 회전한다. 정사영 카메라에서 전방 이동·확대를 함께 사용한 연출이다. 반사 무늬는 Blender 도형이며 실제 게임 화면을 반사한 것은 아니다. 미리보기 배경도 게임 캡처가 아니다.

이 시간·궤적·조각 수·형상은 구현 시안의 선택이며 피해·MP·쿨타임·판정 변경이 아니다. 캐릭터 몸체·공격 동작은 수정하지 않았다. [기사 미니 시트](../../Characters/SmallKnight/walk-transparent-v1.png)의 실제 색에서 은회색·아이보리·금빛을 골라 양자화하고, 최종 효과는 이진 알파와 도트 윤곽으로 변환한다.

## 제작 경로와 확인 범위

프로젝트 루트에서 Blender 5.2의 `--background --python tools/effects/blender/build_cheondan_mirror.py`로 원본·960×540 연속 PNG 50장을 만들고, Pillow Python으로 `tools/effects/blender/pack_cheondan_mirror.py`를 실행한다. 렌더 원본은 `output/cheondan-mirror-v2/raw/`에 보관하며 Git에서 제외한다. 이전 v1 도구의 재질·리본·가시성 함수와 `mirror_geometry.py`의 분할·칼끝 좌표를 재사용한다. 패커는 현재 1–50번 프레임만 읽는다.

검토: 기존 69개 거울 셀의 면적 합 144와 공통 칼끝 곡선을 유지한다. 패커는 RGBA·0/255 알파·기준 팔레트 포함 관계·3–35프레임의 비어 있지 않음과 첫 파편 프레임의 불투명 점유율 80% 미만을 검사한다. 24→25프레임의 직접 전환은 단계 비교에서 확인한다. 실제 수행 결과는 프로젝트 작업 DB에 기록한다.

**게임 미적용**이다. 게임 빌드·실행·GPU 성능·판정·캐릭터 손과의 런타임 부착은 검증하지 않았다. 실제 게임의 움직이는 화면 조각을 구현하려면 별도 화면 텍스처 분할 합성이 필요하며, 이 시트 자체가 게임 배경을 자동으로 복제하지 않는다. 기존 [런타임 구현](../../../../docs/implementation/CHEONDAN_ULTIMATE.md)과 구분한다. 인터넷 참고 자료는 [v1 출처 기록](../CheondanBlender-v1/README.md)의 확인 범위를 따른다.

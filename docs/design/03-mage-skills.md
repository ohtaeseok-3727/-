# 마법사 스킬

## 마법사 추가 액티브 스킬 — 사용자 확정 (2026-09-22)

### 다중 마력검 발사 — 설명용 명칭

- 사용자 확정 수치: 습득 레벨 5, MP 소모 7, 마력검 1개 피해는 `기본 공격 데미지 + INT`이다.

- 여러 개의 마력검을 생성하여 날리는 스킬을 추가한다.
- 마력검 본체는 스프라이트로 제작하지 않고, 검마다 개별 객체로 생성하여 이동시킨다.
- 마력검의 돌진 이펙트는 본체와 분리된 스프라이트로 제작하는 방향이다.
- 검의 개수·생성 위치·외형, 동시 또는 순차 발사 여부, 조준·유도 방식, 속도·사거리·관통 여부는 미정이다.
- 적 관통
- 이동거리 500px
- 5개의 검 생성
- 검들의 배열은 불규칙하게 하고 이동 속도는 최초 미리보기보다 빠르게 한다. 시안에서는 앞뒤·높이를 엇갈리게 배치하고 800px/s에서 1200px/s로 조정한다. 정확한 배치 좌표와 속도는 임시값이다. (2026-09-23 요청)
- 검들의 위아래 간격을 더 좁히며 검끼리 조금 겹쳐도 괜찮다. 미리보기에서는 기존 세로 간격의 약 60%로 줄이며, 정확한 간격은 임시값이다. (2026-09-23 요청)
- 최초 제작 범위는 이미지·발사 미리보기였으며, 2026-09-23 후속 요청으로 두 미리보기 스킬의 실제 게임 연결을 진행한다. `output/mana-swords-v1/preview.html`에서 검 본체를 개별 도형 객체로, 돌진 효과를 별도 투명 스프라이트로 표현한다. 80ms 순차 발사는 비교용 가정이며 확정 설정이 아니다. (2026-09-23)


### 발 구르기 지면 공격 — 설명용 명칭

- 마법사가 발을 세게 구르면 플레이어를 중심으로 땅이 뒤집히면서 피해를 주는 스킬을 추가한다.
- 사용하는 발, 공격 반경, 지면이 뒤집히는 진행 방식과 피해 발생 시점·횟수는 미정이다.
- 지면 연출의 제작 방식과 실제 지형 변경 여부, 넉백·경직 등 추가 효과는 미정이다.
- 지면 연출은 거대한 지면 파편이 위쪽으로 들어올려지는 방식
- 실제 지형 변경은 하지않는다.

### 바람 칼날

- 사용자 확정 수치: 습득 레벨 3, MP 소모 3, 칼날 1개 피해는 `기본 공격 데미지 + INT × 0.7`이다. 레벨 3에서 1개로 시작하고 레벨이 1 오를 때마다 최대 3개까지 증가한다.
- 날아가는 칼날 하나하나가 플레이어 정도의 크기로 보이도록 확대한다. 수직·사선·수평 베기의 형태 차이는 유지하고 플레이어 표시 크기에 연동한다. (2026-09-23 요청)
- 직전 미리보기보다 바람 칼날의 날아가는 속도를 2배 빠르게 한다. 이동거리는 유지하고 미리보기의 도착 시간만 절반으로 줄인다. 정확한 게임 속도는 미정이다. (2026-09-23 요청)
- 바람 칼날 생성 위치를 기존보다 플레이어 앞쪽으로 20px 이동한다. (2026-09-23 요청)
- 칼날의 발사 후 이동 속도를 직전 미리보기 대비 1.5배로 높인다. (2026-09-23 요청)
- 실제로 날아가는 바람의 칼날을 발사한다.
- 첫 번째 바람 칼날과 동일한 모양을 사용하고, 각도만 다르게 하여 화면에 생성하고 이동시킨다. 서로 다른 모양의 칼날을 만드는 이전 해석은 폐기한다. 구체적인 각도는 미정이다. (2026-09-23 수정)
- 세 칼날은 모두 정면으로 곧게 날아간다. 달라지는 것은 이동 궤적이 아니라 수직베기·사선베기·가로베기의 베기 궤적 표현이다. (2026-09-23 확정)
- 첫 번째 베기를 기준으로 각도가 점점 마력칼날 궤적처럼 변하는 표현을 원한다. 화면 평면에서 이미지를 0°·45°·90° 회전한 v3 시안은 사용자 의도와 달라 폐기한다. v4의 베기 면 원근 변형 비율은 시안이며 확정 수치가 아니다. (2026-09-23 수정)
- 두 번째 기울어진 칼날은 더 크게 표시한다. 미리보기에서는 기존 대비 가로·세로 1.25배를 적용하며, 정확한 배율은 구현상 임시값이다. (2026-09-23 요청)
- 세 번째 칼날도 더 크게 표시하고, 첫 번째 칼날은 가로만 늘린다. 미리보기에서는 직전 시안 대비 세 번째는 가로·세로 1.25배, 첫 번째는 가로 1.2배를 적용하며, 정확한 배율은 구현상 임시값이다. (2026-09-23 요청)
- 습득 레벨 기준 1레벨이 상승할때마다 날아가는 바람 칼날의 개수가 상승한다.(최대 3개)
- 바람 칼날의 개수가 상승하면 동시에 날아가는게 아니라, 첫번째 바람칼날이 이동을 시작한 직후 두번째 바람칼날 생성 및 발사, 두번째 바람 칼날 발사 직후 세번째 바람 칼날 생성 및 발사한다.
- 3개의 바람 칼날이 전부 날아갈 때는 같은 모양에 서로 다른 각도가 적용된 칼날이 모두 보인다.

### 공통 제작 조건과 미정 사항

- 바람 칼날과 다중 마력검 미리보기에 플레이어를 포함하고, 두 스킬 모두 기존 `mana-blade-motion-v1.png` 마력칼날 모션을 그대로 사용한다. 원본 8프레임과 프레임 시간을 유지한다. 미리보기 발사 시작은 기존 효과 시작점인 340ms에 맞추며 실제 게임 판정 시점의 확정은 아니다. (2026-09-23 요청)

- 이번에 추가할 두 스킬의 개념을 확정하며, 전체 스킬 목록·개수는 미정이다. 습득 레벨·MP·개별 피해는 위 확정 수치를 따른다. 정식 명칭과 쿨타임 등 나머지 미정 항목은 기존 공통 스킬 규칙을 따른다.

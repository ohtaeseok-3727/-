# 미리보기 스킬 연결

## 2026-09-23 — 미리보기 스킬의 실제 게임 연결

### 디버그 레벨 키 — 사용자 요청 (2026-09-23)

- 키보드 `1`을 누르면 플레이어를 레벨 20으로 설정하여 즉시 스킬을 디버그할 수 있게 한다.
- 입력 충돌 처리: 시작 화면에서 `1`은 기존 마법사 선택과 레벨 20 설정을 함께 수행한다. `2`로 기사를 선택한 경우에도 이후 `1`로 현재 직업의 레벨을 20으로 설정한다.
- 구현 가정: 디버그 설정 시 현재 경험치를 0으로 만들고 HP/MP를 최대치로 회복한다. 직업·장비·퀵슬롯·진행 상태는 유지한다. 빌드 구성에 관계없이 사용할 수 있는 개발용 단축키이며 반복 입력도 정확히 레벨 20으로 설정한다.

### 적용 내용

- 사용자 요청: 바람 칼날 v4와 마력검 사출 v1의 미리보기를 실제 게임에 적용한다. 바람 칼날 원본 PNG와 마력검 돌진 PNG를 바이트 그대로 복사해 사용하고, 마력검 본체는 미리보기의 도형 객체로 유지한다.
- 두 스킬은 기존 마력칼날 8프레임 모션(755ms)을 재생하고 340ms부터 발사한다. 바람은 120ms, 검은 80ms 간격이다. 칼날의 원근 변형·확대·20px 전방 이동, 검 5개의 불규칙한 배열은 최종 미리보기 값을 사용한다.
- 월드 좌표의 개별 발사체가 좌우 정면으로 이동하며 실제 이동 구간에서 적과 충돌할 때 피해를 준다. 근접 공격 판정을 발사체 수만큼 즉시 반복하는 방식은 사용하지 않는다. 처치 시 기존 경험치와 전리품 처리를 사용한다.

### 구현 가정 — 사용자 확정 수치와 구분

- 게임의 마력칼날 모션은 원본 픽셀에 0.42×0.35 배율을 적용한다. 바람 크기·높이는 이 실제 플레이어 배율에 연동하고, 마력검 도형·배열·돌진 효과는 미리보기 플레이어 배율 0.36 대비 같은 비율로 환산한다. 추가 전방 이동 20px과 이동거리는 별도 유지한다.
- 바람의 화면 폭에 따른 이동거리는 900px 미리보기 기준 861.2 월드 단위로 고정한다. 비행시간은 최종 미리보기의 1600/3ms, 속도는 1614.75 단위/초이다. 마력검은 미리보기대로 1200 단위/초, 거리 500을 적용한다.
- 바람도 적을 관통하며 발사체별로 동일 적을 한 번만 맞힌다. 검의 적 관통은 사용자 확정이다. 지형에 막히면 해당 발사체는 소멸한다. 충돌 폭은 보이는 본체 크기를 근사한 상자이며 이미지 알파 단위 충돌은 아니다.
- 기본 어택 데미지는 기존 기본 공격 1타와 같은 공격력+장비 공격 보너스다. INT 계수를 더한 뒤 정수 HP에 맞춰 가장 가까운 정수로 반올림한다. 발사 때의 능력치를 한 번 저장해 각 발사체에 사용한다.
- 기존 임시 쿨타임(바람 2초, 검 5초)을 유지한다. 동작 동안 이동·다른 공격을 제한하고, 발사체는 모션 종료 후에도 남은 거리를 이동한다. 일시정지는 스킬 시간도 정지하며, 귀환·직업 선택·맵 이동·사망·이벤트 조작 잠금에서 남은 발사체를 제거한다.
- 빌드·실행 검증은 사용자 지침에 따라 수행하지 않는다.

# 이야기·몬스터

## 주요 이야기 흐름

1. 플레이어가 용병으로 활동한다.
2. 플레이어가 스스로 네임드 몬스터를 처치하는 업적을 얻는다.
3. 그 이후 매우 강한 존재인 ‘용사’가 찾아와 플레이어를 영입한다.
4. 플레이어는 용사의 길잡이가 되어 함께 활동한다.
5. 플레이어는 용사와 함께 네임드 몬스터들을 처치해야 한다.

- 용사는 강하지만 몬스터 측에도 매우 강한 존재들이 있으며, 이들을 네임드 몬스터라고 부른다.
- 첫 토벌은 위 네임드 던전 진행 방향을 따른다. 구체적 대상·던전 구성과 현재 용사의 이름·성격·능력 등 세부 인물 설정은 아직 미정이다.

## 몬스터 세력

### 적 AI — 사용자 확정 (2026-09-22)

- 적 행동은 FSM(유한 상태 머신)으로 구성한다.
- 플레이어 추적에는 A* 경로 탐색 알고리즘을 사용한다.

### 이번 AI 구현의 가정 — 확정 설정과 구분

- 상태는 대기, 추적, 공격 준비, 재사용 대기, 치유, 지원 비활성, 사망으로 나눈다. 기존 병종별 공격·치유 수치와 보스 다리 부상에 따른 이동 속도를 유지한다.
- 치유병은 기존처럼 제자리에서 아군을 치유한다. 플레이어를 추적하는 근접병·원거리병·그르마에 A*를 적용한다.
- 일반 적 430, 그르마 900의 기존 감지 거리를 유지한다. 감지 범위를 벗어나면 대기하며, 순찰·귀환·추가 어그로 규칙은 확정하지 않는다.
- 24 월드 단위의 8방향 격자를 사용하고, 대각선 모서리 통과를 막는다. 경로의 각 구간과 실제 이동 구간을 기존 맵 충돌 규칙으로 확인한다.
- 성공 경로는 0.45초 뒤 갱신하며 실패는 0.8초 뒤 재시도한다. 업데이트당 최대 2회, 탐색당 최대 4,096개 노드 확장으로 제한한다. 경로가 없으면 정지한다. 수치는 조정 가능한 구현값이다.
- 탐색 범위는 시작점과 목표를 포함하는 사각형에 각 방향으로 384 단위 여유를 둔다. 이 범위를 벗어나는 긴 우회로와 격자가 표현하지 못하는 좁은 길은 경로를 찾지 못할 수 있다.

### 기존 몬스터 설정

- 몬스터에게는 HP와 공격력 스탯만 존재한다.
- 몬스터들의 왕은 드래곤이다.
- 그 왕은 가장 오래된 드래곤이며 ‘아크 드래곤’이라고 불린다.
- 네임드 몬스터들은 아크 드래곤의 수족이다.
- 네임드 몬스터들은 각각 자신의 군단을 거느린다.
- 각 군단은 지휘하는 네임드 몬스터와 동일한 종족으로 구성된다.
- 군단에 속하지 않는 일반 몬스터들도 존재한다.
- 군단은 다양한 형태가 있다.

현재 네임드 몬스터의 종족:

| 종족 | 휘하 군단의 종족 |
|---|---|
| 악마 | 악마 |
| 드래곤 | 드래곤 |
| 오크 | 오크 |
| 사이클롭스 | 사이클롭스 |
| 티탄 | 티탄 |
| 고블린 | 고블린 |
| 배신한 인간 | 배신한 인간 |
| 야수 | 야수 |

- 종족은 나중에 추가될 수 있다.
- 종족별 네임드 수, 군단별 병종과 전술, 네임드 간 관계는 미정이다.
- 아크 드래곤의 전쟁 목적과 최종 직접 대결 여부는 미정이다.

### 챕터 1 고블린 병종 — 사용자 확정

| 병종 | 확정 외형·무기 |
|---|---|
| 일반 고블린 | 갑옷을 입지 않은 상태로 곤봉을 든다. |
| 고블린 워리어 | 일반 고블린보다 크며, 가벼운 갑옷과 검을 사용한다. |
| 고블린 헌터 | 고블린 워리어보다 약간 작으며, 활을 사용한다. |
| 고블린 군단장 | 매우 거대한 체격이며, 육중한 둔기를 사용한다. |

- 이번 확정은 챕터 1의 고블린 병종 외형·무기 범위만 정한다.
- 고블린 군단장의 네임드 여부와 이름·등장 시점은 이번에 정하지 않는다.
- 일반 고블린의 이동 및 공격 스프라이트를 제작한다. 다른 병종의 애니메이션과 전투 수치·역할은 미정이다.
- 일반 고블린의 이동·공격 스프라이트는 현재 시트보다 팔다리를 더 짧게 하고, 플레이어 미니 스프라이트처럼 굵고 큼직한 도트 표현을 사용한다. 이 조정은 일반 고블린에만 적용하며, 다른 고블린 병종이나 다른 종족의 체형 기준을 변경하지 않는다.

### 필드 밀도 보강 — 2026-09-30 구현 조정값

- 사용자 피드백: 필드의 몬스터가 너무 적다.
- 조정 가능한 구현값: 오픈월드 야외 지역마다 최대 12무리, 무리당 일반 근접 몬스터 3마리를 배치한다. 실제 수는 안전한 배치 공간에 따라 줄어든다. 감지 범위는 300으로 설정한다.
- 마을·실내·막힌 지형은 제외하고, 지역 입구 600·상호작용 지점 320·기존 전투 중심 220 단위 주변을 피한다. 무리 간 최소 거리는 320이다.
- 무리 전멸 후 최소 45초가 지나고 플레이어가 배치 중심에서 900~1500 단위 떨어져 있을 때 재생성한다. 기존 스토리 전투는 별도 encounter ID로 유지한다. 위 수치는 사용자 확정 세계 설정이 아닌 구현 밸런스 가정이며 플레이 확인이 필요하다.


### 용사 이동 — 사용자 요청 (2026-09-30)

- 챕터 2 용사도 A*를 사용해 벽을 우회하여 합류한다.
- 구현 조정: 기존 EnemyPathfinder를 재사용하며 성공 경로는 0.6초, 실패는 0.8초 뒤 다시 탐색한다. 경로가 없으면 직진하지 않고 대기한다. 합류 신호는 실제 통행 가능한 연결 통로에 둔다.

### 전투 안내와 필드 오크 난이도 — 2026-10-08 구현 조정값

- 사용자 요청: 목표·상호작용 안내와 공격 판독성을 개선하고 실제 실행으로 몬스터 밀도·난이도를 검토한다. PC 사용 중에는 숨겨진 창에서 자동 플레이·장면 캡처로 검증한다.
- 일반 적 공격 범위·준비 막대와 입력별 장치 안내를 추가한다. 공격 거리·준비 시간·보스 기술 판정은 기존 값을 유지한다.
- 챕터 2 일반 필드 오크 체력은 기존 45에서 스토리 일반 오크와 같은 70으로 조정한다. 배치 상한·무리 수·피해량·인식 거리·재생성 시간은 유지한다. 이는 확정 세계 설정이 아닌 실행 비교용 구현 조정값이다.
- 파일 연결과 자동 플레이 한계는 [전투 안내 개선 기록](../implementation/COMBAT_GUIDANCE_POLISH.md)을 따른다.

### 필드 자동 스폰 수정 — 2026-10-07 구현 조정값

- 사용자 요청: 필드에서 몬스터가 자동으로 스폰되도록 수정한다.
- 좁은 사건 구역만 검사하던 배치 후보를 야외 구역 외곽 320까지 넓히고 80 간격으로 탐색한다. 실내 중심 구역은 제외한다. 실제 충돌·마을·실내·입구 및 지점 보호 거리, 무리 간격과 상한, 재생성 조건은 기존 값을 유지한다. 수치는 구현 가정이며 실행 확인은 미수행이다.


### 스테이지 동선 스폰·순찰 — 사용자 확정 (2026-10-07)

- 몬스터는 스테이지 진행 부분에 생성되어 주변을 순찰하고 플레이어를 발견하면 추격한다. 인식 범위는 지나치게 넓지 않게 조정한다. 직접 디버깅·실행 검증과 성능 최적화를 함께 수행한다.
- 앞선 같은 날짜의 외곽 격자 배치 방식을 대체한다. 야외 진행 도로를 240 간격 이하로 샘플링하고 중심·좌우 48/96 후보에서 무리를 배치한다. 입구 300, 상호작용 지점 120, 스토리 전투 중심 100을 보호하고 무리 간 280 간격을 둔다. 마을·실내·충돌 지형 제외와 지역당 최대 12무리×3마리 상한은 유지한다. 던전·보스의 기존 스토리 생성은 유지한다.
- 일반 근접·원거리 적은 반경 80 안에서 속도의 45%로 순찰한다. 최초 인식 200, 추격 유지 거리 280, 시야 상실 1초, 생성 위치로부터 480 초과 시 복귀한다. 시야는 충돌 지형으로 차단하며 마을 안 플레이어는 새로 인식하지 않는다. 보스·치유병·스크립트 고정 전열은 기존 전용 행동을 유지한다.
- 수치들은 구현 조정값이다. 순찰·추격·복귀와 실제 지도 스폰 회귀 검증을 Release 빌드에서 실행했다. 자세한 결과는 [성능 분석 이력](../performance/PERFORMANCE_ANALYSIS.md)을 참고한다.

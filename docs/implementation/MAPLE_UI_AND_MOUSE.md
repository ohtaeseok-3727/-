# 전체 창형 UI와 마우스 조작 — 2026-11-05

사용자는 메이플스토리 방식의 UI를 **HUD·퀵슬롯·가방·상점·메뉴·시작 화면 등 게임 전체**에 적용하고, 기존 단축키와 함께 마우스 클릭도 지원하도록 확정했다. 이후 **모든 UI를 어두운 색으로 바꾸라**고 정정했다. 현재는 창형 구성·입체 버튼·아이콘 슬롯·하단 자원 바에 다크 테마를 적용한다. 최초의 밝은 패널·주황 제목줄은 아래 다크 테마로 대체했다. 기존 [저장·거래 구현](SAVE_AND_TRADE.md)을 토대로 한다.

## 화면 구성

- 하단에 레벨·지역·HP·MP를 두고 가장 아래에 경험치 바를 배치한다. 짙은 적색 HP와 청색 MP, 남청·차콜 프레임과 패널을 사용한다. 화면이 충분히 넓으면 좌측 위에도 지역·공격력·금화를 표시한다.
- 8개 스킬 퀵슬롯은 하단 자원 바 위에 배치한다. 슬롯 클릭과 기존 키 모두 같은 스킬 사용 경로를 거친다. 슬롯 위에는 클릭·키 사용과 K 등록 안내를 표시한다.
- 가방·상점·스킬·지도·기록·시스템 메뉴를 공통 창·제목줄·X 닫기로 통일한다. 직업 선택·이어하기 버튼, 일시정지·패배 안내와 NPC 말풍선도 어두운 배경·밝은 회색 글자로 통일한다.
- 스킬 창의 세로 위치는 높이에 맞춰 조정하여 최소 표시 높이 570에서도 아래 등록 슬롯이 창에 가려지지 않게 한다. 가방·상점·지도·기록의 기존 최소 표시 크기는 유지하며, 크기가 부족한 경우에도 별도 닫기 버튼은 제공한다.

디자인 참고는 [메이플스토리 공식 인터페이스 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/440)의 자원·퀵슬롯·메뉴 중심 구성이다. 색상·프레임·좌표는 이 게임의 기존 Renderer 도형과 텍스트를 이용한 구현 선택이다.

## 클릭으로 할 수 있는 조작

| 대상 | 클릭 동작 |
| --- | --- |
| 하단 가방·스킬·지도·기록·상점·메뉴 | 해당 창을 연다. 상점의 기존 거리·전투 제한을 적용한다 |
| HP/MP 물약 버튼 | 기존 7/8 사용 경로와 동일하게 물약을 사용한다. 보유량을 표시한다 |
| 저장 버튼 | 기존 F5/메뉴와 같은 수동 저장 경로를 사용한다 |
| 스킬 퀵슬롯 | 등록된 스킬을 사용한다. MP·쿨타임·레벨·행동 상태 검사도 같다 |
| 공격 | 기본 공격을 1회 입력한다. 연속 클릭은 기존 3단 연계 규칙을 따른다 |
| 확인·유지 | 클릭하면 가까운 단서를 확인하고 누른 동안에는 Space 유지와 같은 조작을 전달한다 |
| 가까운 NPC/시설·단서 표식 | 화면상 가까운 지점을 클릭·유지하여 확인한다. 거리 밖 자동 이동은 추가하지 않았다 |
| 귀환 | 기존 B 야영지 복귀 경로를 사용한다 |
| 창 오른쪽 위 X | 열린 창을 닫는다. 확인 화면에서는 실행하지 않고 취소한다 |
| 가방 `<` / `>` | 기존 Page Up/Down과 같은 페이지 이동 |
| 스킬 창 아이콘 → 퀵슬롯 | 기존 마우스 드래그 등록을 유지한다 |
| 상점·장비 가방 | 기존 클릭 구매·판매 및 선택 비교·다시 클릭 착용 |
| 패배·일시정지 | 다시 도전·게임 계속 버튼을 제공한다 |
| 시작 화면·시스템 메뉴 | 직업 선택·이어하기와 저장·불러오기·설정·스킵·종료의 기존 클릭을 유지한다 |

일반 버튼은 같은 항목 안에서 눌렀다가 놓아야 실행된다. 바깥에서 놓기, 창 전환·닫기, 포커스 상실·크기 변경은 누름을 취소한다. 확인·유지와 가까운 지점은 Space처럼 누를 때 한 번 확인하고 유지 입력을 시작하며, 놓을 때 다시 확인하지 않는다. 지점 유지 중에는 최초 지점과 현재 지점의 위치가 같은지도 확인한다. 클릭 유지와 키보드 Space 유지는 게임 갱신에 하나의 유지 입력으로 합친다.

창이 열리면 하단 조작 버튼과 클릭 스킬 사용을 숨겨 모달 창 뒤로 클릭이 전달되지 않게 한다. 창 닫기·가방 페이지·기존 창 내부 입력만 처리한다. 정지·패배에서는 전투·소모품·상호작용 버튼을 비활성화한다. 일시정지 해제는 월드와 앱의 P 정지 플래그를 함께 해제한다.

## 책임과 연결

- [GameUiTheme](../../SimpleGame/src/ui/GameUiTheme.h): 색상·패널·제목줄·버튼·슬롯·자원 막대의 공통 표현.
- [GameUiControls](../../SimpleGame/src/ui/GameUiControls.cpp): 버튼 목록·좌표·상태, 렌더링과 같은 좌표의 클릭 검사, 누름/놓음 및 유지 입력. `std::vector<Button>`을 화면 크기·창·보유 수량 등의 상태가 바뀔 때만 다시 만든다.
- [PrototypeWorldUi](../../SimpleGame/src/app/PrototypeWorldUi.cpp): 창/정지 상태를 UI에 전달하고 `enum class Action`을 기존 저장·거래·전투·메뉴 공개 메서드에 연결한다. `std::exchange`는 재개 요청과 지점 유지 입력을 한 번만 소비한다.
- [PrototypeWorld](../../SimpleGame/src/app/PrototypeWorld.cpp), [SimpleGame](../../SimpleGame/src/app/SimpleGame.cpp): UI 입력을 창 내부 입력보다 먼저 검사하고 포커스·크기·창 전환에서 캡처를 취소한다. 실제 게임 상태의 소유권은 기존 모듈에 둔다.
- [SkillLayout](../../SimpleGame/src/player/SkillLayout.h): 퀵슬롯 표시·클릭·드래그 등록이 공유하는 좌표.
- [UiControlsVerification](../../SimpleGame/src/verification/UiControlsVerification.cpp): 1280×720·960×540·640×480의 버튼 범위·같은 항목 놓음·바깥 놓음·취소·모달 스킬 차단·정지·재도전 및 570~720 높이의 스킬 창/슬롯 분리 검사 소스.

## 아이콘 어두운 색감 보정 — 2026-11-05

사용자가 아이콘이 너무 밝다고 정정하여 스킬·가방 장비·하단 물약 아이콘을 어둡게 조정했다. [SkillView](../../SimpleGame/src/ui/SkillView.cpp)의 파랑·보라·구리색 바탕과 금빛 문양을 낮은 명도로, [InventoryView](../../SimpleGame/src/ui/InventoryView.cpp)의 검날·손잡이·룬 장갑을 건메탈·짙은 가죽·남색으로, [GameUiControls](../../SimpleGame/src/ui/GameUiControls.cpp)의 물약을 짙은 적색·청색 액체와 어두운 병으로 바꿨다. 물약의 흰 반사광도 낮춘다. 기존 창·버튼·상태 바와 아이콘 모양·입력·쿨타임 표시는 유지한다. 구체적인 RGB 값은 구현 선택이다.

수정 RGB와 상대 명도, 색상 호출과 서식을 정적으로 검토했다. 빌드·게임·화면 실행 확인은 수행하지 않았다.

## 전체 UI 다크 테마 — 2026-11-05

사용자의 최신 지시로 아이콘만 어둡게 하던 범위를 모든 UI로 확대했다. [GameUiTheme](../../SimpleGame/src/ui/GameUiTheme.h)의 `Ink`, `Surface`, `Border`, `Text`, `Muted`, `Gold`를 공통 어두운 배경·인셋·테두리와 읽기 쉬운 글자·차분한 강조색으로 정리한다. 창·제목줄·일반/누름/비활성 버튼·퀵슬롯·자원 막대가 이 값을 사용한다.

- [GameView](../../SimpleGame/src/ui/GameView.cpp): 하단 자원 바와 HP·MP·경험치 채움색을 어둡게 조정한다.
- [TitleScreenView](../../SimpleGame/src/ui/TitleScreenView.cpp): 하늘색 시작 배경과 흰 장식을 어두운 남청색 배경·낮은 명도의 장식으로 교체한다.
- [InventoryView](../../SimpleGame/src/ui/InventoryView.cpp), [SkillView](../../SimpleGame/src/ui/SkillView.cpp): 금화 패널·빈/보유 장비 슬롯·선택 테두리·스킬 카드를 어두운 표면에 맞추고 글자 대비를 조정한다.
- [ExpeditionView](../../SimpleGame/src/ui/ExpeditionView.cpp): 목표 표식 배경·지도 바닥과 도로·기록/정지/패배 안내를 공통 팔레트로 맞춘다. 현재 위치·야영지·목표는 작은 구분색으로 표시한다.
- [InteractionBubbleView](../../SimpleGame/src/ui/InteractionBubbleView.cpp): 안내·대사 말풍선의 크림색 바탕을 어두운 배경으로 바꾸고 글자를 밝힌다. 상점·설정은 기존 공통 `Window`/`Button` 연결을 통해 함께 변경된다.

어두운 아이콘의 기존 색조와 클릭·단축키·배치·게임 규칙은 유지한다. RGB/문자 대비와 서식은 정적으로 검토하며 빌드·게임·화면 실행은 하지 않는다.

## 검토 범위

소스 분기·좌표·입력 우선순위·프로젝트 등록·include·문서 링크·서식·공백을 정적으로 검토했다. 프로젝트 지침에 따라 빌드·게임·C++ 회귀 검사 프로그램을 실행하지 않았다. 따라서 실제 화면·폰트·클릭 체감·GPU/프레임 비용을 검증했다고 표시하지 않는다. 실행 확인에서는 각 창의 X·클릭 취소·포션·슬롯 사용·유지 조작·P/포커스 복귀와 작은 창의 안내를 확인해야 한다.

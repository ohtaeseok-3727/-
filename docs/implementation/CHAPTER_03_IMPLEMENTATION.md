# 챕터 3 구현 — 이름 없는 일곱째

2026-10-15 · 브랜치 `codex/chapter3-gameplay`

## 기준과 상태

[최종 스토리](../../_story_scene_production/05_final_chapters/CHAPTER_03_FINAL.md)와 [감독 결정](../../_story_scene_production/04_director_decisions/CHAPTER_03_DECISION.md)을 기준으로 S01~S10의 진행을 추가했다. 기존 [연속 오픈월드](OPEN_WORLD_FLOW.md)에 기념홀·아르겐·봉인 서고 3개 지역을 연결한다. 실제 게임 빌드·실행·회귀 검사는 수행하지 않았다. 아래 내용은 구현된 코드와 정적 검토 범위다.

확정된 이야기와 구현 선택을 구분한다. 엘리안·에드릭·세라드·아르겐은 최종본의 잠정 고유명을 그대로 사용한다. 좌표, 기력·피해량, 이동 속도, 유지 시간, 잠입 경계 거리, 퍼즐의 보급 수량, 추가 보관처 후보와 지급량은 이번 구현 가정이며 새로운 확정 설정이 아니다.

## 시작과 진행

- 일반 플레이: 챕터 2 협곡 구호지에서 피해 보고와 벽화 검토 완료 → 금빛 목표가 기념홀로 변경된다. 구호지 동쪽 길이 기념홀로 이어진다. 먼저 방문한 챕터 3 지역은 탐험할 수 있지만 주요 조사 진행은 잠긴다.
- 지역 단위 이동 경로: 완료 후 챕터 2 벽화 검토 지점을 다시 확인하면 챕터 3으로 이동한다. 챕터 3 출구들도 기존 지역 이동 방식을 지원한다.
- 수동 미리보기: 빌드한 게임을 `--preview-chapter3`로 시작하면 직업 선택 후 기념홀에서 시작한다. 이 경로만 C02 완료·보급 피해 1·피난민 피해 1을 가정한다. C03 진행 조건은 생략하지 않는다. 일반 플레이에서는 실제 C02 결과를 사용한다.
- 수동 회귀 검사: `--verify-chapter3`. 검사 코드는 프로젝트에 등록했지만 이번 작업에서 실행하지 않았다.

## 세라드전·재도전

세라드는 기존 적 시스템에 `minimumHealth = 1`, `scriptedAI = true`로 등록한다. 일반 공격·투사체·범위 궁극기·직접 피해에 모두 같은 체력 하한이 적용된다. 기력 1에서 공격을 멈추며, 브레이크가 내려간 뒤 곁에서 Space를 1초 유지해야 생존 제압된다. 전투 객체를 보상 없이 퇴장시키고 생존 NPC 표현을 남긴다. 적 처치·경험치·전리품으로 세지 않는다.

검격은 0.9초, 쇠뇌는 1.2초 예고한다. 쇠뇌는 예고 시작 위치를 고정하여 회피할 수 있고 세 번째 공격에는 연막 표현이 붙는다. 공격 직전 Space를 새로 누르면 0.28초 패링 창이 생기며 성공 시 세라드 기력 45를 깎고 2초 틈을 만든다. 누른 채 유지하는 것으로 연속 패링할 수 없고 재사용 간격은 0.65초다. 기본 기력 320, 검격 피해 16, 쇠뇌 피해 12는 조정값이다.

운반대가 승강대 끝에 도착하면 해당 저지전을 재설정한다. 플레이어 사망 후 재도전에서도 조사 결과는 유지하고 진행 중 저지전만 다시 시작한다. 다른 C03 지역에서 재도전한 경우 서고의 기존 전투 객체는 서고가 다시 활성화될 때 재설정한다. 지역 재방문 자체는 조사·전투·선택을 초기화하지 않는다. 완료한 보존 작업·추가 보관처 선택·제한 보급 지급은 중복 실행하지 않는다.

## 최종 상태와 한계

`C03_*` 플래그로 실존·반복 삭제·사상 변화·전쟁 전 원정·세라드 생존·원본 회수·분산 보관·증언·왕실 심의·이동 보고·지원 제한·엘리안 해임·에드릭 제재·용사 지휘권 유지·제한 조사 승인·원정 좌표를 전달한다. `C03_WANTED`와 `C03_WAR_ORIGIN_CONFIRMED`는 0이다. C04 콘텐츠는 아직 등록하지 않았으며 완료 후 원정 좌표를 다음 목표로 남긴다.

전용 완성 스프라이트·음성·시네마틱은 만들지 않았다. 인물·장치·연막·공증 출발은 기존 Renderer 도형 표현이다. 기록 비교는 월드 지점 선택·접근·유지 조작이며 별도 문서 확대/드래그 UI는 없다. 용사의 호위대 저지는 고정된 연출 액터이며 별도 집단 전투 AI가 아니다. 제한 보급은 치료 20·금화 10을 1회 지급하고 장비·호송 품목을 표시에서 제거하는 구현이다. 기록 접근 제한은 해당 문서 상호작용의 단계 잠금과 봉인 표시로 표현하며 도시 통행 자체를 봉쇄하지 않는다. 세라드의 연막은 공격 예고를 가리지 않는 시각 효과이며 시야/명중률 시스템이 아니다. 챕터 3 인물·조사·전투의 화면 품질·동선·균형은 실행 확인이 필요하다. 저장/불러오기는 기존처럼 현재 세션 범위다.

정적 확인 대상: C++ 서식, 선언·정의·include와 프로젝트/필터 등록, 지도/객체 ID·목표 연결, 지역/비지역 진행 분기, 체력 하한·중복 보상·재도전 수명, Markdown 상대 링크 및 생성 인덱스. 빌드 성공·회귀 통과·실제 플레이 가능성이나 성능 수치를 검증했다고 주장하지 않는다.

최종 정적 확인 결과: 신규 코드/검사 7개 파일의 프로젝트·필터 단일 등록, Chapter3 메서드 34개의 선언/정의 일치, 상호작용 객체 46개의 고유 ID·지도 배치, include·구분자·상대 링크를 확인했다. 신규 파일과 여정 UI의 서식 검사 및 변경 파일 공백 검사는 종료 코드 0이다. 문서 304개·계층 인덱스 62개 일치 확인을 마쳤다. 회귀 검사 소스에는 일반 세계의 조기 진입 잠금, C02 결과 수신, 잘못된 조사 순서, 비살상 궁극기 피해 하한, 재도전 후 진행, 보존 선행 조건, 중복 보급·보관처 선택, 최종 정치 상태와 지역 등록을 포함했다. 이 검사 소스는 실행하지 않았다.

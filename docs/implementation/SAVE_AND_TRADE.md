# 저장·이어하기와 거래, 시각 보완 — 2026-11-05

사용자는 보완 목록의 2번 저장·이어하기, 4번 전리품 판매·상점 구매, 5번 모션·시각 자산 마감을 요청했다. 아래 조작·상품·저장 정책은 이번 구현 선택이며 새로운 세계 설정이나 최종 밸런스 확정이 아니다. 브랜치는 `codex/save-trade-visual-polish`다.

## 저장과 이어하기

- 게임 중 **Esc → 여정 저장** 또는 **F5**로 현재 수동 슬롯을 덮어쓴다. 자동 저장은 추가하지 않았다. 새 게임을 시작해도 직접 저장하기 전에는 기존 파일을 덮어쓰지 않는다.
- **Esc → 저장한 여정 불러오기**는 현재 진행을 잃는다는 확인 화면을 거친다. 시작 화면의 **Enter** 또는 **이어하기 버튼**으로도 같은 슬롯을 불러온다.
- 저장 위치는 Windows 로컬 앱 데이터 아래 `SimpleGame/Saves/journey-v1.sav`다. 기존 파일은 `.bak`으로 남기고 임시 파일을 완전히 기록한 뒤 Windows 파일 교체를 수행한다. 버전·프로세스 자료형 크기·길이·체크섬을 검증한다. 현재 형식은 동일 게임 버전과 동일 아키텍처에서 사용하는 로컬 저장 형식이다.
- 직업·레벨·경험치·현재 HP/MP·마나 소수 누적·금화·장비·선택 착용·물약·퀵슬롯·쿨타임, 위치·방향·복귀 지점·발견 지역, C01~C03 선택·증거·트리거·보상 수령, 활성/비활성 지역의 적·전리품·재생성·난수 및 챕터 전투 진행을 보존한다.
- 플레이어의 기본 공격·투사체·궁극기와 사망·조작 잠금 연출 중에는 저장을 거절하고 종료 후 저장하도록 안내한다. 적 전투는 저장할 수 있고 적 상태도 복원한다. UI 누름·스킬 드래그·플레이어의 일시적 공격 효과는 저장하지 않는다.
- 파일 복원과 지도·플레이어·퀵슬롯 검사는 임시 월드에서 마친다. 복원된 지역 지도 참조를 현재 월드에 다시 연결하고 준비한 씬을 교환한다. 파일 없음·버전 불일치·손상·잘림은 안내하고 현재 여정을 유지한다.

### 파일 책임

`std::vector`는 적·전리품·장비·경로, `std::array`와 `std::bitset`은 고정 상태와 완료 기록, `std::optional`은 선택 여부를 원래 구조 그대로 보존한다. C++17 `if constexpr`와 가변 템플릿은 필드 종류별 변환을 분리하며, 컬렉션·문자열 길이 제한과 유한한 실수 검사를 적용한다. GPU 자산은 저장하지 않고 기존 로더로 다시 준비한다.

## 거래·장비·소모품

- 시작 마을과 아르겐 입구 야영지 옆에 **보급 상인** 표식을 둔다. 가까이서 **Space** 또는 **T**로 거래하고 **T**로 닫는다. **Esc**는 상점을 닫고 시스템 메뉴로 전환한다.
- 주변 적과 전투·공격·이야기 조작 잠금 중에는 상점을 열 수 없다. 거래 창을 열면 기존 메뉴 규칙에 따라 게임 시뮬레이션을 정지한다.
- 상품·장비를 마우스로 눌렀다가 같은 항목에서 놓으면 구매·판매한다. 보유 금액이 부족하면 금화·물품을 변경하지 않는다. 장비 목록은 페이지로 나누고 판매 후 인덱스를 보정한다.
- **I**의 가방에서 장비를 한 번 클릭하면 현재 장비와 공격력 차이를 보여 주고, 같은 장비를 다시 클릭하면 착용한다. 판매한 장비를 착용 중이었다면 해제하며 남은 장비의 인덱스를 보정한다.
- **7**은 체력 물약, **8**은 마나 물약이다. 생존·일반 조작 중에 사용하며 자원이 가득 찼거나 물약이 없으면 소모하지 않는다. 물약 보유량은 HUD에 표시한다.

다음 값은 [TradeSystem](../../SimpleGame/src/ui/TradeSystem.h)의 **조정 가능한 임시값**이다.

| 항목 | 임시값 |
| --- | --- |
| 체력/마나 물약 가격 | 각각 20 금화 |
| 체력/마나 물약 효과 | HP 50 / MP 30 회복, 최대치 제한 |
| 직업별 상점 장비 | 공격력 보너스 5, 가격 60 금화 |
| 장비 판매가 | 공격력 보너스 × 5 금화 |

가격과 회복량은 사용자 확정 밸런스로 기록하지 않는다. [PlayerInventory](../../SimpleGame/src/player/PlayerInventory.cpp)가 소유권과 금화·물품 변경을, [TradeSystem](../../SimpleGame/src/ui/TradeSystem.cpp)이 거래 창을, [PrototypeWorldTrading](../../SimpleGame/src/app/PrototypeWorldTrading.cpp)이 안전 거리와 물약 효과 적용을 담당한다.

## 시각 보완과 남은 범위

- [SceneRenderer](../../SimpleGame/src/rendering/SceneRenderer.cpp)는 정지 시 기존 승인된 기본 공격 1타의 첫 준비 자세를 사용한다. 이펙트 시작 전 몸체만 표시하며 이동·공격·시전의 기존 우선순위를 유지한다. 기사의 패시브 오라도 같은 준비 자세의 검 위치를 참조한다. 기사·마법사 자산을 선택 이동 시트와 직접 대조했다. 새로운 대기 PNG를 추가한 것은 아니다.
- [Chapter3View](../../SimpleGame/src/chapters/Chapter3View.cpp)의 조사 원고에 제본·필기·완료 표식, 석재에 홈·복원 표시, 수도원 기록에 인장을 보강한다. 기존 Renderer 기반 소품을 보완했으며 새 충돌·진행 규칙을 만들지 않는다.
- **C03 NPC 연속 보행은 미완료다.** 기존 시트의 방향별 단일 자세는 양발 교대 시트가 아니다. 이미지 생성과 국소 수정의 여러 시안은 발 교대·얼굴/장비/팔·픽셀 크기 또는 알파 기준을 충족하지 못해 연결하지 않았다. 기존 망토·장갑·갑옷과 다리가 겹쳐 있는 원본을 직사각형으로 분리하는 방식도 체형과 윤곽을 훼손하므로 적용하지 않았다. 실패 시안은 게임 자산이 아니다.
- 기존 별도 대기 후보 역시 선택 이동 시트와 체형이 다르고, 마법사 후보는 실제 알파가 없는 RGB 이미지여서 연결하지 않았다. 기존 상태 헤더·공격 규칙·승인된 이동 PNG는 유지한다.

## 확인 범위

빌드·게임·C++ 검증 프로그램을 실행하지 않았다. 실제 파일 저장 후 재시작, 장시간 전투 복원, 화면 배치·클릭·동작 체감은 사용자 실행 확인이 필요하다. 소스 연결·명시적인 상태 필드·정지/입력 우선순위·지도 참조 수명·프로젝트 등록·문서 링크·C++ 서식·공백을 정적으로 확인한다.

정적 검사에서 신규 소스 6개·헤더 3개의 프로젝트/필터 단일 등록, C01~C03 상태 구조체 5개의 필드 누락 없음, 변경 C++의 로컬 include와 문서 상대 링크, clang-format 및 git diff --check를 확인했다.

[PersistenceVerification](../../SimpleGame/src/verification/PersistenceVerification.cpp)을 기존 C01 검증 경로에 추가했다. 사용자 슬롯을 쓰지 않는 메모리 왕복으로 두 직업의 성장·완료 플래그·물품·선택 착용·거래 실패·장비 판매 후 인덱스·물약 단일 소비·잘린 아카이브 거절을 검사하도록 작성했다. 검사 소스를 작성한 것이 실행 통과를 의미하지 않는다.

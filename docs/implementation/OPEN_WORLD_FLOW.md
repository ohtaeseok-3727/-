# 연속 오픈월드와 플레이 흐름

2026-10-15 확장: 기존 여섯 지역에 [챕터 3](CHAPTER_03_IMPLEMENTATION.md)의 기념홀·아르겐·봉인 서고를 추가했다. C02 종료 후 C03 목표를 추적하고 구호지 동쪽 연결로로 기념홀에 접근한다. 세계 완료 기준은 C03 제한 현장 조사 승인까지이며, C03 선행 잠금과 미리보기 전제는 해당 구현 문서를 따른다.

## 사용자 요청과 적용 범위

게임 전체 흐름을 재구축하고 맵 이동 방식에서 오픈월드 방식으로 변경한다는 2026-09-28 요청을 반영한다. 마을·숲·폐광·회색벽·협곡·성채를 하나의 월드에 배치하고, 기존 C01/C02 스토리의 단서·구출·협력 전투·선택 결과를 연결했다. 시작 전부터 있던 C02 목표 이동 수정은 별도 지역 검증 경로에 보존했으며, 실제 오픈월드 플레이에서는 목표 선택으로 순간이동하지 않는다.

근거: [월드 기획](../design/02-world-and-player.md), [C01 확정본](../../_story_scene_production/05_final_chapters/CHAPTER_01_FINAL.md), [C02 확정본](../../_story_scene_production/05_final_chapters/CHAPTER_02_FINAL.md).

## 플레이 흐름

1. 직업 선택 후 마을 야영지에서 시작한다. 마법사를 고르는 입력이 디버그 레벨 20 입력으로 연달아 처리되던 동작을 분리했다. 플레이 중 `1` 디버그 기능은 유지한다.
2. 배급소 보수를 받고 농가 전투와 자유 순서 조사를 진행한다. 금빛 방향 안내와 세계 지도에서 다음 단서를 확인한다.
3. 북쪽 길을 걸어 숲으로 들어간다. 외곽 야생지도 걸을 수 있고 마을로 되돌아갈 수 있다. 숲 추적·수송대 구출·폐광 송장으로 주요 사건이 이어진다.
4. 폐광의 정문/배수로·갱도·지휘 구역을 도보로 진행한다. 폐광 외곽 우회로로 북부를 먼저 탐험할 수도 있다. C01 사건은 단서를 갖춰야 진행된다. 용사 연출 중 Space 유지로 시간을 빠르게 진행할 수 있다.
5. 장부 조사와 용사 대화를 마치면 주요 목표가 회색벽 작전으로 바뀐다. 별도 출구 버튼으로 챕터 화면을 전환하지 않는다.
6. 회색벽 정찰 후 협곡으로 걸어간다. 작전 내용을 확인한 다음 봉화탑·작업장·수용소 중 접근한 목표의 대응을 시작한다. 관측소에서 먼저 목표를 지정할 수도 있다. 선택은 우선순위와 위험을 기록하며 플레이어를 옮기지 않는다.
7. 목표를 완료하고 명령서를 조사한 뒤 옛 성채의 진입로·벽화·용사 합류·바르칸 전투를 진행한다. 성채 외곽 귀환로 또는 지나온 길을 걸어 구호지로 돌아간다.
8. 생존자와 손실을 확인하고 탁본을 검토하면 여정 기록에 작전 결과를 표시한다. 창을 닫고 계속 탐험할 수 있다.

`Select → GameSession::Reset → OpenWorld`에서 세계 지형을 한 번 조립한다. 이동 중 `FollowPlayer`는 지역 소유자와 지역별 적·전리품만 바꾸며 월드 지도 revision, 플레이어 위치, 카메라를 초기화하지 않는다. 충돌·지면·장식은 공통 월드 좌표를 사용한다. 기존 챕터 스크립트는 지역 좌표를 사용하므로 세션 경계에서 변환하고, 지역 `LevelMap`의 충돌은 실제 월드 지형으로 위임한다. 충돌 위임 대상은 세션보다 오래 유지되는 `PrototypeWorld::m_Map`이며 지역 간 이동 중 교체하지 않는다.

적과 전리품은 모든 방문 지역에서 같은 렌더 큐에 등록한다. 근접·발사체 공격은 지역별 좌표로 변환해 모든 적 저장소를 검사하므로 경계 양쪽을 공격할 수 있다. 적 ID에 지역별 상위 비트를 배정해 발사체 중복 타격 기록이 다른 지역 적과 충돌하지 않게 했다. 일반 적은 플레이어에서 1500 월드 단위 이내만 갱신하고 먼 적은 대기한다. 전리품도 먼 곳에서는 수명과 자석 이동을 멈춘다. 가까운 미회수 전리품의 기존 120초 수명은 유지한다. 챕터 사건·동행·보스 스크립트는 활성 지역에서 갱신한다.

챕터별 `VisitMap`은 최초 입장과 달리 완료된 전투를 초기화하지 않는다. C02는 세 지역의 전투 상태를 `std::array`에 보관한다. 세계 지역과 동적 데이터는 `std::vector`, 선택적 목표는 C++17 `std::optional`, 세션 챕터 소유권은 기존 `std::unique_ptr`와 `std::unordered_map`을 사용한다. 이동 시 적과 전리품 저장소를 `std::move`하여 매 프레임 복사하지 않는다. 새 외부 라이브러리는 없다.

## 구현 가정과 한계

- 지역 원점·도로 폭·야영지 위치·600 단위 복귀 제한·1500 단위 갱신 반경·목표 접근 거리 420은 조정 가능한 구현값이다. 확정 세계 설정으로 취급하지 않는다.
- 길 밖 지형과 장식은 기존 시드/청크 구조로 계속 이어진다. 저작된 사건·적·NPC 콘텐츠는 현재 여섯 지역에 있으며 무한 퀘스트 생성은 구현하지 않았다.
- 폐광·성채 실내 벽과 스토리 장치의 국소 차단은 유지한다. 성채 차단선이 야생지 끝까지 뻗지 않도록 실내 폭으로 제한했다.
- 현재 기록은 플레이 세션 메모리에 저장된다. 디스크 저장/불러오기와 Chapter 3 본편은 구현되지 않았다. 게임 화면의 여정 기록에도 종료 시 보존되지 않음을 표시한다.
- 환경과 장치의 기존 도형·스프라이트를 재사용했다. 신규 아트 제작과 밸런스 실측은 이 변경에 포함되지 않는다.

## 검증 범위

프로젝트 지침에 따라 **빌드·게임 실행·C++ 검증 실행은 하지 않았다**. 정적 검사에서 C++ 소스/헤더 105개와 로컬 include 240개의 경로·프로젝트 XML 등록, 변경 C++ 40개의 clang-format, 문서 링크 492개, `git diff --check`를 확인했다. 누락 경로·누락 링크·서식 오류는 없었다. 성능 실측은 하지 않았다.

사용자가 빌드한 뒤 `--verify-open-world`로 여섯 지역의 좌표 왕복, 입구, 도로 중심선 통행, 도보 이동 시 revision 보존, 재방문 전투 보존, 주요 목표 유지, 전투 중 귀환 제한, 패배 대기·회복, 전리품/처치 수 보존, 새 게임 초기화, 협곡 선택의 순간이동 제거를 검사할 수 있도록 검증 코드를 추가했다. 이 검증은 아직 실행되지 않았다. 기존 `--verify-chapter1`, `--verify-chapter2-foundation`은 지역 단위 스토리 검증 경로를 유지한다.

사용자 플레이 확인에서는 마을→숲 왕복, 원거리에서 쏜 발사체의 경계 통과, 야영지 등록 후 전투 패배, 지역을 떠났다가 돌아오는 협곡 목표, 성채 진입로와 외곽 귀환로, 마지막 탁본 후 결과 화면을 확인한다. 컴파일 성공·시각 품질·체감 밸런스는 정적 검토만으로 보장하지 않는다.


## 필드 몬스터 보강 (2026-09-30)

[FieldPopulation](../../SimpleGame/src/combat/FieldPopulation.cpp)이 지역별 야외 무리의 배치와 재생성을 담당한다. RegionRuntime이 개체군을 보관하고 EnemySystem의 기존 전투·보상·렌더 경로에 적을 추가한다. 지역 이동에도 무리 재생성 시간이 유지된다. 맵 생성 시 충돌을 검사하며, 게임 중에는 1초 간격으로 최대 12개 무리의 생존 여부만 검사한다. 무리 좌표는 std::array, 제한된 무리 목록은 std::vector로 보관한다. 일반 적의 1500 단위 갱신 반경과 기존 경로 탐색 예산은 유지한다.

배치 수·안전 거리·재생성 시간은 [몬스터 기획의 구현 조정값](../design/05-story-and-enemies.md)을 따른다. 폐광·성채 실내와 보스 결투에 야외 무리를 추가하지 않는다. 지점 보호 거리는 생성 위치 기준이며 추적 중의 적을 강제로 귀환시키지는 않는다. 무한 야생지와 지역 간 추가 연결 도로는 아직 이 배치 대상이 아니다. 기존 회귀 검증에 개체수 상한·충돌·ID 분리·중복 생성·재생성 대기 검사를 추가했으며 빌드와 실행은 하지 않았다.

## 필드 자동 스폰 후보 수정 (2026-10-07)

기존 배치는 사건 구역의 가장자리에서 100 단위 안쪽만 360 간격으로 검사했다. 좁은 야외 구역에 입구·조사 지점 보호 반경이 겹치면 후보가 탈락하고, 이후 Update도 등록된 무리만 재생성하므로 비어 있는 지역을 채우지 못한다.

FieldPopulation::Populate의 탐색 범위를 야외 구역 외곽 320까지 확장하고 후보 간격을 80으로 줄였다. 실제 충돌 검사, 마을·실내·입구·지점 보호, 무리 간 320 간격과 최대 12무리 제한은 유지한다. 실내 중심 구역은 외곽 탐색에서도 제외하여 던전의 무리를 늘리지 않는다. 범위와 간격은 구현 조정값이다. 연결 도로 전체나 무한 야생지 생성은 포함하지 않는다.

회귀 검증에는 합성 맵 외에 실제 마을 외곽·숲·회색벽·협곡의 최초 자동 생성 여부, 개체수 상한과 금지 지형을 확인하는 검사를 추가했다. 빌드·게임 실행·회귀 검증 실행은 하지 않았다.


## 스테이지 순찰 몬스터 (2026-10-07 후속 수정)

앞선 외곽 격자 탐색 대신 FieldPopulation이 야외 진행 도로를 따라 안전한 무리를 생성한다. 순찰·감지 정책은 [EnemyPatrol.h](../../SimpleGame/src/combat/EnemyPatrol.h), 상태 전이·공격·A* 추격 및 복귀는 [EnemyStateMachine.cpp](../../SimpleGame/src/combat/EnemyStateMachine.cpp)가 담당한다. EnemySystem::Add가 생성 위치와 개체별 감지 검사 시차를 초기화한다. 챕터 2 일반 오크의 별도 600 인식 거리도 200으로 조정했다.

고정 순찰 방향은 constexpr std::array로 보관해 프레임별 할당을 피한다. 순찰은 충돌 없는 짧은 구간을 이동하며 막히면 다른 방향을 선택한다. 추격·복귀 경로는 기존 std::vector와 waypoint 인덱스를 재사용한다. 감지 검사는 0.2초마다 수행하고, 복귀 경로는 고정 목적지이므로 성공 시 2초 간격으로 갱신한다. 죽은 적 AI를 생략하고 무리 생존 여부는 초당 한 번 전체 적을 순회해 std::array<bool, 12>에 집계한다. 먼 적의 1500 휴면 반경과 시스템별 프레임당 A* 2회 예산은 유지한다.

SimpleGame의 활성 창 타이머 목표 간격을 4ms, 비활성 창은 100ms로 설정했다. 실제 FPS는 렌더링·드라이버·디스플레이 제한에 따르며 수직 동기화 설정은 바꾸지 않는다. 경과 시간 기반 이동은 유지한다.

검증: Release x64 빌드, --verify-open-world(도로 주변 생성·상한·순찰·근거리 감지·차폐·복귀 포함), --verify-chapter1, --verify-chapter2-foundation을 실행해 통과했다. --benchmark-enemies는 시드 743의 96마리 AI를 1800회 갱신하고 앞 120회를 제외한다. --benchmark-render는 1280×720, 후처리 켜짐, 1200회 고정 dt 자동 이동 후 종료한다. 측정 전용 모드의 종료는 GPU 정리 대기를 피하기 위해 로그 flush 후 _Exit를 사용하며 일반 종료 경로는 유지한다. 자동 화면 측정은 실행 검증이며 사람이 보는 애니메이션 품질 검토를 대체하지 않는다.

## 기록관 실내의 포탈 예외 — 2026-10-20

최신 사용자 요청에 따라 챕터 3 야외 도시는 연속 도보 탐험을 유지하고 기록관 건물만 포탈로 출입한다. 기념홀·공개 열람실·봉인 서고는 `portalInterior`로 자동 도로 연결에서 제외하고 폐쇄 외벽으로 둘러싼다. 공개 열람실 추가로 전체 지역은 10개다. 건물 충돌·세계 좌표 변환·도시 구획·포탈 목표 안내의 책임과 정적 검토 범위는 [챕터 3 도시 구조](CHAPTER_03_CITY.md)를 따른다. 기존 챕터 1·2의 일반 지역 이동을 포탈 방식으로 바꾸지 않는다.

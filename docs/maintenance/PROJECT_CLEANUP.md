## 삭제 기준

- `output/wind-blade-v1`, `v2`, `v3`: 게임·제작 도구에서 참조하지 않는 이전 시안이다. 현재 `wind-blade-v4`를 유지한다.
- `output/procedural-effects-v1`, `procedural-sword-v2`: 후속 `procedural-sword-v3`로 대체된 독립 Canvas 시안이다. 후속 화면의 이전 시안 링크도 제거했다.
- 미리보기 PNG 8개: 런타임 PNG와 SHA-256이 일치하는 복사본이다. HTML·JavaScript가 런타임 정본을 직접 읽도록 수정했다. 이미지 내용은 바꾸지 않았다.
- Python `__pycache__`: 재생성 가능한 캐시를 삭제했다.

현재 코드에서 참조하지 않더라도 제작 원본·팔레트 기준·향후 챕터용 자료일 수 있다. Blender 원본과 변환 도구, 현재 시안, 게임 자산, 외부 라이브러리, 검증 코드, 빌드 산출물과 실행 로그는 유지한다. 모든 미사용 파일을 판별했다는 보장은 아니다.

## 코드 통합과 흐름

[EnemySystem.cpp](../../SimpleGame/src/combat/EnemySystem.cpp)에 `StrikeArea`를 합치고 단일 메서드만 있던 `EnemyAreaAttack.cpp`를 삭제했다. 일반·발사체·범위 공격은 각자의 피격 조건을 확인한 뒤 `ApplyHit`를 호출한다. 이 메서드가 최소 체력 보호, 피격 표시, 일반 AI 중단과 회복 시간을 공통 처리한다. 공격별 처치 위치 반환과 발사체 중복 피격 집합은 기존 호출부에 남는다. 새 STL 기능이나 언어 표준 변경은 없다.

두 미리보기에 복제되어 있던 `MagePlayerMotion`은 [공통 모션 코드](../../output/shared/mage-player-motion.js)로 합쳤다. 마력검과 바람 미리보기는 이 스크립트와 같은 런타임 PNG를 사용한다. 프레임 시간과 발 기준 좌표는 유지한다.

Visual Studio 프로젝트·필터에서 삭제한 소스 등록을 제거했다. 정적 검사에서 발견한 기존 `MageUltimateSwordView.h` 필터 누락도 프로젝트 등록에 맞췄다. 서로 다른 책임의 모듈은 유지한다.

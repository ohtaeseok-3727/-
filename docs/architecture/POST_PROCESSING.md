# 렌더링 결과 기반 후처리

## 구성

월드 도형과 캐릭터 → 전체 해상도 RGBA16F 장면 → 절반 해상도 밝은 영역 추출과
장면 축소 → 가로·세로 가우시안 블러 2회 반복 → 원본 장면과 합성 → UI.

`Renderer::Begin()`이 HDR 장면 버퍼를 연결하고, `FinishWorld()`가 월드 출력을
마친 뒤 후처리한다. 직업 선택 패널, 텍스트와 HUD는 그 이후 기본 화면에 그린다.
장면과 블러 결과를 같은 텍스처에 동시에 읽고 쓰지 않도록 두 버퍼를 교대로 사용한다.

## 효과

- HDR: RGBA16F 부동소수점 버퍼에 1을 넘는 밝기를 보존한다. 모닥불에 높은
  밝기를 부여하여 톤 매핑과 블룸의 차이를 확인할 수 있게 했다.
- 톤 매핑: 노출을 적용한 후 `1 - exp(-color * exposure)`로 SDR 범위에 압축한다.
- 블룸: 임계값을 넘는 밝은 부분만 추출해 번지게 한다. 물리적인 주변 조명이나
  실제 그림자 계산은 아니다. 마법진의 별도 HDR 발광은 아직 추가하지 않았다.
  모닥불의 직접 그리던 반투명 타원 광륜은 제거하고, 불꽃의 HDR 밝기에서만
  번짐을 만든다. 불꽃 밝기도 작게 변화하여 Bloom이 함께 맥동한다.
  Bloom 샘플 간격은 가장자리 블러와 독립적으로 조절한다.
- 비넷: 중앙에서 모서리로 갈수록 부드럽게 어두워진다.
- 가장자리 블러: 화면 중앙은 원본을 유지하고 가장자리 근처에서 흐린 장면과
  점진적으로 섞는다. 중앙 캐릭터의 최근접 픽셀 표시를 유지하기 위한 구성이다.

이 구현은 HDR 중간 렌더링을 SDR 창으로 출력하는 방식이다. HDR10 모니터 출력,
자동 노출, 깊이 기반 피사계 심도나 모션 블러를 구현한 것은 아니다.

## 색 공간

기존 도형과 PNG의 색을 디스플레이 색으로 간주하고 월드 셰이더에서 선형 색으로
변환한다. 선형 HDR 버퍼에서 합성과 블러를 수행하고 최종 합성에서 한 번만
디스플레이 색으로 변환한다. GL_FRAMEBUFFER_SRGB는 끄며 UI는 기존 색을 사용한다.
후처리를 끄면 블룸·블러·비넷·노출·톤 매핑을 건너뛰고 원본 선형 장면을
SDR 범위로 제한해 표시한다. HDR 광원의 과도한 밝기는 이 모드에서 잘릴 수 있다.

## 조작

| 키 | 기능 |
|---|---|
| F1 | 전체 후처리 켜기/끄기 |
| F2 | 블룸 켜기/끄기 |
| F3 | 비넷 켜기/끄기 |
| F4 | 가장자리 블러 켜기/끄기 |
| [ / ] | 노출 0.1씩 감소/증가, 범위 0.1~5.0 |

현재 상태와 노출은 상단 HUD에 표시한다. 설정은 실행 중에만 유지된다.
기본값은 `PostProcessing.h`의 `PostSettings`에서 수정한다.
노출 1.15, 블룸 강도 0.32/임계값 1.0/반경 계수 2.5, 비넷 강도 0.38, 가장자리 블러 강도 0.8은
실행 결과를 보며 조정할 초기값이다. 가장자리 전환 범위는 `PostProcessingShaders.h`에 있다.

## 자원 관리와 실패 처리

창 크기 변경 시 전체/절반 해상도 버퍼를 재생성하고 최소 1픽셀을 보장한다.
종료 시 FBO, 텍스처, 셰이더 프로그램과 VAO를 해제한다.
초기 후처리 초기화 실패는 기존 렌더러 초기화 실패 경로로 종료된다.
실행 중 크기 변경에서 FBO 생성이 실패하면 콘솔에 알리고 직접 렌더링으로
전환한다. 다음 크기 변경 시 다시 생성을 시도한다.

장면 RGBA16F 1장, 절반 해상도 RGBA16F 4장을 사용한다. 짝수 크기 기준
색상 저장 공간은 약 `가로 × 세로 × 16` 바이트이며 드라이버 오버헤드는 별도이다.
1280×720에서는 약 14.1 MiB이다. 블룸과 가장자리 블러가 모두 꺼지거나
F1이 꺼지면 축소·블러 패스를 건너뛴다.

## 사용자 확인 항목

1. F1 전환으로 월드만 달라지고 HUD와 선택 화면 글씨는 선명한지 확인.
2. 모닥불에서 F2 전환으로 번짐이 달라지는지 확인.
   F2를 끄면 불꽃은 남고 주변 빛 번짐은 없어져야 한다. 원형·타원형 광륜이
   별도 도형처럼 보이지 않는지 확인한다. 현재 맵에는 별도 등불 구현이 없으며,
   추후 추가하는 등불도 HDR 광원 픽셀을 같은 Bloom 경로에 전달하면 된다.
3. F3/F4를 각각 전환하여 어두워짐과 흐려짐이 독립적으로 바뀌는지 확인.
4. 중앙의 작은 플레이어가 선명한지, 화면 가장자리에 뒤집힘·검은 테두리가 없는지 확인.
5. [와 ]로 노출을 조절하고 창 크기 변경·최소화·복원 후 화면과 UI를 확인.

에이전트는 소스와 프로젝트 연결을 정적으로 검토했으며, 사용자 지침에 따라
빌드, 게임 실행, GPU 셰이더 컴파일, 렌더링 및 성능 확인을 수행하지 않았다.

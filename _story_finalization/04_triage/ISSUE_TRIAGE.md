## Director Decisions

### I01 — MUST FIX
**Final direction**
- 플레이어 광역 수배: REJECTED.
- 용사 공식 직위/현장 긴급 지휘권 박탈: REJECTED.
- 왕실 심의, 일부 지원 동결, 엘리안 해임, 에드릭 보급 제재: KEEP.
- 제한 현장 조사 승인: CONFIRMED for final continuity.

### I02 — MUST FIX
**Final direction**
왕좌/권능핵과 잔여 왕권을 분리한다.
- 왕좌/핵 파괴 = 현 전선의 지휘·공급·왕 자신의 자발적 권능 이전 종료.
- 귀속이 끊긴 잔여 왕권 = C15~17 OPEN.
- 죽음의 왕이 특수 권능으로 회수 = C18 CONFIRMED.
이 수정은 최종 반전을 더 공정하게 만든다.

### I03 — SHOULD FIX
새 장면 대량 추가 금지. 각 장의 기존 결과 화면/NPC/월드 상태로 플레이어가 ‘무엇을 책임지게 됐는지’를 보여준다.

### I04 — SHOULD FIX
각 조사 장의 대표 동사를 다르게 고정:
C03 보존 / C04 현장 검증 / C05 보존 압박 / C06 신뢰도 분류 / C07 봉인 해제 / C08 예측 깨기.

### I05 — SHOULD FIX
보스 승리 조건을 다양화하고 HUD 목표를 체력보다 임무 중심으로 표현.

### I06 — SHOULD FIX
C12 아크 드래곤 패배 뒤 30~90초 수준의 짧은 후속 플레이로 섬멸 중단과 부상자 보호가 실제 작동함을 확인한 뒤 지옥문 전환.

### I07 — SHOULD FIX
C15=소유권, C16=공급 흐름, C17=충돌 회피라는 대표 루프를 절대 섞지 않는다.

### I08 — SHOULD FIX
C18의 시스템을 단계별로 가르친다.
1. 사령망.
2. 패전권.
3. 게이트 내핵.
최종 단계에서만 세 시스템이 결합한다.

### I09 — SHOULD FIX
‘계승 기술’ → ‘용사 전용 전투 기술’ 또는 개별 기술명.

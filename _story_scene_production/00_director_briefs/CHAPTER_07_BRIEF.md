# CHAPTER 07 — DIRECTOR BRIEF
# 지워진 자

## Chapter Function
백색성에서 제7영웅이 단순한 삭제 피해자만이 아니라 위험한 선택의 주체였음을 검증한다. 자발적 악마 접촉과 검은 문 개방은 확정하되 최종 목적은 OPEN으로 남긴다.

## Start State
- 제7영웅 실존/조직적 삭제/배타주의/야수족 원정은 CONFIRMED.
- 에르가논은 제7영웅의 변화와 백색성 은거를 직접 목격.
- 악마 접촉 여부는 아직 OPEN.

## End State
- 제7영웅의 필체·계약 흔적·개방 장치가 일치해 자발적 접촉과 검은 문 개방이 CONFIRMED.
- 악마 위장 물자와 관측소 좌표 확보.
- 악마도 제7영웅을 이용했다는 정황 확인.
- 최종 의도·운명은 OPEN.

## Mandatory Events
백색성 진입, 필체 대조, 계약 조각 복원, 위장 물자 발견, 검은 문 봉인 전투, 관측소 좌표 획득.

## Character Beats
‘억울하게 지워진 영웅’이라는 단순 해석 붕괴. 삭제 피해와 행위 책임을 동시에 기록한다.

## Setup/Payoff
C03~C06 변화 흔적 PAYOFF. 관측소 좌표와 위장 물자 → C08.

## Guardrails
제7영웅이 모든 전쟁의 단일 원흉이라고 확정하지 않는다. 악마 조작을 면책으로 쓰지 않는다.

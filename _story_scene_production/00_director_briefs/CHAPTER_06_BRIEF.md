# CHAPTER 06 — DIRECTOR BRIEF
# 오래된 용

## Chapter Function
C05에서 확보한 거의 동시 피격 기록을 최초 대규모 결전의 실제 피해와 연결해, 승전 신화가 아닌 상호 파괴에 가까웠다는 사실을 살아 있는 증언과 물증으로 검증한다. 동시에 플레이어와 용사가 “증언은 중요하지만 증언만으로 확정하지 않는다”는 공통 판단 원칙을 완성한다.

## Start State
- 아르카스 정식 회담과 양측 무기 보관 절차는 CONFIRMED.
- 협정 최종 서명·선제 공격·배후는 OPEN.
- 에르가논이 검은 척추 산맥으로 후송된 동일 개체일 가능성은 PROVISIONAL.
- 플레이어는 거의 동시 피격 보고의 공통 시간표를 보유.
- 용사는 승전 신화의 상징이지만 인간 측 기록 조작을 이미 목격했다.

## End State
- 인간/용인족 양측 후송자료가 모두 치명적 손실을 가리킨다.
- 최초 결전은 일방적 승리가 아니라 상호 파괴에 가까웠음이 CONFIRMED.
- 에르가논은 생존한 고대 증언자로 확인되지만, 그의 기억과 해석은 물증과 분리된다.
- 제7영웅의 변화 시기와 백색성 위치 단서를 확보한다.
- 다음 목적지는 백색성.

## Mandatory Events
1. 검은 척추 산맥 봉쇄선을 통과하기 위해 옛 후송지도를 복원한다.
2. 인간 측 후송표와 용인족 측 치료 기록을 독립적으로 확보한다.
3. 두 자료 모두 핵심 전력의 치명적 손실을 가리킨다.
4. 에르가논과 대면한다.
5. 그의 증언을 C05 기록 및 현장 물증과 교차 검증한다.
6. 관계 증명형 통과 장치에서 플레이어와 용사가 서로 다른 역할을 수행한다.
7. 백색성 위치를 확보한다.

## Mandatory Character Beats
- 용사는 “승리했다”는 국가 전승을 직접 내려놓는다.
- 플레이어는 에르가논의 권위나 고령을 사실 보증으로 취급하지 않는다.
- 두 사람은 같은 증거 분류 원칙을 공유한다.
- 에르가논은 제7영웅의 변화를 증언하되 최종 동기를 단정하지 않는다.

## Mandatory Information
- 최초 결전은 양측 모두 핵심 전력이 무너진 상호 파괴에 가까웠다.
- C05의 거의 동시 피격은 실제 대규모 결전으로 이어졌다.
- 제7영웅은 말년에 눈에 띄게 변했고 이후 백색성으로 물러났다.
- 백색성 위치.
- 제7영웅의 악마 접촉 자체는 아직 C06에서 확정하지 않는다.

## Setup
- 에르가논이 본 제7영웅의 변화와 백색성 → C07 PAYOFF.
- 인간/몬스터/용 기억의 편향을 분류하는 습관 → C07~C09.

## Payoff
- C05 에르가논 생존 단서.
- C05 거의 동시 피격 보고.

## Next Chapter Requirement
백색성으로 갈 수 있는 실제 좌표와 접근 조건을 확보하고, “제7영웅이 무엇과 접촉했는가”를 조사할 충분한 동기를 만든다.

## Canon Guardrails
- 제7영웅이 악마와 접촉했다는 결론은 C07까지 보류.
- 에르가논의 해석을 객관적 사실로 승격하지 않는다.
- 최초 결전을 어느 한쪽의 명확한 승리로 묘사하지 않는다.

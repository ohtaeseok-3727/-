# FINAL SCENE PRODUCTION AUDIT
# Chapter 01~18

## 1. Causality
C01 지역 군단 조사 → C02 조직 전쟁 → C03 삭제 기록 → C04 야수족 현장 검증 → C05 아르카스 회담 → C06 최초 결전 → C07 제7영웅/악마 접촉 → C08 악마 관측망 → C09 네 왕/현계 고리 → C10 현재 전쟁 복귀 → C11 후송 → C12 아크 드래곤 제압/악마 교두보 → C13 첫 지옥문 → C14 중심문 규칙/지옥 진입 → C15~17 세 왕 시스템 해체 → C18 죽음의 왕/양핵 폐쇄로 인과가 연결된다.

각 Chapter의 마지막 결과가 다음 Chapter의 직접 목표 또는 접근 조건을 제공한다.

## 2. Character Arc
### Player
생계형 용병 → 선택의 비용을 감당하는 판단자 → 자기 진영의 가해도 같은 기준으로 검증 → 증언/물증/정황을 구분 → 진영 승리보다 생존과 제한 조건을 설계 → 적 개인보다 소유/공급/충돌 시스템을 해체 → 최종적으로 강제 전쟁 구조를 제거하고 전후 선택을 각 진영에 남긴다.

### Hero
국가가 정면 돌파에 쓰던 강력한 전사 → 플레이어의 다른 능력을 인정 → 공식 전승과 자기 체제를 조사 → 권한을 공격보다 철수/후송에 사용 → 자기 진영의 왕까지 멈춤 → 지옥에서 힘을 어디에 쓰지 않을지도 선택 → C18에서 플레이어의 판단을 믿고 예정 사령의 실을 스스로 고정한다.

### Relationship
실력 확인 → 판단 신뢰 → 공동 조사 → 증거 원칙 공유 → 분리 대응과 재합류 → 제한 공격과 시스템 해체 → C18에서 서로 다른 역할이 모두 필요한 동등한 파트너 관계로 완결된다.

## 3. Emotion Rhythm
C01~03: 능력 증명과 호기심.
C04~06: 자기 진영의 과거와 승전 신화 붕괴.
C07~09: 책임의 복잡성, 관측당한다는 불안, 진실만으로 전쟁은 멈추지 않는 현실.
C10~12: 후송과 생존, 자기 진영 권력에 맞서는 결단.
C13~14: 신뢰 대신 검증 가능한 규칙, 돌아올 길을 계산한 위험.
C15~17: 강한 적을 죽이는 것보다 소유·공급·충돌의 구조를 끊는 성장.
C18: 기존 모든 규칙과 관계의 회수.

## 4. Gameplay Variety
주요 경험:
- 추적/폐광/증원망 파괴
- 전장 우선순위 선택
- 기록 잠입/자료 비교
- 구조/기억석/비살상 충돌 차단
- 호송/기록 보존/시간대조
- 지도 복원/피해 자료 대조/비대칭 협동
- 계약/필체/봉인 역차단
- 다중 기록실/예측 파괴
- 계급문/현계 고리/제한 투영
- 후송로/접견 규칙
- 수문/교량/역돌파 호송
- 분단 생존/신호 재합류/비행 제한
- 제한 비공격 공동 전선
- 양핵 계측/귀환 설계
- 소유권 역전
- 공급망 역류
- 충돌 게이지 최소화
- 잔여 왕권 간섭/사자 해방/양핵 동시 폐쇄

‘마을→NPC 설명→잡몹→보스’ 패턴으로 고정되지 않았다.

## 5. Information Discipline
CONFIRMED / PROVISIONAL / OPEN 구분을 유지했다.
특히 다음은 끝까지 과확정하지 않았다.
- 아르카스 협정 최종 서명 여부.
- 제7영웅 최종 목적과 운명.
- 악마가 수백 년 모든 전쟁을 직접 설계했는지.
- 최초 전쟁의 최종 책임 배분.
- 정복/기근/전쟁의 왕 육체 최종 생사.
- 전후 인간/몬스터/야수족/드래곤 관계.

C03 전쟁 전 원정 → C04 야수족 피해 현장.
C04 경계 표식 → C05 아르카스 회담로.
C05 동시 피격 → C06 최초 결전.

C07 관측소 좌표 → C08 소모 관측망.

## 7. Ending Consistency
FINAL_SETTINGS와 일치:
- 죽음의 왕 사망.
- 무덤 왕좌와 현재 사령망 종료.
- 현재 중심 지옥문 네트워크 폐쇄.
- 플레이어와 용사 귀환.
- 외핵 타격과 내핵 지연 절단 쐐기, 복구파 역발동으로 양핵 동시 폐쇄.
- 용사 생존, 후유증 가능성 보존.
- 자동 세계 평화는 확정하지 않음.

## 8. Structural Issues
새로운 CANON CONFLICT 없음.
Story Spine의 주요 사건, 사망/생존, 반전, 복선 위치, Chapter End State를 변경하지 않았다.

## Final Audit Result
Chapter 01~18 장면 제작 구조는 전체 Story Spine과 정합적이다.
후속 단계는 대사 polishing, 레벨/미션 디자인 상세화, 전투 수치 설계, 실제 퀘스트 데이터화로 이동할 수 있다.

# C01–C03 CHECKPOINT

## Emotional Rhythm
- C01: 생존/현장 문제 → 개인 전투 성취 → 군단 물량에 의한 한계 → 동행.
- C02: 첫 공동 작전 → 판단의 비용 → 부분 성공/손실 → 동등한 신뢰 규칙.
- C03: 역사적 의심 → 제도적 충돌 → 진실 확보 → 보존 책임/정치적 대가.

**Assessment:** 상승 방향이 명확하며 감정 기능이 서로 다르다. 수정 필요 없음.

## Gameplay Repetition
- C01 핵심 동사: 추적 / 구출 / 침투 / 증원 차단.
- C02 핵심 동사: 정보 연결 / 우선순위 선택 / 다중 전장 대응 / 협업 보스.
- C03 핵심 동사: 교차 검증 / 비살상 추격 / 잠입 / 기록 보존.

**Assessment:** 동일한 ‘찾고 싸우는’ 골격은 있으나 대표 플레이는 충분히 차별화됨. C04는 조사 연속감을 피하기 위해 야외 현장·양군 충돌 개입을 전면에 둬야 함.

## Relationship Change
C01 서로의 능력 인정
→ C02 실제 판단을 맡기고 반대할 수 있는 규칙 형성
→ C03 같은 조사 원칙을 공유하고 자기 진영 증거에도 적용.

**Assessment:** 관계가 대사 선언보다 행동 비용으로 발전함.

## Information Release
- C01: 몬스터 군단이 조직화됨.
- C02: 일곱째 벽화와 기록 모순.
- C03: 일곱째 실존/삭제/사상 변화/전쟁 전 인간 원정.

**Assessment:** 정보 단계가 자연스럽고 C03에서 전쟁 발단까지 과잉 확정하지 않음.

## Foreshadow
- C01 역할 차이 → C02 payoff 완료.
- C02 벽화 → C03 payoff 완료.
- C03 원정 기록 → C04 setup 정상.
- C02 선택 손실 → C03 배급/피난민 상태로 부분 payoff 완료.

## Escalation
지역 약탈
→ 지역 전장 전략
→ 인간 사회의 제도와 역사 통제.

**Assessment:** 적 규모뿐 아니라 갈등의 종류가 확대됨.

## Risks for C04
1. C03 조사 직후 또 문서 조사 중심으로 시작하지 말 것.
2. 야수족이 ‘진실을 알려주는 현자 NPC’가 되지 않게 할 것.
3. 인간 기록과 야수족 기억을 모두 단일 진실로 취급하지 말고 현장 물증으로 대조할 것.
4. 용사의 현장 긴급 지휘권을 C03 Final 상태와 일치하게 사용할 것.
5. 오늘의 인간-야수 충돌 중단과 과거 책임 규명을 구분할 것.

## Checkpoint Result
PASS.

C04 제작 진행 가능.

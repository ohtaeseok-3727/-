# CHAPTER 04 — SCENE MAP

## S01 — 밀어내러 온 게 아니다

**Type**  
Exploration / Dialogue / Command

**Location**  
로덴 전초촌과 북문 지휘소.

**Characters**  
플레이어, 용사, 주둔대장 하르벤, 부상병·주민.

**Player Goal**  
원정 경로 진입 허가와 현장 표본을 확보한다.

**Immediate Conflict**  
현지 병사와 주민은 용사가 공세를 지휘하러 왔다고 기대한다.

**What Happens**  
현재 야수 습격의 실제 피해를 본다. 용사는 공식 조사 인장을 제시하고 성역 진입 중지, 북문 방어 유지, 실제 조난 신호에만 제한 구조를 서면 명령한다. 플레이어는 아크 드래곤의 흑유리 화염 결정과 발톱 간격 표본을 빌린다.

**Player Does**  
부상병·전사자 묘지·비축고를 확인하고 조사 장비를 받는다.

**Story Function**  
WORLDBUILDING / CHARACTER / PLOT

**Information Gained**  
오늘의 인간 피해도 실제다. 용사의 공식 지휘권은 살아 있다.

**Character Beat**  
용사는 권위를 공격이 아니라 진입 통제에 사용한다.

**Result**  
조사대만 숲에 들어간다.

**Transition**  
수림 경계에서 첫 생물 접촉.

## S02 — 숲은 한 종류의 적이 아니다

**Type**  
Combat / Exploration / Information

**Location**  
수림 경계와 후각 수로.

**Characters**  
플레이어, 용사, 일반 야수, 야수족 척후, 조련 야수.

**Player Goal**  
숲을 통과하며 원정 흔적을 찾는다.

**Immediate Conflict**  
일반 야수와 야수족이 같은 지역에서 공격하지만 행동 방식이 다르다.

**What Happens**  
첫 전투의 덩굴표범은 언어·퇴로 판단 없이 공격한다. 두 번째 교전의 야수족 척후는 부상자를 업고 후퇴하고 포효로 조련 야수만 움직인다. 플레이어가 후각 수문을 열면 일반 야수 추적이 끊긴다.

**Player Does**  
야수 전투, 야수족 교전, 후각 수문 조작. 후퇴하는 야수족은 추격하지 않는다.

**Story Function**  
GAMEPLAY / INFORMATION / CHARACTER

**Information Gained**  
야수와 야수족은 전투 규칙부터 다르다.

**Character Beat**  
용사가 인간군의 관습적 ‘짐승’ 분류를 수정한다.

**Result**  
폐초소로 이어지는 옛 인간 흔적 발견.

**Transition**  
전쟁보다 오래된 초소 조사.

## S03 — 살던 곳

**Type**  
Exploration / Investigation / Encounter

**Location**  
폐초소 → 불탄 거주지.

**Characters**  
플레이어, 용사, 세라크 정찰대.

**Player Goal**  
전쟁 전 인간 진입과 거주지 성격을 확인한다.

**Immediate Conflict**  
인간 기록은 ‘위험 요소 통제’라 부르지만 현장에는 생활 흔적이 남아 있다.

**What Happens**  
폐초소의 연륜·장비 규격·명령서를 C03 원정 연대와 대조한다. 이어 불탄 거주지에서 공동우물, 육아실, 식량 분배 홈, 가족 묘역을 조사한다. 기억석 조각을 회수하자 세라크가 나타나 약탈로 오해한다.

**Player Does**  
현장 조사, 기억석 회수, 세라크와 제한 전투.

**Story Function**  
INFORMATION / GAMEPLAY / TENSION

**Information Gained**  
전쟁 전에 인간군이 들어왔고 이곳은 야수 소굴이 아니라 생활 공동체였다.

**Character Beat**  
플레이어와 용사는 인간 기록의 용어와 현장 상태가 다르다는 것을 인정한다.

**Setup / Payoff**  
기억석과 공명 방향 규칙 Setup.

**Result**  
세라크의 연락병이 일반 야수에게 습격당한다.

**Transition**  
연락병 구조 여부가 대치의 성격을 바꾼다.

## S04 — 돌을 내려놓는 법

**Type**  
Combat / Choice / Dialogue

**Location**  
불탄 거주지 외곽.

**Characters**  
플레이어, 용사, 세라크, 야수족 연락병, 일반 야수.

**Player Goal**  
연락병을 살리고 기억석을 약탈품이 아니라 조사물로 다뤘음을 행동으로 보여준다.

**Immediate Conflict**  
세라크는 기억석 회수를 위해 공격하고, 일반 야수는 쓰러진 연락병을 덮친다.

**What Happens**  
플레이어가 일반 야수를 처치해 연락병을 살린 뒤 기억석을 바닥에 내려놓으면 세라크가 공격을 멈춘다. C03의 문장 탁본을 보여주자 세라크는 같은 문장을 ‘하얀 학살자’ 표식으로 알아본다. 그러나 성역 진입을 허가하지 않고 수비대에 침입 사실을 알리며 후퇴한다.

**Player Does**  
연락병 구조, 기억석 반환, 짧은 대화.

**Story Function**  
CHARACTER / INFORMATION / TENSION

**Information Gained**  
야수족은 제7영웅을 ‘하얀 학살자’로 기억한다. 이것은 야수족의 명칭이며 단독 진실 판정은 아님.

**Character Beat**  
신뢰가 아니라 행동 하나로 전투만 중단된다.

**Result**  
세라크 후퇴, 성역 경계 강화.

**Transition**  
인간 기록과 야수족 기억을 별도 경로에서 비교해야 한다.

## S05 — 두 기록, 한 사건

**Type**  
Investigation / Traversal / Puzzle

**Location**  
서쪽 인간 야영지와 동쪽 선조 묘역.

**Characters**  
플레이어, 용사.

**Player Goal**  
인간 명령서와 야수족 기억석의 공통 사건 순서를 검증한다.

**Immediate Conflict**  
양측 기록의 언어와 목적이 달라 직접 일치하지 않는다.

**What Happens**  
서쪽에서 네 단계 인간 명령과 보급표를 확보한다. 최종 친필에는 ‘비전투 거주자와 그 흔적까지 남기지 말라’는 제7영웅 개인 지시가 있다. 동쪽에서는 계절·가족수·출발·화재 기준석을 먼저 배우고, 기억석 층위·마모·매장 위치로 사건 순서를 정렬한다. 공명 방향의 기본 원리도 이 구간에서 학습한다.

**Player Does**  
명령서 연대 비교, 권양축 수리, 기억석 정렬, 음각 반향으로 낙석길 통과.

**Story Function**  
INFORMATION / GAMEPLAY / REVELATION / SETUP

**Information Gained**  
강제 추방·흔적 말소가 CONFIRMED. 기억석의 감정·동기는 관점 기록으로 남긴다.

**Character Beat**  
용사는 자기 진영의 영웅 명령도 같은 증거 기준으로 받아들인다.

**Result**  
옛 전장으로 가는 길 개방.

**Transition**  
용흔과 퇴각선 조사.

---

## S06 — 용이 향한 방향

**Type**  
Investigation / Tension / Signal Failure

**Location**  
옛 전장과 용흔 절벽.

**Characters**  
플레이어, 용사, 부상당한 인간 순찰 전령.

**Player Goal**  
아크 드래곤 공격 방향과 현재 인간 구원대 상황을 확인한다.

**Immediate Conflict**  
과거 흔적을 조사하는 동안 현재 야수족이 인간 조난 신호를 이용해 순찰대를 매복시킨다.

**What Happens**  
발톱 자국, 흑유리 화염 결정, 인간 장비 비산선, 숲 밖을 향한 퇴각선을 대조해 아크 드래곤이 인간군을 숲 밖으로 밀어냈음을 확정한다. 동시에 부상 전령이 도착해 인간 구원대가 매복로로 들어오고 있다고 알린다. 플레이어가 신호기를 수리하지만 포효 중계가 신호를 덮는다.

**Player Does**  
현장 흔적 대조, 전령 응급처치, 신호기 수리.

**Story Function**  
PAYOFF / TENSION / INFORMATION / PLOT

**Information Gained**  
아크 드래곤의 공격자·방향은 CONFIRMED, 보호 의도는 OPEN.

**Character Beat**  
두 사람은 과거 진실보다 현재 충돌 중단을 우선해야 하는 상황으로 이동한다.

**Result**  
인간 구원대와 야수족 수비대가 중앙 성역으로 수렴 중.

**Transition**  
가르칸이 성역에서 용사를 먼저 제거하려 한다.

## S07 — 오늘의 적

**Type**  
Dialogue / Pre-boss Tension

**Location**  
중앙 성역 외문.

**Characters**  
플레이어, 용사, 가르칸, 세라크, 야수족 수비대, 멀리 인간 구원대.

**Player Goal**  
전투 전 현재 양군 충돌을 피할 여지가 있는지 확인한다.

**Immediate Conflict**  
가르칸은 과거 기록을 인정하더라도 오늘 인간군이 다시 숲에 들어오고 있다는 사실을 더 중요하게 본다.

**What Happens**  
플레이어가 명령서와 기억석을 제시하지만 가르칸은 그것이 오늘의 침입을 무효화하지 않는다고 말한다. 인간 구원대 불빛이 가까워지고 포효 중계기가 가동된다. 가르칸은 용사를 인간 최대 전력으로 판단해 전투불능으로 만들기로 한다.

**Player Does**  
증거 제시, 전장 구조 관찰.

**Story Function**  
CHARACTER / TENSION / PLOT

**Information Gained**  
과거의 진실과 오늘의 적대는 별개로 남을 수 있다.

**Character Beat**  
가르칸을 ‘진실을 몰라 싸우는 인물’로 만들지 않는다.

**Result**  
보스전 시작.

**Transition**  
포효 중계기와 수문을 활용한 전투.

## S08 — 백아장 가르칸

**Type**  
Boss Combat / System Payoff / Command

**Location**  
중앙 성역, 공명 기둥, 수문, 범람로.

**Characters**  
플레이어, 용사, 가르칸, 야수족 수비대, 제한 인간 구원대.

**Player Goal**  
가르칸을 죽이지 않고 전투불능으로 만들고, 인간군과 야수군의 오늘 충돌을 중단한다.

**Immediate Conflict**  
가르칸은 용사를 집중 제압하고 포효 중계기로 조련 야수를 부른다. 인간 구원대도 외곽에 도착한다.

**What Happens**  
Phase 1: 플레이어가 공명 방향을 읽어 첫 중계기를 역류 파손.
Phase 2: 용사 보장 저지 뒤 두 번째 중계기 파괴, 조련 야수 이탈.
Phase 3: 인간 구원대와 야수족 후위가 충돌하는 동안 플레이어가 수문 방향을 조정한다. 용사가 가르칸을 고정하고 플레이어가 백아 갑주 3곳을 파괴한다. 마지막으로 플레이어가 수문 고정핀을 박는다.
용사는 인간측 단상에 올라 공식 인장 깃발과 철수 나팔을 직접 사용한다. 인간군이 후퇴를 시작한다. 수로 과부하로 중앙 바닥이 붕괴해 양측 단상이 분리된다. 가르칸은 야수측 단상으로 추락해 전투불능이 된다.

**Player Does**  
공명 판독, 중계기 파괴, 수문 조작, 갑주 파괴, 최종 고정핀 입력.

**Story Function**  
GAMEPLAY / CHARACTER / PAYOFF / CONSEQUENCE

**Information Gained**  
용사의 현장 지휘권이 실제로 인간군 철수에 작동한다.

**Character Beat**  
용사는 공격 명령이 아니라 철수 명령으로 권위를 행사한다.

**Result**  
오늘의 충돌 중단. 가르칸 생존.

**Transition**  
세라크가 가르칸을 회수하고, 범람으로 열린 최심부 기억실이 드러난다.

## S09 — 내려놓은 무기

**Type**  
Exploration / Dialogue / Exit Hook

**Location**  
최심부 기억실과 갈라진 단상.

**Characters**  
플레이어, 용사, 건너편 세라크·가르칸.

**Player Goal**  
최심부 흔적을 기록하고 다음 조사 방향을 정한다.

**Immediate Conflict**  
양측은 물리적으로 분리돼 있고 적대는 유지된다. 누구도 화해를 선언하지 않는다.

**What Happens**  
세라크가 가르칸을 회수한다. 가르칸은 아크 드래곤이 야수족을 살리러 왔다는 계승 기억을 말하지만 플레이어는 이를 ‘야수족의 믿음’으로 기록한다. 최심부에는 인간 인물과 용 문장, 내려놓은 무기, 서로 다른 인간 측/용 측 경계 표식이 있다. 플레이어가 두 표식의 탁본을 뜬다. 마모 방향은 북동쪽 후보만 가리킨다.

**Player Does**  
탁본 2장 확보, 마모 방향 비교.

**Story Function**  
INFORMATION / FORESHADOW / CHARACTER / EXIT HOOK

**Information Gained**  
과거 비전투 접촉 가능성을 시사하지만 정식 회담 여부는 아직 OPEN.

**Character Beat**  
플레이어는 ‘회담이었다’고 쓰지 않는다.

**Result**  
북동 후보 방향과 탁본 두 장 확보.

**Transition**  
C05에서 현장 제단과 두 탁본을 대조해 아르카스 회담로를 검증한다.

# CHAPTER 02 — SCENE MAP

## S01 — 성문 앞의 정답

**Type**  
Dialogue / Exploration / Gameplay / Hybrid

**Location**  
회색벽 요새 작전실과 성벽.

**Characters**  
플레이어, 용사, 요새 지휘관, 정찰병.

**Player Goal**  
그르마 장부에 적힌 오크 이동을 확인하고 요새 방어 계획에 참여한다.

**Immediate Conflict**  
요새 지휘관은 대군의 발자국을 보고 정면 공격을 확신하며 용사에게 성문 방어를 요구한다. 플레이어는 병력 규모와 목표가 맞지 않는다고 느낀다.

**What Happens**  
용사는 정식 총사령관이 아니므로 현지 지휘관의 요청을 듣는다. 플레이어는 성벽에서 보이는 흔적과 그르마 장부의 수송 기록을 비교한다. 지휘관은 플레이어를 보조 용병 정도로 대한다.

**Player Does**  
작전실 장부 확인, 성벽 관찰, 첫 조사 지점 선택.

**Story Function**  
PLOT / CHARACTER / INFORMATION / TENSION

**Information Gained**  
오크가 실제로 많기는 하지만 요새 공격에 필요한 물자 규모가 이상하다.

**Character Beat**  
두 사람은 처음으로 다른 군대의 지휘 체계 안에서 함께 움직인다. 용사는 플레이어를 소개하되 대신 판단을 말해주지 않는다.

**Setup / Payoff**  
‘성문을 지키면 된다’는 단순 정답이 이후 미끼로 뒤집힌다.

**Result**  
플레이어가 외곽 흔적을 직접 조사할 짧은 시간을 얻는다.

**Transition**  
대군 도착 전에 주변 초소와 이동 흔적을 확인해야 한다.

## S02 — 만들어진 대군

**Type**  
Investigation / Exploration

**Location**  
파괴된 감시초소, 요새 앞 다리, 버려진 수레길.

**Characters**  
플레이어, 용사 동행 AI 일부 구간, 사망한 정찰병 흔적.

**Player Goal**  
대군이 실제 공성군인지 확인한다.

**Immediate Conflict**  
발자국 수만 보면 대군이 맞지만 다른 군수 흔적이 맞지 않는다.

**What Happens**  
점령되지 않은 초소, 같은 부대가 왕복한 발자국, 빈 수레, 부족한 사료와 공성 장비를 확인한다. 정찰병 시체에서 왕의 협곡 통과 일정표 일부를 얻는다.

**Player Does**  
현장 비교, 발자국 방향 확인, 일정표 회수.

**Story Function**  
INFORMATION / GAMEPLAY / CHARACTER

**Information Gained**  
‘병력이 많다’와 ‘요새를 점령할 준비가 됐다’는 다른 사실이다.

**Character Beat**  
용사는 플레이어의 의심을 무시하지 않지만 아직 정면 위협도 실제라고 본다.

**Setup / Payoff**  
협곡 일정표는 S04에서 그르마 장부·봉화 방향과 결합된다.

**Result**  
플레이어는 미끼 가능성을 제기하지만 진짜 목표는 아직 모른다.

**Transition**  
오크 대군이 실제로 요새 앞에 나타나 조사 시간이 끝난다.

## S03 — 끝낼 수 있는 적

**Type**  
Combat / Character / Choice Pressure

**Location**  
회색벽 요새 전면 방어선.

**Characters**  
플레이어, 용사, 요새 병사, 오크 미끼 부대, 신호병.

**Player Goal**  
요새 전면 공격을 저지하면서 적 지휘 구조를 확인한다.

**Immediate Conflict**  
용사는 정면 병력을 실제로 무너뜨릴 수 있다. 그러나 플레이어는 지휘관급·공성대가 없고 신호병이 뒤로 빠지는 것을 발견한다.

**What Happens**  
용사가 전면 방어선을 깨는 동안 플레이어는 측면의 신호병과 지휘 표식을 추적한다. 후퇴 신호병이 왕의 협곡 방향으로 봉화를 올린다. 용사는 지금 추격하면 전멸시킬 수 있다고 말한다. 플레이어는 미끼일 가능성을 근거로 추격 중지를 요구한다.

**Player Does**  
측면 신호병 차단, 지휘 표식 조사, 마지막 봉화 방향 확인.

**Story Function**  
CHARACTER / GAMEPLAY / PLOT / TENSION

**Information Gained**  
이 부대에는 실제 공성 지휘관과 장비가 없다. 누군가 협곡 쪽에 신호를 보냈다.

**Character Beat**  
용사가 플레이어의 판단을 처음으로 실제 전장에서 따른다. 비용은 ‘끝낼 수 있는 적을 놓치는 것’.

**Setup / Payoff**  
적이 플레이어의 판단을 위협으로 인식하게 되는 첫 명확한 계기.

**Result**  
두 사람은 요새를 떠나 협곡 쪽으로 방향을 튼다. 지휘관은 전장 이탈을 비난한다.

**Transition**  
봉화가 올라간 시각과 일정표를 맞추면 협곡에서 그날 지나가는 대상이 드러난다.

## S04 — 성 밖의 사람들

**Type**  
Investigation / Urgency / Planning

**Location**  
요새-협곡 연결 도로의 임시 관측 지점.

**Characters**  
플레이어, 용사, 연락병.

**Player Goal**  
바르칸의 실제 목표를 확정한다.

**Immediate Conflict**  
정보가 흩어져 있고 시간이 없다.

**What Happens**  
플레이어가 그르마 장부의 오크 물자 이동, 정찰병 일정표, 봉화 방향을 한 지도에 겹친다. 같은 시각 협곡에는 겨울 식량 수레, 전선 증원병, 부상자, 피난민 호송대가 지나간다.

**Player Does**  
지도 정보 조합. 우선순위 선택 화면의 전제가 여기서 열린다.

**Story Function**  
PLOT / INFORMATION / CHARACTER

**Information Gained**  
바르칸의 목표는 요새가 아니라 동부를 겨울 동안 고립시키는 것.

**Character Beat**  
용사는 “성을 지키면 이긴다”는 기존 목표를 즉시 버리고 협곡으로 향한다.

**Result**  
왕의 협곡 긴급 작전이 시작된다.

**Transition**  
협곡에 도착하면 이미 세 곳에서 동시에 공격이 진행 중이다.

## S05 — 세 개의 불

**Type**  
Choice / Gameplay / Multi-objective Hybrid

**Location**  
왕의 협곡 전역: 봉화탑, 공성 작업장, 포로 수용소.

**Characters**  
플레이어, 용사, 인간 호송대, 피난민, 오크 부대.

**Player Goal**  
세 목표의 우선순위를 정하고 최대한 많은 피해를 줄인다.

**Immediate Conflict**  
모든 목표를 완벽하게 해결할 시간이 없다.

**What Happens**  
세 작전이 동시에 열린다.
- 봉화탑: 먼저 끊으면 최종전 정예 증원 감소.
- 공성 작업장: 먼저 처리하면 교량 붕괴 범위와 보급 손실 감소.
- 포로 수용소: 먼저 처리하면 생존자가 늘고 성채 우회로를 얻음.

첫 선택 후 나머지 두 목표는 진행 상태가 악화된다. 두 번째 처리 뒤 세 번째는 완전한 성공이 불가능하지만 최소 피해는 줄일 수 있다.

**Player Does**  
목표 순서 선택, 각 구역의 서로 다른 플레이 수행. 용사는 일부 구간에서 병력을 붙들고 플레이어가 핵심 장치를 처리하도록 공간을 만든다.

**Story Function**  
CHOICE / GAMEPLAY / CHARACTER / CONSEQUENCE

**Information Gained**  
바르칸은 ‘무엇을 구해도 다른 곳이 무너지는’ 전장을 설계했다.

**Character Beat**  
플레이어는 처음으로 자기 판단이 구체적인 손실 분배가 되는 부담을 진다.

**Setup / Payoff**  
선택 결과는 S08 보스전 조건과 S09 후속 상태에 남는다.

**Result**  
세 곳 모두 최소한의 대응은 이루지만 교량/보급/생존자/증원 중 일부 손실이 발생한다.

**Transition**  
살아남은 지휘병 또는 포로가 바르칸이 옛 성채에서 작전을 지휘한다고 알려준다.

## S06 — 지워진 자리

**Type**  
Exploration / Foreshadow / Infiltration

**Location**  
점령된 옛 인간 성채와 예배당.

**Characters**  
플레이어, 용사, 잔존 오크 경비.

**Player Goal**  
바르칸 지휘실로 침투한다.

**Immediate Conflict**  
진입 경로가 선택 결과에 따라 달라지고, 성채 내부에는 아직 작동 중인 폭파 장치가 있다.

**What Happens**  
급수로 / 피난민이 알려준 예배당 통로 / 손상된 성벽 중 가능한 경로로 진입한다. 예배당에서 최초 전쟁 직후 벽화를 발견한다. 귀환 인물은 일곱 명인데 한 인물의 얼굴과 이름만 후대 도구로 긁혀 있다. 그 인물은 쓰러진 이종족 전사에게 손을 내밀고 있다.

**Player Does**  
성채 침투, 잔존 장치 해제, 벽화 탁본 또는 조각 확보.

**Story Function**  
FORESHADOW / INFORMATION / EXPLORATION / CHARACTER

**Information Gained**  
공적 전승의 ‘일곱 영웅’과 실제 알려진 여섯 이름 사이에 의도적인 삭제가 있다.

**Character Beat**  
용사도 자신이 배운 전승의 모순을 처음 명확히 자각한다.

**Setup / Payoff**  
Chapter 3의 제7영웅 조사 Setup.

**Result**  
벽화 증거를 확보하지만 지금은 바르칸 작전을 막는 것이 우선이다.

**Transition**  
성채 깊은 곳에서 대규모 전투음과 폭파 준비 신호가 동시에 발생한다.

## S07 — 이기지 말고 빠져나와

**Type**  
Combat / Split-pressure / Character

**Location**  
성채 내부 두 연결 구역.

**Characters**  
플레이어, 용사, 바르칸의 정예병, 갇힌 피난민, 폭파병.

**Player Goal**  
용사가 적의 고정 전투에 묶이지 않도록 우회로를 열고 합류한다.

**Immediate Conflict**  
바르칸은 용사에게 끝없이 싸울 병력을 던지고, 플레이어 쪽에는 구조·폭파·명령서 단서를 서로 다른 방향에 배치한다.

**What Happens**  
용사는 적을 이기고 있지만 전진하지 못한다. 플레이어는 한 구역을 완전히 해결하는 대신 우회로 개방에 필요한 장치와 사람을 우선 처리한다. 용사가 자신이 ‘막힌 것이 아니라 붙잡힌 것’임을 알아차린다.

**Player Does**  
폭파선 차단, 우회문 개방, 피난민 최소 구조. 용사에게 합류 신호를 보낸다.

**Story Function**  
CHARACTER / GAMEPLAY / PAYOFF / TENSION

**Information Gained**  
바르칸의 목표는 용사를 죽이는 것이 아니라 계속 싸우게 만드는 것.

**Character Beat**  
Chapter 1의 관계가 뒤집힌다. 이번에는 플레이어 판단이 용사를 적의 의도에서 빼낸다.

**Dialogue Beat**
용사:
“놈들이 날 막는 게 아니야.”

플레이어:
“여기서 계속 싸우게 만드는 거야.”

용사:
“그러면?”

플레이어:
“이기려고 하지 마. 빠져나와.”

**Result**  
용사가 전멸 가능한 적을 남기고 우회로로 이탈해 플레이어와 합류한다.

**Transition**  
두 사람이 처음으로 바르칸에게 함께 도달한다.

## S08 — 철혈 장군 바르칸

**Type**  
Boss Combat / Hybrid

**Location**  
옛 성채 중앙 교량 제어구역.

**Characters**  
플레이어, 용사, 바르칸, 선택 결과에 따른 정예 증원.

**Player Goal**  
바르칸을 격파하고 남은 교량 폭파를 최소화한다.

**Immediate Conflict**  
바르칸은 중장갑, 봉화, 폭파 장치, 퇴로 차단으로 전장을 계속 자신에게 유리하게 바꾼다.

**What Happens**  
용사가 바르칸 정면 방어를 깨고 플레이어는 봉화·폭파선·증원 지휘관을 차단한다. S05 선택 결과가 난이도와 지형에 반영된다. 마지막에는 플레이어가 퇴로를 닫아 바르칸을 고립시키고, 용사와 플레이어가 연속 행동으로 결정타를 만든다.

**Player Does**  
전장 이동, 장치 차단, 증원 통제, 마지막 퇴로 봉쇄.

**Story Function**  
PLOT / GAMEPLAY / CHARACTER / CONSEQUENCE

**Information Gained**  
바르칸의 전략은 선택을 없애는 것이 아니라 모든 선택에 손실을 붙이는 것.

**Character Beat**  
두 사람은 서로 역할을 지시하는 것이 아니라 상황에 맞춰 맡는다.

**Setup / Payoff**  
C01의 역할 차이가 완전한 공동 전투로 payoff.

**Result**  
바르칸 격파. 그러나 공성 작업은 일부 완료돼 교량 한 구간은 반드시 무너진다.

**Transition**  
전투 후 살아남은 사람과 손실 규모를 직접 확인한다.

## S09 — 완전하지 않은 승리

**Type**  
Exploration / Dialogue / Consequence / Exit Hook

**Location**  
왕의 협곡 임시 구호지와 손상된 교량.

**Characters**  
플레이어, 용사, 피난민, 요새 지휘관/연락병.

**Player Goal**  
작전 결과를 확인하고 다음 목표를 정한다.

**Immediate Conflict**  
승리했지만 선택에 따른 손실이 실제로 남아 있다. 군은 두 사람의 전장 이탈을 문제 삼고, 생존자는 협곡 개입의 이유를 증언한다.

**What Happens**  
플레이어가 구출 인원, 남은 보급 수레, 교량 상태를 직접 돌아본다. 요새 지휘관은 즉시 영웅 대우하지 않는다. 용사는 Chapter 1의 구조 관계를 언급하고, 둘은 앞으로 판단을 한쪽에 떠넘기지 않는 규칙을 만든다. 이후 벽화 탁본을 다시 펼쳐 ‘일곱인데 이름은 여섯’이라는 모순을 확인한다.

**Player Does**  
결과 상태 확인, 벽화 증거 조사.

**Story Function**  
EMOTION / CHARACTER / CONSEQUENCE / FORESHADOW / EXIT HOOK

**Information Gained**  
작전 승리와 별개로 동부 배급은 줄어든다. 벽화의 삭제는 우연한 파손이 아니다.

**Character Beat**  
용사와 플레이어의 동등한 협력 규칙이 확정된다.

**Dialogue Beat**
용사:
“이번에는 네가 날 빼냈어.”

플레이어:
“처음부터 빚진 적 없어.”

용사:
“그 말도 맞네.”

잠시 후.

용사:
“다음 판단도 먼저 말해.”

플레이어:
“틀릴 수도 있어.”

용사:
“그럼 내가 반대할게.”

“혼자 결정하지는 말고.”

**Result**

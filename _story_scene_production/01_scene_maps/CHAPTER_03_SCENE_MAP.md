# CHAPTER 03 — SCENE MAP

## S01 — 일곱 번째 불

**Type**  
Dialogue / Exploration / Information

**Location**  
왕립 기록관의 영웅 기념홀.

**Characters**  
플레이어, 용사, 학자 엘리안, 의식 참가자.

**Player Goal**  
C02 벽화 탁본의 연대와 훼손 시점을 확인한다.

**Immediate Conflict**  
공식 전승은 일곱 영웅을 기념하면서도 여섯 이름만 낭독하고, 마지막 하나를 ‘이름 없는 동료’라는 희생 신화로 설명한다.

**What Happens**  
플레이어는 실제 의식에서 일곱 개의 불이 켜지고 여섯 이름만 불리는 모습을 본다. 엘리안은 탁본의 원래 제작층과 후대 긁힘의 재질 차이를 확인해, 이름 없는 상태가 원본부터였던 것이 아님을 지적한다.

**Player Does**  
탁본 확대 비교, 기념홀의 명판·필사본 확인.

**Story Function**  
INFORMATION / WORLDBUILDING / FORESHADOW / CHARACTER

**Information Gained**  
‘스스로 이름을 버린 영웅’이라는 전승과 물리적 훼손이 맞지 않는다.

**Character Beat**  
용사도 익숙한 의식을 처음 낯설게 본다.

**Setup / Payoff**  
C02 벽화 Setup을 직접 회수하기 시작한다.

**Result**  
가장 오래된 원본들이 있는 기록도시 아르겐으로 조사 범위를 넓힌다.

**Transition**  
엘리안의 열람 허가로 세 사람이 기록도시로 이동한다.

---

## S02 — 기록이 사람을 먹는 도시

**Type**  
Exploration / Worldbuilding / Consequence

**Location**  
기록도시 아르겐의 행정 광장과 배급소.

**Characters**  
플레이어, 용사, 엘리안, 유족, 행정관, 피난민.

**Player Goal**  
원본 열람 절차를 밟으며 조사 장소를 파악한다.

**Immediate Conflict**  
기록은 과거를 보관하는 장치가 아니라 현재 사람의 배급·연금·거주권을 결정한다.

**What Happens**  
전사자 명부 누락으로 연금을 받지 못하는 유족, 탈영 기록 때문에 거주권을 잃은 가족, 영웅 이름으로 진행되는 징집 선서를 본다. C02에서 보급 손실이 컸다면 배급 줄이 더 길고 동부 피난민이 추가로 등장한다.

**Player Does**  
행정 창구 상호작용, 열람 허가 수령, 조사 지점 표시.

**Story Function**  
WORLDBUILDING / CONSEQUENCE / CHARACTER

**Information Gained**  
기록을 바꾸는 일은 현재의 권리와 충성 체계도 바꾼다.

**Character Beat**  
플레이어는 ‘진실 공개’가 추상적 선이 아니라 실제 사람의 삶을 흔드는 일임을 본다.

**Setup / Payoff**  
C02 선택 손실 재노출.

**Result**  
세 조사 지점의 열람 순서를 정하려는 순간 벽화 탁본이 도난된다.

**Transition**  
도둑이 시장 골목으로 도주한다.

## S03 — 사라진 탁본

**Type**  
Chase / Nonlethal Gameplay / Dialogue

**Location**  
시장, 지붕, 행정 수로.

**Characters**  
플레이어, 도둑/에드릭 연락책, 경비.

**Player Goal**  
탁본을 훼손 없이 회수한다.

**Immediate Conflict**  
도둑은 시민을 해치지 않고 경비와도 충돌을 피하며 도주한다. 살상 공격을 쓰면 기록이 손상될 위험이 있다.

**What Happens**  
비살상 추격 끝에 플레이어가 막다른 지붕에서 연락책을 제압한다. 그는 왕립 기록관에 들어간 원본이 다시 나오지 않을 수 있어 탁본을 다른 보관처로 빼돌리려 했다고 말한다.

**Player Does**  
추격, 지름길 선택, 비살상 제압.

**Story Function**  
GAMEPLAY / CHARACTER / INFORMATION / SETUP

**Information Gained**  
추방 장군 에드릭이 독립적으로 기록을 보존하고 있다.

**Character Beat**  
플레이어는 절도를 용납하지 않지만 ‘보관자가 하나뿐이면 다시 지워질 수 있다’는 문제는 기억한다.

**Setup / Payoff**  
S09 분산 보존 원칙 Setup.

**Result**  
탁본을 되찾고 에드릭 연락 표식을 확보한다.

**Transition**  
공식 조사와 비공식 연락선을 동시에 가진 상태로 세 장소 교차 조사에 들어간다.

## S04 — 세 시대의 같은 빈자리

**Type**  
Investigation / Exploration / Puzzle Hybrid

**Location**  
왕립 대서고 → 영웅 기념묘 → 폐쇄 수도원.

**Characters**  
플레이어, 용사, 엘리안, 기록관 직원.

**Player Goal**  
일곱째의 실존과 삭제 방식, 사상 변화를 독립 증거로 검증한다.

**Immediate Conflict**  
세 장소는 서로 다른 시대·매체를 사용하며 어느 하나만으로는 결론이 충분하지 않다.

**What Happens**  
- 대서고: 시대별 필사본을 겹쳐 ‘일곱’ 숫자는 남고 이름만 지속적으로 사라지는 수정 패턴과 재점화 방지 결재 문구를 확인.
- 기념묘: 철거된 일곱 번째 석상 기초와 동일 시기 공방 기록으로 실존 확인.
- 폐쇄 수도원: 장례 명부·숙소표·설교문 필체/인장을 연결해 초기 공존적 태도 → 후기 배타주의 변화를 확인.

**Player Does**  
필사본 연대 정렬, 석재/공방 기록 대조, 필체·인장 매칭.

**Story Function**  
INFORMATION / GAMEPLAY / CHARACTER / PAYOFF

**Information Gained**  
일곱째는 실존했고 삭제는 장기적·조직적이었다. 사상도 시간이 지나며 변했다.

**Character Beat**  
두 사람은 ‘억울하게 지워진 영웅’이라는 단순 해석을 경계한다.

**Setup / Payoff**  
C02 벽화의 실존 문제를 CONFIRMED로 전환.

**Result**  
조사 기록이 중앙 시스템에 올라가고 세라드가 개입한다.

**Transition**  
기록수호대가 서고와 도시 출입문을 봉쇄한다.

## S05 — 공개해도 되는 사실

**Type**  
Dialogue / Tension / Institutional Conflict

**Location**  
대서고 중앙 회랑.

**Characters**  
플레이어, 용사, 엘리안, 세라드, 기록수호대.

**Player Goal**  
조사 기록과 탁본을 압수당하지 않고 다음 단서를 확보한다.

**Immediate Conflict**  
세라드는 상부 명령에 따라 관련 기록을 왕실 봉인고로 회수하고 목격자를 조사하려 한다.

**What Happens**  
세라드는 징집 거부, 종교 분열, 변경 반란 위험을 이유로 조사를 중단시킨다. 용사의 권위도 기록 반출 명령 자체를 취소할 수는 없다. 엘리안의 열람 권한이 즉시 정지된다.

**Player Does**  
대화 선택으로 세라드의 명령 범위를 확인하고, 공개 압수 목록에서 빠진 에드릭 연락 표식을 이용할 기회를 만든다.

**Story Function**  
PLOT / CHARACTER / TENSION / INFORMATION

**Information Gained**  
세라드는 삭제의 최상위 지시자가 아니라 현재 봉인을 집행하는 인물이다.

**Character Beat**  
갈등은 ‘진실 vs 악당’이 아니라 공개 책임과 안정의 충돌로 확장된다.

**Result**  
공식 열람은 중단되지만 두 사람은 아직 체포/수배 상태가 아니다. 왕실 심의가 예고된다.

**Transition**  
원본이 수도로 이송되기 전에 위치를 알기 위해 에드릭과 접촉한다.

## S06 — 질문을 두려워하는 사람들

**Type**  
Dialogue / Exploration / Moral Contrast

**Location**  
기록도시 외곽의 추방민 작업장.

**Characters**  
플레이어, 용사, 에드릭, 연락책.

**Player Goal**  
전쟁 전 원정 원본의 위치와 이송 시점을 알아낸다.

**Immediate Conflict**  
에드릭은 왕국 기록 기관을 믿지 않지만 자기 연락책의 절도도 정당화하지 않는다.

**What Happens**  
에드릭은 전쟁 이전 원정 기록을 발견했다가 압수당했고 일부 탁본을 빼돌린 일로 추방됐다고 밝힌다. 연락책을 공개적으로 무장 해제하고 탁본 절도 책임을 인정한다. 결정적 원본이 그날 밤 수도로 이동한다는 이송표를 제공한다.

**Player Does**  
에드릭의 탁본과 S04 자료를 비교해 같은 작전 표식을 확인한다.

**Story Function**  
INFORMATION / CHARACTER / SETUP

**Information Gained**  
전쟁 전 원정 기록이 실제로 존재하며 곧 중앙 봉인고로 이동한다.

**Character Beat**  
플레이어는 왕국 반대편 인물도 자동으로 믿지 않고 증거를 대조한다.

**Result**  
옛 군용 통로와 압수 상자 이동 경로를 얻는다.

**Transition**  
원본 반출 전에 봉인 서고로 진입해야 한다.

## S07 — 봉인되기 전의 원본

**Type**  
Infiltration / Investigation / Nonlethal Combat

**Location**  
기록도시 하부 군용 통로와 봉인 서고.

**Characters**  
플레이어, 용사, 기록수호대.

**Player Goal**  
원본을 찾아 공개 검증 가능한 상태로 확보한다.

**Immediate Conflict**  
수호대는 살해 대상이 아니며, 원본은 여러 압수 상자 중 하나에 섞여 이동 중이다.

**What Happens**  
플레이어는 압수 상자 이동표, 서고 연대, 보급 수량을 비교해 실제 원본 상자를 추적한다. 북부 경계 정화 작전 원본에서 최초 전쟁 이전 인간 정규군과 일곱째의 군대가 야수족 영역으로 이동했음을 확인한다. 목적·최종 명령 부분은 훼손돼 있다.

**Player Does**  
잠입, 비살상 제압, 이동표 역추적, 문서 연대·수량 대조.

**Story Function**  
PLOT / GAMEPLAY / INFORMATION / REVELATION

**Information Gained**  
인간군은 최초 전쟁 이전에 야수족 영역으로 실제 원정을 갔다. 그 이유와 결과는 아직 모른다.

**Character Beat**  
플레이어와 용사는 문서가 허용하는 범위 이상을 말하지 않는다.

**Result**  
원본 상자를 확보하지만 세라드가 반출대를 이끌고 중앙 회랑을 봉쇄한다.

**Transition**  
원본을 가지고 나가려면 세라드와 직접 충돌해야 한다.

## S08 — 기록수호대장 세라드

**Type**  
Boss Combat / Objective Combat / Character

**Location**  
중앙 회랑과 기록 반출 승강대.

**Characters**  
플레이어, 용사, 세라드, 기록수호대.

**Player Goal**  
봉인 상자가 수도 이송 승강대에 실리는 것을 막고 세라드를 제압한다.

**Immediate Conflict**  
세라드는 플레이어 살해보다 원본 반출을 우선하며 진형, 연막, 쇠뇌로 시간을 번다.

**What Happens**  
용사는 호위대를 죽이지 않고 진형을 막는다. 플레이어는 세라드와 직접 싸우며 동시에 승강대 잠금 장치를 끊어야 한다. 최종적으로 플레이어가 세라드를 전투 불능으로 만들고 봉인 상자를 직접 회수한다.

**Player Does**  
패링 중심 인간 보스전 + 반출 타이머 차단 + 비살상 마무리.

**Story Function**  
GAMEPLAY / CHARACTER / PLOT / CONSEQUENCE

**Information Gained**  
세라드는 자신의 명령이 나라를 지키기 위한 것이라 끝까지 믿는다.

**Character Beat**  
용사는 자신의 이름보다 기록의 존재를 지키겠다고 선택한다.

**Result**  
세라드는 생존, 원본 반출은 중단된다.

**Transition**  
이제 원본을 다시 한 장소에 숨기는 대신 ‘다시 지울 수 없는 상태’로 만들어야 한다.

## S09 — 다시 지울 수 없는 기록

**Type**  
Choice / Public Verification / Character

**Location**  
기록도시 시민 회랑과 여러 보관처.

**Characters**  
플레이어, 용사, 엘리안, 에드릭, 성직자·시민 증인.

**Player Goal**  
원본의 진위와 존재를 한 기관이 독점하지 못하도록 보존한다.

**Immediate Conflict**  
원본을 공개하면 사회적 파장이 커지고, 다시 중앙 기관에 맡기면 삭제 위험이 남는다.

**What Happens**  
엘리안이 공개된 증인 앞에서 원본 목록과 진위를 기록한다. 탁본/공증 사본을 에드릭 공동체, 회색벽 생존자 대표, 왕립 기록관 내부 서로 다른 서고로 분산한다. 용사는 자신의 인장으로 ‘원본이 실제 존재하며 직접 확인했다’고 증언한다. 공개문은 CONFIRMED와 OPEN을 구분한다.

**Player Does**  
사본 배치와 공개문 항목 확인. 메인 결과는 분산 보존으로 고정되며, 어느 보관처를 추가 선택하는지는 부가 선택 가능.

**Story Function**  
CHARACTER / PAYOFF / CONSEQUENCE / INFORMATION

**Information Gained**  
‘진실’과 ‘추정’을 구분해 공개할 수 있다.

**Character Beat**  
플레이어의 성장: 발견자가 아니라 보존 구조를 만드는 사람.

**Result**  
기록은 완전히 다시 지우기 어려워진다.

**Transition**  
왕실은 사건을 무시할 수 없게 되고 긴급 심의를 연다.

---

## S10 — 심의 아래의 길

**Type**  
Dialogue / Consequence / Exit Hook

**Location**  
왕립 연락소와 도시 출구.

**Characters**  
플레이어, 용사, 엘리안, 왕실 심의관/전령.

**Player Goal**  
정치적 결과를 확인하고 다음 현장 조사를 준비한다.

**Immediate Conflict**  
왕실은 기록 탈취와 명령 불복종을 문제 삼지만, 분산된 원본·생존 증언·용사의 공식 증언 때문에 단순 은폐나 반역 처리가 불가능하다.

**What Happens**  
- 플레이어에게 왕실 출석·심의 명령 및 이동 보고 의무.
- 일부 중앙 지원과 기록 접근 동결.
- 엘리안 직위 해임.
- 에드릭 공동체 보급 제재.
- 용사의 궁정 재량과 일부 중앙 지원 제한.
- 용사의 공식 직위와 현장 긴급 지휘권은 유지.
- ‘추가 증거 확보 후 심의’ 명목으로 원정 경로에 대한 제한 현장 조사 승인.
두 사람은 원정 좌표와 경로 사본을 들고 야수족 영역으로 출발한다.

**Player Does**  
심의 문서 확인, 보급을 제한된 목록에서 정리, 원정 경로 선택.

**Story Function**  
CONSEQUENCE / CHARACTER / PLOT / EXIT HOOK

**Information Gained**  
정치적 대가는 실재하지만 두 사람은 도망자가 아니다. 다음 조사는 공식·제한된 권한 아래 진행된다.

**Character Beat**  
용사는 “문서 하나로 전쟁 시작을 정할 수 없다”고 선을 긋고, 플레이어는 “직접 확인한 것부터 믿자”고 답한다.

**Result**  
정치적 비용과 조사 권한이 동시에 확정된다.

**Transition**  
C04에서 인간 기록의 원정 경로를 야수족 현장 증거와 대조한다.

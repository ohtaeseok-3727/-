# CHAPTER 05 — SCENE MAP

## S01 — 불길 사이의 길

**Type**
Gameplay / Escort / Exploration / Hybrid

**Location**
아르카스 외곽 피난로와 불탄 관문.

**Characters**
플레이어, 용사, 피난민 호송대, 현지 수비병, 폐성 점령 세력의 척후.

**Player Goal**
피난민을 안전지대로 이동시키며 C04에서 확보한 표식과 일치하는 진입 흔적을 찾는다.

**Immediate Conflict**
불탄 도로와 붕괴물 때문에 피난로가 좁고, 점령 세력의 척후가 이동 경로를 압박한다.

**What Happens**
피난민 이동 중 플레이어는 불탄 관문 양쪽에서 서로 다른 문장 홈을 발견한다. C04의 인간 측/용 측 탁본과 각각 일치하지만, 두 홈은 서로 마주 보는 구조다.

**Player Does**
호송대 앞뒤를 오가며 매복을 끊고, 붕괴물을 열어 통로를 확보한 뒤 두 탁본을 관문 홈에 대조한다.

**Story Function**
GAMEPLAY / PAYOFF / INFORMATION / TENSION

**Information Gained**
C04 경계 표식이 단순 국경 표지가 아니라 같은 시설의 양측 접근 표식이었다는 강한 물증.

**Character Beat**
용사는 병력에게 폐성 진격이 아니라 피난민 통행 확보를 우선 명령한다.

**Setup / Payoff**
C04 표식 PAYOFF.

**Result**
표식이 맞물리며 지하 우회 통로의 방향이 드러난다.

**Transition**
피난민을 안전지대로 보내고 두 사람은 지하 통로를 통해 회담 시설로 진입한다.

## S02 — 내려놓는 곳

**Type**
Exploration / Puzzle / Environmental Storytelling

**Location**
지하 대기실과 양측 무기 보관실.

**Characters**
플레이어, 용사.

**Player Goal**
시설의 성격을 판단하고 현재 점령 세력이 파괴하기 전에 남은 기록을 확보한다.

**Immediate Conflict**
화재와 붕괴로 보관실 일부가 무너지고 있으며, 양측 표식을 잘못 배치하면 오래된 잠금장치가 닫힌다.

**What Happens**
양쪽에 대칭 배치된 무기 걸이, 수량 대조 홈, 비무장 통과선을 발견한다. 인간식 무기 규격과 비인간형 무기 규격이 서로 분리 보관되도록 설계되어 있다.

**Player Does**
C04 탁본 방향을 맞춰 두 개의 잠금석을 동시에 개방하고, 남은 걸이 번호와 출입표를 비교한다.

**Story Function**
INFORMATION / WORLDBUILDING / PAYOFF / GAMEPLAY

**Information Gained**
이 시설은 적 포로 수용소가 아니라 양측 대표가 무기를 맡기고 안쪽으로 들어가기 위한 중립 절차 시설이었다.

**Character Beat**
용사는 “우리 쪽 기록에 이런 절차는 없었다”고 말하지만, 부정 대신 현장을 기록한다.

**Setup / Payoff**
정식 회담 실재 확인의 첫 물증.

**Result**
내부 회담실로 가는 통행표 조각과 양측 출입 번호를 확보한다.

**Transition**
출입 번호가 같은 날짜의 기록 보관실 묶음과 연결된다.

## S03 — 불탄 회담실

**Type**
Exploration / Dialogue / Environmental Storytelling

**Location**
아르카스 중앙 회담실.

**Characters**
플레이어, 용사, 피난 중인 노기록관.

**Player Goal**
회담이 실제로 진행되었는지 확인한다.

**Immediate Conflict**
점령 세력의 약탈로 기록함이 뜯겨 있고, 노기록관은 남은 문서를 들고 탈출하려 한다.

**What Happens**
회담실에는 대칭 좌석, 중립 서기관 자리, 양측 인장 슬롯이 남아 있다. 노기록관은 이곳을 세대 전부터 “불탄 협정실”이라 불렀다고 하지만 전승과 사실을 구분하지 못한다.

**Player Does**
서기관 자리의 장부 번호와 S02 출입 번호를 대조하고, 인장 슬롯의 압인 흔적을 탁본한다.

**Story Function**
PLOT / INFORMATION / CHARACTER / WORLDBUILDING

**Information Gained**
정식 대표단이 동일 날짜에 내부 회담실에 들어왔다는 사실이 확정된다. 단, 최종 문서의 서명 여부는 알 수 없다.

**Character Beat**
플레이어는 노기록관의 전승을 “증언”으로, 현장 흔적을 “물증”으로 따로 기록한다.

**Setup / Payoff**
C06 이후 증언/물증 분리 방식 SETUP.

**Result**
회담 당일 기록 묶음의 일부가 지하 기록고에 남았다는 단서를 얻는다.

**Transition**
화재가 번지기 전에 기록고로 이동해야 한다.

## S04 — 타는 기록

**Type**
Gameplay / Rescue / Timed Objective

**Location**
붕괴 중인 지하 기록고.

**Characters**
플레이어, 용사, 노기록관, 점령 세력 약탈조.

**Player Goal**
사람과 핵심 기록을 동시에 보존한다.

**Immediate Conflict**
화재, 붕괴, 약탈조가 동시에 진행된다. 모든 문서를 구할 수 없다.

**What Happens**
기록고는 여러 구역으로 나뉘어 있고, 플레이어는 먼저 사람을 구하면서 어떤 기록함을 우선 보존할지 선택해야 한다. 핵심 장부 위치는 S02~S03에서 얻은 번호로 추적 가능하다.

**Player Does**
붕괴 경로를 열고, 약탈조를 저지하고, 물을 돌려 불길을 늦춘 뒤 회담일 장부와 양측 연락 기록을 우선 회수한다.

**Story Function**
GAMEPLAY / CHOICE / TENSION / PLOT

**Information Gained**
양측 연락 장부가 서로 다른 시간 표기법을 쓴다는 사실.

**Character Beat**
용사는 병력에게 문서보다 사람부터 빼라고 지시하고, 플레이어는 제한 시간 안에서 증거 보존 우선순위를 정한다.

**Setup / Payoff**
판단의 비용과 증거 범위 원칙 강화.

**Result**
핵심 기록은 부분 보존되지만 일부 문서는 소실된다.

**Transition**
회수한 양측 기록의 시간 표기를 맞추기 위해 외부 관측 장치가 필요하다.

## S05 — 같은 밤, 다른 시계

**Type**
Puzzle / Investigation

**Location**
회담소의 두 관측탑과 중앙 시간석.

**Characters**
플레이어, 용사.

**Player Goal**
인간 측과 몬스터 측 기록의 시간대를 공통 기준으로 환산한다.

**Immediate Conflict**
한쪽 시간석이 파손되어 있고, 기록에는 서로 다른 천문 기준과 교대 시각이 사용된다.

**What Happens**
플레이어는 별자리 각도, 종탑 파손 시점, 화재층의 낙진 순서를 이용해 두 기록의 기준점을 맞춘다.

**Player Does**
관측탑 장치를 재정렬하고, 세 개의 시간 단서를 맞춰 양측 피격 보고를 같은 축에 놓는다.

**Story Function**
INFORMATION / GAMEPLAY / FORESHADOW / PLOT

**Information Gained**
인간 측 외곽 숙영지와 몬스터 측 집결지가 거의 같은 시간대에 공격받았다는 사실. 어느 쪽이 먼저 공격했는지는 기록 정밀도로 확정할 수 없다.

**Character Beat**
용사는 “그럼 한쪽이 먼저 배신했다는 증거는 없다는 거군”이라고 결론을 낮춘다. 플레이어는 “없다는 것과 아니었다는 건 다르다”고 선을 긋는다.

**Setup / Payoff**
‘거의 동시인 양측 피격 보고’ 장기 SETUP.

**Result**
두 보고를 공통 시간표로 보존한다.

**Transition**
기록 끝부분의 후송 목록에서 반복되는 이름과 산맥 표기가 발견된다.

## S06 — 에르가논의 이름

**Type**
Investigation / Dialogue / Exploration

**Location**
후송 명부실과 치료소 잔해.

**Characters**
플레이어, 용사, 노기록관.

**Player Goal**
피격 이후 누가 어디로 이동했는지 추적한다.

**Immediate Conflict**
명부는 이름 대신 직책과 문장으로 기록되어 일부 식별이 어렵다.

**What Happens**
용 문장, 오래된 치료 인장, 후송 노선을 대조하면 “에르가논”이라는 고유명이 한 번 남아 있고, 그 이후 기록에는 동일 개체로 추정되는 ‘장수 용 증언자’가 검은 척추 산맥 방향으로 이동한 흔적이 이어진다.

**Player Does**
세 조각의 명부를 조합하고 문장 중복을 제거해 이동 경로를 복원한다.

**Story Function**
PLOT / INFORMATION / SETUP

**Information Gained**
에르가논이 최초 결전 직후 즉사하지 않았을 가능성이 높으며, 검은 척추 산맥으로 옮겨졌다는 기록.

**Character Beat**
두 사람은 이름 하나로 생존을 확정하지 않고 “추적할 가치가 충분한 단서”로 분류한다.

**Setup / Payoff**
C06 직접 동기 SETUP.

**Result**
검은 척추 산맥의 옛 후송로 좌표를 확보한다.

**Transition**
점령 세력이 기록고 전체를 불태우기 위한 화약/마법 장치를 작동시킨다.

## S07 — 증거를 들고 나가기

**Type**
Combat / Escape / Hybrid

**Location**
아르카스 지하 회랑과 외곽 수문.

**Characters**
플레이어, 용사, 피난민/노기록관, 점령 세력 지휘자.

**Player Goal**
생존자와 보존 기록을 들고 폐성을 탈출한다.

**Immediate Conflict**
점령 지휘자가 기록을 없애고 통로를 봉쇄하려 한다. 전투 중 기록함이 직접 위험에 놓인다.

**What Happens**
보스는 기록함 운반자를 노리고, 통로를 붕괴시키며 증거 손실을 강요한다. 플레이어는 전투와 운반 경로 보호를 동시에 수행한다.

**Player Does**
수문을 열어 화재를 끊고, 지휘자를 제압하고, 운반 인원을 보호해 기록을 밖으로 빼낸다.

**Story Function**
COMBAT / GAMEPLAY / TENSION / PLOT

**Information Gained**
점령 세력은 오래된 진실을 알고 지운 것이 아니라, 폐성의 금속·문서·봉인물을 자원화하려던 세력이다. 과거 배후와 직접 연결되지 않는다.

**Character Beat**
두 사람은 현재 적을 과거 음모의 증거로 오인하지 않는다.

**Setup / Payoff**
“모든 갈등을 하나의 배후로 묶지 않는다”는 Canon guardrail 강화.

**Result**
기록과 생존자 일부를 보존해 탈출한다.

**Transition**
안전지대에서 보존한 자료를 최종 분류한다.

## S08 — 확정된 것, 남은 것

**Type**
Dialogue / Choice / Chapter Exit

**Location**
아르카스 외곽 임시 피난 진지.

**Characters**
플레이어, 용사, 노기록관.

**Player Goal**
이번 조사에서 무엇을 확정하고 무엇을 보류할지 정리한다.

**Immediate Conflict**
현장 병사와 난민들은 “누가 먼저 배신했는가”라는 단순한 답을 요구한다.

**What Happens**
플레이어와 용사는 보존 자료를 세 범주로 나눈다: 확정, 정황, 미확인. 회담 실재와 무기 보관, 거의 동시 피격은 확정한다. 협정 서명 여부와 공격 배후는 미확인으로 남긴다.

**Player Does**
기록 분류표에 핵심 항목을 배치하고, C06으로 가져갈 증거 묶음을 선택한다.

**Story Function**
CHARACTER / INFORMATION / CHOICE / EXIT HOOK

**Information Gained**
에르가논 추적 경로와 검은 척추 산맥 후송표가 가장 신뢰도 높은 다음 단서다.

**Character Beat**
용사는 자신의 진영에 유리한 결론을 요구하는 병사에게 “모르는 건 모른다고 적는다”고 말한다. 플레이어는 그 기준을 그대로 적용한다.

**Setup / Payoff**
C03~C06 ‘상징이 자기 체제를 조사’ 아크 강화.

**Result**
아르카스 회담 실재는 CONFIRMED. 협정 서명 여부·배후·최초 책임은 OPEN. 에르가논 생존 가능성과 산맥 경로 확보.

**Transition**
두 사람은 검은 척추 산맥의 옛 후송로로 향한다.

# Scene Map Self-Check
1. C04 End State의 두 표식이 S01~S02에서 직접 사용된다.
2. 모든 주요 정보는 플레이어 행동과 물증 대조를 통해 획득한다.
3. 회담 실재는 확정하지만 협정 체결과 배후는 확정하지 않는다.
4. 동시 피격 보고는 C06~C09 복선으로 보존된다.
5. 에르가논 단서가 C06 이동의 직접 원인이 된다.
6. 현재의 점령 세력을 과거 음모와 임의 연결하지 않는다.
7. 호송·탐험·기록 보존·시간대조·전투가 서로 다른 플레이 경험을 제공한다.

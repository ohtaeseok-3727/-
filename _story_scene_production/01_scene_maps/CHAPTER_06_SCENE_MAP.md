# CHAPTER 06 — SCENE MAP
# 오래된 용

## S01 — 끊어진 후송로
**Type** Exploration / Traversal / Puzzle
**Location** 검은 척추 산맥 남사면.
**Characters** 플레이어, 용사, 산맥 초소 인원.
**Player Goal** C05 후송표를 현재 지형에 맞춰 복원한다.
**Immediate Conflict** 눈사태와 붕괴로 옛 길이 끊겼고 인간 지도와 용인족 표식이 서로 다르다.
**What Happens** 세 시대의 지도를 겹쳐 실제 후송로를 복원한다.
**Player Does** 지형 흔적 판독, 표식 정렬, 우회로 개방.
**Story Function** GAMEPLAY / INFORMATION / CONTINUITY
**Information Gained** 대규모 부상자 이동이 양 방향으로 있었음.
**Character Beat** 용사가 자신의 전승 지도를 절대 기준으로 쓰지 않는다.
**Result** 첫 치료 거점 진입.
**Transition** 인간식 후송표가 발견된다.

## S02 — 승전 뒤의 명부
**Type** Investigation / Exploration
**Location** 폐쇄된 인간 후송소.
**Player Goal** 인간 측 전투 결과를 복원한다.
**Immediate Conflict** 승전 기념문과 실제 부상 명부가 서로 모순된다.
**What Happens** 기념문은 승리를 선언하지만 명부는 장교·영웅대의 대량 손실과 후송 실패를 기록한다.
**Player Does** 명부 조각 복원, 인장 대조, 병상 수 계산.
**Story Function** INFORMATION / CHARACTER
**Information Gained** 인간 핵심 전력도 치명적 손실.
**Character Beat** 용사가 승전 문구를 직접 지운 대신 옆에 실제 수치를 기록한다.
**Result** 북쪽 용인족 치료소 좌표 확보.
**Transition** 독립 자료와 대조 필요.

## S03 — 반대편의 상처
**Type** Exploration / Hazard / Investigation
**Location** 용인족 암벽 치료소.
**Player Goal** 용인족 측 피해를 독립 검증한다.
**Immediate Conflict** 산맥 봉쇄 생물과 무너진 비행 플랫폼.
**What Happens** 치료실의 체격별 고정대, 비행막 봉합틀, 사망/후송 표식을 발견한다.
**Player Does** 위험 구역 횡단, 치료표 해독, C05 시간표와 대조.
**Story Function** INFORMATION / PAYOFF
**Information Gained** 용인족도 비슷한 시각대에 핵심 전력을 잃음.
**Result** 최초 결전은 상호 파괴에 가까웠다는 물증 강화.
**Transition** 같은 치료 인장이 에르가논의 안식처 방향을 가리킴.

## S04 — 관계를 증명하는 문
**Type** Puzzle / Choice / Hybrid
**Location** 고대 산맥 봉쇄문.
**Player Goal** 에르가논의 영역으로 진입.
**Immediate Conflict** 문은 단독 강제 개방을 거부하고 두 역할의 협력을 요구한다.
**What Happens** 한쪽은 힘으로 압력을 유지하고 다른 쪽은 흔적을 읽어 안전 순서를 찾는다.
**Player Does** 용사와 신호 교환, 순차 봉인 해제.
**Story Function** GAMEPLAY / CHARACTER
**Character Beat** C01부터 쌓인 상호보완이 시스템으로 검증된다.
**Result** 봉쇄문 통과.
**Transition** 에르가논과 대면.

## S05 — 오래된 용의 증언
**Type** Dialogue / Investigation
**Location** 산맥 내부 고대 치료 동굴.
**Characters** 플레이어, 용사, 에르가논.
**Player Goal** 최초 결전과 제7영웅 관련 기억을 검증한다.
**Immediate Conflict** 에르가논의 기억에는 분노와 편견이 섞여 있다.
**What Happens** 에르가논은 양측이 모두 무너졌고, 제7영웅이 말년에 다른 종족을 적으로 규정하며 백색성에 틀어박혔다고 증언한다.
**Player Does** C05 기록과 증언을 항목별 대조, 확인/불일치 표시.
**Story Function** INFORMATION / CHARACTER / SETUP
**Information Gained** 제7영웅 변화 시기, 백색성 방향.
**Result** 백색성 좌표 해독의 열쇠 확보.
**Transition** 마지막 물증 확인.

## S06 — 승리가 아니었던 전장
**Type** Exploration / Environmental Storytelling / Chapter Exit
**Location** 최초 결전 능선.
**Player Goal** 증언의 핵심을 현장 물증으로 최종 검증.
**Immediate Conflict** 눈보라와 불안정한 잔류 마력.
**What Happens** 양측 후퇴 방향, 버려진 지휘 장비, 동시 응급 후송 흔적이 한 전장에 겹쳐 있다.
**Player Does** 세 지점 기록, 피해 축을 지도에 합성.
**Story Function** PAYOFF / EMOTION / EXIT HOOK
**Information Gained** 최초 결전은 승리가 아니라 양측 핵심 전력 붕괴.
**Character Beat** 용사가 승전 신화를 내려놓는다.
**Result** 에르가논이 준 표식과 현장 방위각으로 백색성 위치 확정.
**Transition** C07 백색성 조사.

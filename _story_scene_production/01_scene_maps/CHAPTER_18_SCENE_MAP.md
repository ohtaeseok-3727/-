# CHAPTER 18 — SCENE MAP
S01 죽음 영역 입구 — C15~17 세 흔적의 도착점 확인.
S02 잔여 왕권 검증 — 정복/기근/전쟁의 비활성 권능이 죽음의 왕에게 회수됐음을 축소 실험으로 증명.
S03 실제 사자 — 유품/기억을 통해 실제 죽은 자와 전쟁 잔영을 구분.
S04 고정못 해제 — 사자를 다시 죽이지 않고 귀속 고정못을 역류시켜 해방.
S05 예정 사령의 실 — 용사가 스스로 실을 붙잡아 죽음의 왕 위치를 고정.
S06 세 권능 간섭 — 소유권/흡수 흐름/충돌 자원화 규칙을 역이용.
S07 무덤 왕좌 — 왕좌 파괴 후 죽음의 왕 사망.
S08 내핵 쐐기 — 지연 절단 쐐기 설치, 귀환 타이밍 확보.
S09 귀환 — 외핵 좌표 조각으로 두 사람 귀환.
S10 공진 폐쇄 — 아크 드래곤 외핵 타격 → 복구파 역발동 → 내핵 쐐기 발동 → 양핵 동시 폐쇄.
S11 남은 세계 — 사령망 종료 확인, 전후 선택은 OPEN.

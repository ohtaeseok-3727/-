# CHECKPOINT — CHAPTER 04~06

## 감정 리듬
C04는 인간 측 과거 가해를 직접 목격하는 충격, C05는 답을 서두르지 않는 절제, C06는 승전 신화를 내려놓는 수용으로 기능이 분리된다.

## Gameplay
- C04: 구조 / 기억석 / 충돌 차단 / 비살상 보스
- C05: 호송 / 기록 보존 / 시간대조 / 호위 보스
- C06: 지도 복원 / 피해 자료 대조 / 비대칭 협동 / 현장 검증

## 관계
용사는 권위를 보호와 철수에 쓰고, 플레이어는 증거 강도를 분류한다. C06에서 두 사람은 같은 증거 판단 원칙을 공유한다.

## 정보 공개
C04 인간 가해 확인 → C05 회담 실재와 동시 피격 → C06 최초 결전 상호 파괴. 제7영웅의 악마 접촉은 C07까지 보류한다.

## 복선
C04 경계 표식→C05 회담로 PAYOFF 완료.
C05 동시 피격→C06 최초 결전 PARTIAL PAYOFF.
C06 에르가논의 제7영웅 변화/백색성→C07 준비.

## Result
구조 수정 필요 없음. C07 진행 가능.

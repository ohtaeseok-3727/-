# CHECKPOINT — CHAPTER 16~18

## 감정 리듬
C16은 절제와 버티기, C17은 싸울 수 있어도 싸우지 않을 선택, C18은 지금까지 배운 규칙과 신뢰를 모두 재사용하는 결론으로 상승한다.

## Gameplay
- C16: 자원 흐름 추적 / 유량 비교 / 역류 / 절제형 보스
- C17: 패링 / 해제 / 구출 / 충돌 게이지 관리
- C18: 잔여 왕권 시험 / 사자 해방 / 권능 간섭 / 내핵 쐐기 / 귀환 / 공진 폐쇄
최종 3개 Chapter의 핵심 경험이 반복되지 않는다.

## 관계 변화
플레이어는 시스템 규칙을 읽고 조합하는 최종 책임자가 되고, 용사는 C18에서 예정 사령의 실을 스스로 잡아 플레이어의 판단을 신뢰한다. 어느 한쪽도 다른 쪽을 대신할 수 없다.

## 정보 공개
C15~C17의 잔여 흔적은 C18에서 죽음의 왕이 회수한 실제 잔여 왕권으로 확정된다.
죽음의 왕은 자연적 죽음의 원천이 아니라 실제 죽은 자를 사령망에 귀속시키는 존재로 유지된다.

## 복선 회수
- C14 외핵 보존 → C18 귀환 및 양핵 동시 폐쇄 PAYOFF.
- C15 소유권 규칙 → C18 정복 왕권 간섭 PAYOFF.
- C16 흡수 흐름 → C18 기근 왕권 역류 PAYOFF.
- C17 충돌 자원화 → C18 전쟁 왕권 과충전 PAYOFF.
- C15~17 잔여 흔적 → C18 죽음의 왕 회수 구조 PAYOFF.
- C12/C17 분리 신호 경험 → C18 신뢰 기반 역할 분담의 최종 형태로 정서적 회수.

## Ending Guardrails
- 죽음의 왕 사망 CONFIRMED.
- 현재 사령망 종료 CONFIRMED.
- 현재 중심 지옥문 네트워크 폐쇄 CONFIRMED.
- 인간/몬스터/야수족/드래곤의 전후 화해는 OPEN.
- 세계의 모든 전쟁이 자동 종결됐다고 표현하지 않음.

## Result
구조 수정 필요 없음. C18 End State는 FINAL_SETTINGS 및 FINAL_STORY_SPINE과 일치한다.

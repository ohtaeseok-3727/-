# CHAPTER 18 — CRITIQUE
C18-01 Major: 잔여 왕권 Reveal이 설명 대사로 끝날 위험. 세 축소 시험으로 각 권능 반응을 재현할 것.
C18-02 Major: 실제 사자 해방이 일반 언데드 처치가 되면 주제 붕괴. 유품/기억 확인 후 고정못 역류만 허용.
C18-03 Major: 용사의 예정 사령 고정이 희생 연출로 오해될 위험. 실제 사망하지 않으며 능동적 선택/후유증을 명확히.
C18-04 Major: 죽음의 왕 최종전이 새 규칙이면 안 됨. C15 소유, C16 흡수, C17 충돌 규칙만 재사용.
C18-05 Major: 양핵 폐쇄가 데우스 엑스 마키나가 되지 않게 C14 좌표 조각과 축소 실험을 그대로 재사용.
C18-06 Major: 엔딩이 자동 평화처럼 보일 위험. 강제 전쟁 구조만 제거하고 전후 관계는 OPEN 유지.
